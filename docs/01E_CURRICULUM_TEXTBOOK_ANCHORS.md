# 구석기 역사 체험 웹게임
## Stage 01E — Curriculum / Textbook Anchor Principles v3

> 목적: 사용자가 제공한 5학년 사회 교과서 구석기 부분의 핵심 표현·유물·생활 요소를 체험에 분명히 연결하되, 교과서 설명이나 퀴즈가 서사를 끊지 않도록 한다.
>
> 이 문서는 교과서 원문의 장문 복제가 아니라, 프로젝트 구현에 필요한 핵심 개념 관계와 오개념 방지 규칙을 정리한다.

---

# 1. 보존할 핵심 Anchor

1. **뗀석기**
   - 돌을 깨뜨리거나 떼어 만들어 사용한 도구라는 상위 교과 개념.
2. **주먹도끼**
   - 뗀석기의 대표적인 구체 예.
   - 자르기·두들기기·땅파기 등 여러 생활 행동과 연결한다.
3. **이동 생활**
   - 먹을 것을 찾아 옮겨 다니는 생활.
4. **거처의 다양성**
   - 한데의 임시적인 막집.
   - 동굴이나 바위 그늘 같은 자연 생활 공간.
5. **불의 이용**
   - 추위를 피함.
   - 사나운 짐승으로부터 몸을 보호하는 데 도움.
   - 음식을 익혀 먹음.
6. **사냥·채집·생활 가공**
   - 먹을거리 확보를 사냥 하나로 축소하지 않음.
   - 풀뿌리 등 먹을거리의 가공 경험을 활용할 수 있음.
7. **선사 시대의 재구성 성격**
   - 구체 인물·대사·하루 사건은 근거가 뒷받침하는 생활 조건 안에서 만든 재구성임을 구분한다.

---

# 2. 교과 연결 문법

# **Experience → Name → Reuse → Connect**

```text
1. 먼저 만난다 / 겪는다
        ↓
2. 짧고 정확하게 이름을 붙인다
        ↓
3. 이후 생활 행동/다른 관점에서 다시 사용한다
        ↓
4. 후속 개념화에서 교과서 표현·실제 유물/유적과 연결한다
```

# **핵심 용어는 숨기지 않는다. 다만 용어가 경험보다 먼저 세계를 설명하지 않게 한다.**

---

# 3. 뗀석기와 주먹도끼의 위계

공식 관계:

```text
뗀석기
└─ 대표적인 예: 주먹도끼
```

좋은 student-facing reveal:

> **뗀석기**  
> 돌을 깨뜨리거나 떼어 만든 도구를 뗀석기라고 한다. 지금 손에 든 것은 그 대표적인 예인 **주먹도끼**다.

피할 것:

- `뗀석기 = 주먹도끼`
- `뗀석기 · 주먹도끼`를 관계 설명 없이 같은 급의 제목으로 제시
- 모든 뗀석기가 주먹도끼인 것처럼 묘사
- 주먹도끼를 사냥 무기로만 묘사

Stage 07은 **받기 + 명명 + continuity**까지만 proof한다.

Stage 08 이후 실제:

- 땅파기
- 두들기기
- 자르기/손질

등을 경험한 뒤에만 `다용도성 경험 완료`를 주장한다.

---

# 4. Terminology Reveal 규칙

좋은 방식:

- 행동 직후 1~2문장
- 같은 화면 안의 작은 cue
- 이미 경험한 대상과 바로 연결
- 다음 행동과 공존 가능

피할 방식:

- 장문의 모달
- 즉시 객관식/OX
- 모든 사물 박물관식 이름표
- 감정/위험 peak를 용어 설명이 덮음
- 같은 개념을 Scene마다 반복 설명

Terminology Reveal은 tutorial/scaffold와 다르다.

- Terminology Reveal = 이것의 역사적 이름이 무엇인지 연결
- Scaffold = 학생이 다음 행동을 이해하도록 도움

---

# 5. 거처 용어의 공식 구분

## 현재 임시 거처

Stage 07에서 학생이 처음 보는 현재 생활 공간을 가리키는 중립적 player-facing 표현.

이 표현은 해당 CSS/placeholder primitive가 최종 역사 아트로 검증되기 전에 `막집`을 섣불리 단정하는 것을 막는다.

## 막집

교과서 핵심 용어.

기본 경로:

```text
Camp에서 현재 임시 거처 생활/손질
→ 바람/덮개/재료/불편을 몸으로 경험
→ '막집' 짧은 명명
```

## 동굴 / 바위 그늘

자연 지형을 이용한 생활 공간.

기본 경로:

```text
먼저 자연 공간 발견/이용/평가
→ 장점과 불확실성 확인
→ '동굴 / 바위 그늘' 짧은 명명
```

# **막집과 동굴/바위 그늘은 경쟁 정답이 아니다.**

---

# 6. 동굴 / 바위 그늘 발견 Event

좋은 흐름:

```text
한동안 이동
→ 큰 바위 아래 어두운 공간 발견
→ 동행자 반응
→ 가까이 감
→ 입구 / 바닥 / 안쪽 / 바람 / 주변 길을 살핌
→ 비바람을 피할 가능성 파악
→ 어둠/동물 흔적/물·먹을거리 거리의 불확실성 확인
→ 생활 공간 후보로 기억
```

학생이 추론할 것:

- 비·바람을 피할 수 있는가?
- 안쪽은 충분히 넓은가?
- 너무 어둡거나 위험하지 않은가?
- 다른 동물이 이용한 흔적은 없는가?
- 물·먹을거리·귀환 길과의 관계는 어떤가?

# **동굴 = 자동 새 집이 아니다.**

---

# 7. 불

불은 설명보다 반복 경험을 우선한다.

예:

- Hunt 시작: 따뜻함/거처 anchor
- Camp: 불 유지
- 음식: 익혀 먹기
- 어둠/위험: 보호와 안정감
- 귀환: 멀리서 보이는 사람/거처 anchor

후속 개념화에서 기능을 정확한 교과 표현으로 정리한다.

---

# 8. 역할별 Anchor 분배

## Hunt

- 뗀석기 상위 개념 첫 명명
- 대표적인 예인 주먹도끼
- 이동 거리와 먹을거리 불확실성
- 동굴/바위 그늘 후보 발견 가능
- 불/거처로 귀환

## Gather

- 채집
- 풀뿌리·열매 등 먹을거리
- 땅파기/두들기기/손질 등 도구 재사용
- 가까운 자원 한계
- 공간 기억/범위 확대

## Camp

- 불 유지/조리
- 현재 임시 거처 생활/손질
- 경험 뒤 `막집` 명명
- 가죽·도구·먹을거리 손질
- 동굴 등 새 거처 후보 재평가

# **한 개념은 가능하면 두 역할 이상에서 다른 의미로 다시 만난다.**

---

# 9. 실제 유물·유적 연결

체험 자체를 특정 유적의 실제 하루라고 주장하지 않는다.

가능한 후속 구조:

```text
재구성된 1인칭 체험
→ 교과 개념 명명
→ 실제 유물/유적 증거
```

예:

- 실제 주먹도끼 유물
- 실제 동굴/구석기 유적

구체 유적명은 source 확인 뒤 사용한다.

---

# 10. Fact / Reconstruction Matrix

## Source-supported Fact

- 뗀석기 사용
- 주먹도끼의 대표성/다용도성
- 이동 생활
- 막집
- 동굴/바위 그늘 생활
- 불 이용

## Reconstructed Event

- R/H1/H2라는 인물
- 특정 아침 도구 전달
- 특정 날 자연 거처 후보 발견
- 특정 대사
- 선택에 따른 감정/결과

Player를 매번 `[재구성]` 표시로 끊지 않는다.
Teacher/Debug에서 관리 정보로 구분한다.

---

# 11. 오개념 Guardrail

Human QA에서 직접 확인한다.

학생에게 물어볼 수 있는 질문:

- 뗀석기와 주먹도끼는 완전히 같은 말일까?
- 모든 뗀석기가 주먹도끼일까?
- 주먹도끼는 사냥할 때만 쓰였을까?
- 구석기 사람들은 동굴에서만 살았을까?
- 막집에서만 살았을까?
- 동굴을 발견하면 무조건 그곳으로 옮겼을까?
- 체험 속 R/H1/H2가 실제 역사 기록에 이름이 남은 사람들일까?

목표:

- `뗀석기` 상위 개념 이해
- `주먹도끼` 대표 예 이해
- 여러 거처 형태 이해
- 사실과 재구성 구분

---

# 12. Anchor Coverage 원칙

필수 교과 개념을 특정 선택 분기 하나에만 가두지 않는다.

예: Hunt에서 동굴 후보를 못 봤다면:

- Gather에서 바위 그늘을 이용하거나
- Camp에서 다른 사람이 본 장소 이야기를 듣거나
- Common Evening/Conceptualization에서 회수

할 수 있다.

# **Narrative Variant와 Learning Invariant를 분리한다.**

---

# 13. Acceptance Gate

- 뗀석기와 주먹도끼의 위계가 정확한가?
- 명명 전에 학생이 먼저 도구를 경험하는가?
- 주먹도끼를 사냥 전용 무기로 축소하지 않는가?
- 실제 기능 사용과 단순 receive proof를 구분하는가?
- 현재 임시 거처와 `막집` 명명 시점이 구분되는가?
- 막집과 동굴/바위 그늘을 모두 생활 공간으로 다루는가?
- 동굴 발견이 탐색·판단·관계 사건인가?
- 불의 기능을 설명보다 행동으로 먼저 경험시키는가?
- 이동 생활을 거리·자원·거처 문제로 체감시키는가?
- 사실과 재구성을 구분하는가?
- 필수 개념이 선택 한 갈래에만 갇히지 않는가?
- terminology cue가 몰입을 과도하게 끊지 않는가?

이 Gate를 Stage 02 이후가 모두 보존해야 한다.
