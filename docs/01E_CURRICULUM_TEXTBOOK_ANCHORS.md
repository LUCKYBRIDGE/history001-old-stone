# 구석기 역사 체험 웹게임
## Stage 01E — Curriculum / Textbook Anchor Principles v2

> 목적: 교과서의 핵심 표현·유물·생활 요소를 체험에 분명히 연결하되, 교과서 설명이나 퀴즈가 서사를 끊지 않도록 한다. 동시에 `뗀석기 = 주먹도끼`, `구석기 집 = 동굴 하나`, `주먹도끼 = 사냥 무기` 같은 단순 오개념을 예방한다.
>
> 기준 자료: 사용자가 제공한 5학년 사회 교과서 PDF의 구석기 시대 부분(교과서 13~14쪽 / PDF 6~7쪽). 아래 내용은 해당 자료가 직접 뒷받침하는 범위와 프로젝트의 역사적 재구성을 구분한다.

# 1. Source Fidelity Matrix

## 교과서 13쪽 / PDF 6쪽이 직접 뒷받침

- 한반도와 주변 지역의 구석기 생활을 약 70만 년 전부터로 **추정**함.
- 돌을 깨뜨리거나 떼어서 만든 **뗀석기**를 주로 사용함.
- 먹을 것을 찾아 **옮겨 다님**.
- 한데에 **막집**을 짓기도 함.
- **동굴이나 바위 그늘**에서도 생활함.
- **불**을 사용하여 추위와 사나운 짐승으로부터 몸을 보호하고 음식을 익혀 먹음.
- 그림 예시로 가죽옷, 풀뿌리 두들기기, 고기 익히기 같은 생활 장면이 제시됨.

## 교과서 14쪽 / PDF 7쪽이 직접 뒷받침

- **주먹도끼**를 대표적인 구석기 유물/다용도 도구로 다룸.
- 자르기·두들기기·땅파기 등 여러 용도로 사용함.
- 전곡리에서 발견된 주먹도끼 사례를 실제 유물 연결로 제시함.

## 프로젝트가 재구성하는 것

교과서가 다음의 구체 사건까지 말하는 것은 아니다.

- R/H1/H2라는 특정 인물
- 오늘 아침 R이 플레이어에게 주먹도끼를 건넨 사건
- 사냥 중 특정 동굴 후보를 발견한 사건
- 그 장소를 보며 “머물기 괜찮겠다”고 판단한 대화
- 특정 선택 뒤 죄책감·후회·안도를 느끼는 개인 서사

이들은 위 역사 조건 안에서 가능한 삶을 체험시키기 위한 **역사적 재구성**이다.

# 2. 반드시 보존할 구석기 Curriculum Anchor

1. **뗀석기**
   - 돌을 깨뜨리거나 떼어 만든 도구라는 상위 개념.
2. **주먹도끼**
   - 대표적인 구석기 뗀석기의 한 예.
   - 자르기·두들기기·땅파기 등 여러 생활 행동과 연결.
3. **이동 생활**
   - 먹을 것을 찾아 옮겨 다니는 생활.
4. **거처의 다양성**
   - 한데의 임시적인 막집.
   - 동굴이나 바위 그늘.
5. **불의 이용**
   - 추위 대응.
   - 사나운 짐승으로부터 보호에 도움.
   - 음식 익히기.
6. **생활 속 도구와 먹을거리**
   - 사냥뿐 아니라 채집·가공도 중요함.
   - 풀뿌리 등을 두드리거나 손질하는 생활 장면 활용 가능.
7. **선사 시대라는 성격**
   - 구체 대사·하루 사건은 문자 기록으로 남은 실제 개인 서사가 아니라 증거와 조건을 바탕으로 한 재구성임을 교사/후속 개념화에서 구분.

---

# 3. 핵심 학습 흐름 — Experience → Name → Reuse → Connect

```text
먼저 만난다 / 겪는다
        ↓
짧고 정확하게 이름을 붙인다
        ↓
생활 행동 속에서 다시 사용한다
        ↓
다른 역할·후속 장면에서 의미를 넓힌다
        ↓
교과서 개념·실제 유물/유적과 연결한다
```

핵심 교과 용어를 숨기지 않는다. 하지만 용어가 경험보다 먼저 세계를 설명하지 않게 한다.

---

# 4. 뗀석기와 주먹도끼 — 반드시 계층적으로 가르친다

금지되는 표현:

> `뗀석기 · 주먹도끼`

를 아무 설명 없이 같은 급의 동의어처럼 병렬 표시하는 것.

권장되는 짧은 연결:

> **뗀석기** — 돌을 깨뜨리거나 떼어 만든 도구.
>
> **지금 손에 든 것은 그 대표적인 예인 주먹도끼다.**

즉 학생이 다음 관계를 이해해야 한다.

```text
뗀석기
└─ 대표적인 예: 주먹도끼
```

`모든 뗀석기가 주먹도끼다`라는 인상을 만들지 않는다.

또한 `주먹도끼 = 사냥 전용 무기`로 축소하지 않는다. 실제 기능적 사용은 Gather/Camp/후속 Hunt의 생활 행동에서 자르기·두들기기·땅파기 같은 다용도성으로 확장한다.

---

# 5. Terminology Reveal Budget

용어 cue가 몰입을 끊지 않도록 다음을 기본으로 한다.

- 한 순간에 핵심 개념 cue **1묶음**만 노출.
- 1~2개의 짧은 문장.
- 이미 학생이 보고/만지고/사용한 대상에만 이름을 붙임.
- 인물의 중요한 대사, 위협 peak, 감정 climax와 동시에 교과 cue를 겹치지 않음.
- 한 번 명명한 개념은 매 장면 다시 설명하지 않고 실제 사용/회수로 기억하게 함.

장문의 모달, 즉시 정답 퀴즈, 모든 사물에 상시 박물관식 라벨을 사용하지 않는다.

---

# 6. 막집과 동굴/바위 그늘의 순서

둘을 경쟁 정답으로 만들지 않는다.

중요한 오개념 방지:

- `구석기 사람은 모두 동굴에서 살았다` → 금지.
- `구석기 사람은 모두 막집에서 살았다` → 금지.
- `동굴을 발견하면 반드시 그곳으로 이사했다` → 금지.

Stage 07 Hunt Skeleton에서는 현재 공동체의 임시 거처를 먼저 **보거나 떠나는 생활 공간**으로 인식하게 한다. `막집`이라는 정확한 용어의 본격 명명은 Camp에서 생활·손질과 함께 하는 편이 자연스럽다.

따라서 Hunt의 동굴 cue에서 아직 경험하지 않은 `막집` 용어를 끌어와 비교 설명하지 않는다.

권장 동굴 cue:

> **동굴 / 바위 그늘**
>
> 구석기 사람들은 이런 자연 공간도 생활 공간으로 이용했다.

후속 Camp에서:

> **막집**
>
> 비바람을 겨우 피하도록 임시로 만든 거처.

처럼 경험 뒤 명명한다.

---

# 7. 동굴 / 바위 그늘 발견 Event 원칙

동굴 생활은 설명 카드가 아니라 장소를 발견하고 판단하는 사건으로 경험하게 할 수 있다.

```text
한동안 더 멀리 이동
→ 바위 면 아래 어두운 공간 발견
→ 가까이 감
→ 입구 / 바닥 / 안쪽 / 바람 / 주변 길을 직접 살핌
→ 동행자와 의견을 나눔
→ 생활에 쓸 수 있을 가능성을 느낌
→ 바로 새 집으로 확정하지 않음
```

살필 조건:

- 비·바람을 어느 정도 피할 수 있는가?
- 공간이 충분해 보이는가?
- 안쪽이 너무 어둡거나 위험하지 않은가?
- 다른 동물이 이용한 흔적은 없는가?
- 물·먹을거리와의 관계는 어떤가?
- 다시 찾아올 길을 기억할 수 있는가?

# **동굴 = 정답인 집이 아니다. 이동 생활 속에서 만날 수 있는 생활 공간 후보 중 하나다.**

구체적으로 “오늘 이 사람들이 이 동굴을 발견했다”는 사건은 재구성이다. Teacher/Debug surface에서는 이 사실을 구분할 수 있게 한다.

---

# 8. 역할별 Curriculum Anchor

## Hunt

- 뗀석기 / 주먹도끼 첫 만남과 정확한 계층 명명
- 도구를 몸에 지닌 상태의 continuity
- 흔적과 관찰
- 이동 거리와 먹을거리 불확실성
- 동굴·바위 그늘 후보 발견 가능성
- 불과 귀환의 의미

## Gather

- 채집
- 풀뿌리·열매 등 식량 탐색
- 주먹도끼 등 뗀석기의 두들기기/땅파기/손질 같은 생활 사용
- 가까운 자원의 한계
- 공간 기억과 이동 범위 확대

## Camp

- 불 유지
- 음식 익히기
- 임시 거처를 실제로 보고 손질한 뒤 **막집** 명명
- 가죽·도구·먹을거리 손질
- 돌아오지 않은 사람을 기다림
- Hunt가 발견한 자연 거처 후보를 다른 입장에서 평가

---

# 9. 실제 유물·유적 연결

체험 자체를 특정 유적의 실제 사건으로 단정하지 않는다.

교과서가 제시한 연결 예:

- 전곡리 주먹도끼
- 단양 금굴 유적

좋은 구조:

```text
재구성된 1인칭 체험
→ 교과 개념 명명
→ 실제 유물/유적과 연결
```

학생에게 “내가 방금 전곡리에 있었다”는 인상을 주지 않는다.

---

# 10. Misconception Guardrail

Teacher/Student QA에서 다음을 직접 확인한다.

학생이 다음처럼 이해하면 수정이 필요하다.

- “뗀석기와 주먹도끼는 같은 말이다.”
- “모든 뗀석기는 주먹도끼다.”
- “주먹도끼는 사냥할 때만 쓰는 무기다.”
- “구석기 사람들은 동굴에서만 살았다.”
- “막집이 구석기의 유일한 집이다.”
- “동굴을 찾으면 항상 그곳으로 이사했다.”
- “게임 속 R/H1/H2 사건이 실제 기록에 남은 이야기다.”

반대로 학생이 다음과 같이 말할 수 있으면 좋은 증거다.

- “돌을 깨뜨리거나 떼어 만든 도구가 뗀석기이고, 주먹도끼는 그중 대표적인 도구다.”
- “주먹도끼는 여러 일에 쓸 수 있었다.”
- “구석기 사람들은 이동하면서 임시 거처나 동굴·바위 그늘 같은 여러 공간을 이용할 수 있었다.”
- “게임 속 사건은 실제 생활 모습을 바탕으로 상상해서 만든 이야기다.”

---

# 11. Acceptance Gate

- 뗀석기와 주먹도끼의 상·하위 관계가 분명한가?
- 명명 전에 학생이 도구를 먼저 체험하는가?
- 실제 기능적 재사용은 `받기`와 별도 evidence로 구분되는가?
- 현재 임시 거처가 동굴 발견 전에 세계 안에 존재함이 느껴지는가?
- 막집과 동굴/바위 그늘을 하나의 정답 경쟁으로 만들지 않는가?
- 동굴 발견이 탐색·판단·관계 사건으로 작동하는가?
- 동굴 cue가 아직 경험하지 않은 막집 설명을 끌어오지 않는가?
- 불의 기능이 후속 역할에서 생활 행동으로 경험되는가?
- 이동 생활이 거리·자원·거처 판단으로 체감되는가?
- 사실과 재구성을 Teacher/후속 개념화에서 구분하는가?
- Terminology Reveal Budget을 지키는가?
- 오개념 QA가 Teacher/Student pilot에 포함되는가?
