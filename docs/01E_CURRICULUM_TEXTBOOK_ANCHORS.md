# 구석기 역사 체험 웹게임
## Stage 01E — Curriculum / Textbook Anchor Principles v1

> 목적: 교과서의 핵심 표현·유물·생활 요소를 체험에 분명히 연결하되, 교과서 설명이나 퀴즈가 서사를 끊지 않도록 하는 기준을 고정한다.
>
> 기준 자료: 사용자가 제공한 5학년 사회 교과서 PDF의 구석기 시대 부분(교과서 13~14쪽). 이 문서는 교과서 문장을 장문 복제하지 않고, 프로젝트 구현에 필요한 핵심 사실과 용어만 요약한다.

---

# 1. 교과서에서 반드시 보존할 구석기 핵심

현재 프로젝트의 구석기 체험에서 최소한 다음 요소는 역사적·교과 연계 핵심으로 취급한다.

1. **뗀석기**
   - 돌을 깨뜨리거나 떼어 만들어 사용한 도구.
2. **주먹도끼**
   - 대표적인 구석기 뗀석기.
   - 자르기·두들기기·땅파기 등 여러 생활 행동에 활용되는 다용도 도구로 다룬다.
3. **이동 생활**
   - 먹을 것을 찾아 옮겨 다니는 생활.
4. **거처의 다양성**
   - 한데에 임시적인 **막집**을 짓기도 함.
   - **동굴이나 바위 그늘**도 생활 공간으로 이용함.
5. **불의 이용**
   - 추위를 피함.
   - 사나운 짐승으로부터 몸을 보호하는 데 도움을 줌.
   - 음식을 익혀 먹음.
6. **생활 속 도구와 먹을거리**
   - 사냥뿐 아니라 채집과 가공이 중요함.
   - 풀뿌리 등 먹을거리를 두드리거나 손질하는 생활 장면을 활용할 수 있음.
7. **선사 시대라는 성격**
   - 문자 기록 이전의 시대이므로, 체험의 구체적 인물·대사·하루 사건은 역사적 증거를 토대로 한 재구성임을 후속 개념화에서 구분한다.

---

# 2. 핵심 원칙 — Experience → Name → Reuse → Connect

교과 개념을 다음 순서로 연결한다.

```text
1. 먼저 만난다 / 겪는다
        ↓
2. 짧게 이름을 붙인다
        ↓
3. 이후 생활 행동 속에서 다시 사용한다
        ↓
4. 체험 후 교과서 개념·유물·유적과 연결한다
```

예: 주먹도끼

```text
R이 손에 쥔 돌도구를 건넨다
→ 내 손으로 직접 받는다
→ 짧게 '뗀석기 / 주먹도끼'라고 명명
→ 이동 중 계속 손에 보인다
→ 땅파기·자르기·두들기기 중 역사적으로 타당한 행동에 사용
→ 나중에 교과서의 대표 유물 개념과 연결
```

# **핵심 교과 용어를 숨기지 않는다. 다만 용어가 경험보다 먼저 세계를 설명하지 않게 한다.**

---

# 3. Terminology Reveal 규칙

`뗀석기`, `주먹도끼`, `막집`처럼 교과서에서 학습 가치가 높은 용어는 적어도 한 번은 명확히 짚는다.

좋은 방식:

- 행동 직후 1~2문장의 짧은 이름표
- 이야기 흐름과 같은 화면 안의 작은 개념 cue
- NPC의 자연스러운 말 + 짧은 교과 용어 표기
- 후속 개념화에서 다시 정확한 용어 회수

피할 방식:

- 장문의 모달 강제
- “정답을 고르세요”식 즉시 퀴즈
- 모든 사물에 박물관식 이름표 상시 표시
- 용어 설명 때문에 인물·위험·감정이 멈추는 구성

---

# 4. Textbook Anchor와 Story의 우선순위

나쁜 순서:

```text
주먹도끼를 가르쳐야 함
→ 주먹도끼 설명 장면을 억지로 만듦
```

좋은 순서:

```text
아침에 관계를 만드는 도구 전달 장면이 필요함
→ 역사적으로 타당한 주먹도끼를 건네게 함
→ 실제 행동 속에서 의미를 갖게 함
→ 교과 용어를 짧게 명명
```

# **Textbook Anchor가 스토리를 지배하지 않는다. 좋은 역사적 상황 안에 교과서 핵심을 심는다.**

---

# 5. 동굴 / 바위 그늘 발견 Event 원칙

동굴 생활은 설명 카드가 아니라 **장소를 발견하고 판단하는 사건**으로 경험하게 할 수 있다.

예시 흐름:

```text
더 멀리 탐색
→ 바위 면 아래 어두운 공간 발견
→ 가까이 감
→ 입구 / 바닥 / 안쪽 / 바람 / 주변 길을 직접 살핌
→ 동행자와 의견을 나눔
→ '비바람을 피하기 괜찮아 보인다' 같은 생활 판단
→ 바로 새 집으로 확정하지 않음
```

학생이 자연스럽게 추론해야 할 것:

- 비·바람을 피할 수 있는가?
- 안쪽은 충분히 넓은가?
- 너무 어둡거나 위험하지 않은가?
- 다른 동물이 이용한 흔적은 없는가?
- 물·먹을거리·귀환 길과의 관계는 어떤가?

# **동굴 = 정답인 집이 아니다. 이동 생활 속에서 발견할 수 있는 생활 공간 후보 중 하나다.**

이 사건은 향후 여러 날의 생활 부담과 결합하여 `새 거처를 고려하는 이유`로 회수할 수 있다.

---

# 6. 막집과 동굴을 경쟁 정답으로 만들지 않는다

구석기 생활은 하나의 주거 형태로 고정하지 않는다.

- 현재 날의 공동체가 막집 중심 임시 거처를 사용할 수 있음.
- 다른 날 또는 이동 중 동굴·바위 그늘을 이용할 수 있음.
- 특정 장소와 환경에 따라 선택이 달라질 수 있음.

따라서 다음과 같은 단순 이분법은 피한다.

> 구석기 사람의 집은 무엇인가? 막집 vs 동굴

대신:

> 왜 이 장소가 지금 이 사람들에게 쓸 만한가?

를 경험하게 한다.

---

# 7. 역할별 Curriculum Anchor

## Hunt

필수 후보:

- 뗀석기 / 주먹도끼
- 흔적과 관찰
- 이동 거리와 먹을거리 불확실성
- 동굴·바위 그늘 발견 가능성
- 불과 귀환의 의미

## Gather

필수 후보:

- 채집
- 풀뿌리·열매 등 식량 탐색
- 뗀석기의 두들기기/땅파기 등 생활 사용
- 가까운 장소의 자원이 줄어드는 경험
- 공간 기억과 이동 범위 확대

## Camp

필수 후보:

- 불 유지
- 음식 익히기
- 임시 거처 / 막집
- 가죽·도구·먹을거리 손질
- 돌아오지 않은 사람을 기다림
- 동굴 또는 다른 거처 후보에 대한 공동체 논의

# 8. 실제 유물·유적 연결

체험 자체는 특정 유적의 사건을 그대로 재현한다고 단정하지 않는다.

예:

- 전곡리 주먹도끼
- 단양 금굴 유적

같은 실제 유물·유적은 **체험 후 연결 증거**로 활용한다.

좋은 구조:

```text
재구성된 1인칭 체험
→ 교과 개념 명명
→ 실제 유물/유적과 연결
```

학생에게 “내가 방금 전곡리에 있었다”는 식으로 오해시키지 않는다.

---

# 9. Historical Integrity 규칙

교과서가 직접 뒷받침하는 것과 프로젝트가 재구성하는 사건을 구분한다.

교과서 근거로 고정 가능한 것:

- 뗀석기 사용
- 주먹도끼의 다용도성
- 이동 생활
- 막집
- 동굴/바위 그늘 생활
- 불의 여러 기능

프로젝트가 역사적 조건 안에서 재구성하는 것:

- R/H1/H2라는 구체 인물
- 그날 동굴을 발견하는 사건
- “여기 머물기 괜찮겠다”는 대화
- 어느 날 어떤 선택을 했는지
- 감정과 관계의 구체 흐름

# **교과서 사실은 학습 불변조건으로, 구체 사건은 역사적 상상력을 위한 재구성으로 다룬다.**

---

# 10. Stage 01E Acceptance Gate

- `뗀석기`와 `주먹도끼`가 최소 한 번 명확하게 명명되는가?
- 명명 전에 학생이 먼저 도구를 실제 체험하는가?
- 이후 같은 도구가 반복적인 생활 행동 속에서 의미를 갖는가?
- `막집`과 `동굴/바위 그늘`을 둘 다 구석기 생활 공간으로 다루는가?
- 동굴 발견이 설명 문제가 아니라 탐색·판단·관계 사건이 되는가?
- 불의 기능이 설명보다 생활 행동으로 먼저 경험되는가?
- 이동 생활이 단순 문장이 아니라 거리·자원·거처 판단으로 체감되는가?
- 교과 개념이 몰입을 멈추는 장문의 설명 UI로 변질되지 않는가?
- 실제 유적/유물과 재구성 스토리를 구분하는가?

이 Gate를 Stage 02~07이 모두 보존해야 한다.
