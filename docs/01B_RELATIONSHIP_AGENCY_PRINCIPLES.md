# 구석기 역사 체험 웹게임
## Stage 01B — 관계·선택·결과 원칙 v2

> 목적: 주변 인물이 실제 사람처럼 기억되고, 위협과 고민이 `문항`이 아니라 상황으로 다가오며, 선택이 획일적 결론으로 무효화되지 않도록 한다. 동시에 관계를 죄책감·도덕 채점·숨겨진 정답으로 악용하지 않는다.
>
> 상위 기준:

> - `docs/01A_EMBODIED_FIRST_PERSON_PRINCIPLES.md`

# 1. 핵심 정의

관계는 NPC 호감도 시스템이 아니다.

# **관계 = 함께 겪은 사건을 서로 기억하고, 이후 행동·대사·시선·기다림의 의미가 달라지는 것**

선택은 정답 버튼이 아니다.

# **선택 = 관찰 가능한 여러 조건 사이에서 판단하고, 그 판단의 흔적이 이후 세계와 사람에 남는 것**

결과 구조:

# **Bounded Agency + Persistent Consequence + Reconverging Narrative**

즉 선택 범위는 통제하지만 선택의 의미는 지우지 않는다.

---

# 2. 주변 인물은 기능 카드가 아니다

각 역할에는 반복해서 만나는 소수의 사람이 필요하다.

인물은 다음으로 기억된다.

- 얼굴/목소리/자세/손짓 같은 일관된 존재
- 나와 함께 한 사건
- 나에게 한 짧은 말
- 내가 그 사람 앞에서 한 판단
- 이후의 반응

피할 것:

- `동행자 A: 신중한 성격`
- 관계 설명 카드
- 호감도/친밀도 숫자
- 정답을 대신 말하는 튜토리얼 NPC
- 언제나 현명한 인물과 언제나 무모한 인물의 고정 역할

좋은 관계는 **반복되는 상호작용과 기억**으로 만든다.

---

# 3. 관계의 최소 기능

모든 역할에서 다음 세 기능을 검토한다.

## 함께 행동하는 사람

내 판단을 보고 반응하며 노동·위험·이동을 함께 겪는다.

## 기다리거나 의존하는 사람

내가 보지 않는 곳에서도 존재하며 귀환과 결과의 의미를 만든다.

## 다른 관점에서 다시 만나는 사람

한 역할에서 보았던 사람이 다른 역할에서는 `나`가 되거나, 반대편 위치에서 같은 사건을 경험한다.

모든 역할에 정확히 세 명을 배치하라는 뜻은 아니다. **관계 기능이 살아 있어야 한다.**

---

# 4. 관계는 숫자 대신 Memory Signal

예시:

- `stayed-together-under-danger`
- `followed-companion-warning`
- `pressed-on-despite-fatigue`
- `shared-carry-burden`
- `returned-late`
- `returned-empty-handed`
- `noticed-waiting-person`

학생에게 ID를 보여주지 않는다.

이 기억은 다음을 바꿀 수 있다.

- 시선
- 짧은 대사
- 누가 먼저 행동하는가
- 누가 부담을 나누는가
- 귀환의 정서
- Perspective Bridge
- Common Evening

중요:

## **Memory Signal은 행동 평가 점수가 아니다.**

`좋음/나쁨`, `용감/겁쟁이`, `협력도` 같은 단일 가치 척도로 환산하지 않는다.

---

# 5. 관계의 정서적 안전

관계가 강할수록 학생 선택에 감정적 무게가 생긴다. 이를 조작적으로 사용하지 않는다.

금지:

- NPC가 학생을 모욕하거나 비난
- `네가 잘못해서 모두가 굶었다` 식 과도한 책임 전가
- 한 선택을 택하면 중요한 사람이 관계를 끊는 식의 처벌
- 걱정하는 사람을 반복 노출해 특정 루트를 강요
- 죄책감을 정답 유도 장치로 사용

허용:

- 걱정
- 아쉬움
- 의견 차이
- 서로 다른 우선순위
- 결과의 현실적 부담

# **관계는 판단의 무게를 만들되 학생을 처벌하지 않는다.**

---

# 6. 위협은 선택지보다 먼저 느껴져야 한다

기본 문법:

# **징후 → 다른 사람 반응 → 내 몸의 변화 → 내 관찰 → 판단**

예:

1. 평소와 다른 소리
2. 동행자가 갑자기 멈춤
3. 내 움직임도 멈춤
4. 시야 밖 수풀 움직임
5. 학생이 그 방향을 확인
6. 흔적/움직임을 이해
7. 그 뒤 행동 판단

위협을 UI 문구나 붉은 화면만으로 설명하지 않는다.

---

# 7. 위협의 강도는 초등학생 수준으로 제한

목표는 공포가 아니라 **취약함·판단·협력**이다.

허용:

- 비그래픽 긴장
- 가까운 소리/흔적/움직임
- 사람들의 조심스러운 행동 변화
- 위험에서 함께 벗어남

금지:

- 고어/그래픽 부상
- 반복 jump scare
- 적 HP/처치
- 장시간 강한 공포
- 죽음/게임오버 처벌

위협 뒤에는 짧은 recovery beat를 둔다.

---

# 8. 고민은 가치 충돌이어야 한다

좋은 딜레마에서는 선택 전에 다음이 보인다.

- 원하는 것
- 가능성
- 비용/부담
- 시간/공간 조건
- 다른 사람의 상태

Hunt 예:

- 흔적은 선명해짐
- 먹을 것은 필요함
- 해는 낮아짐
- 거처는 멀어짐
- 동행자는 지침
- 누군가는 기다림

그 뒤 여러 합리적 선택이 존재한다.

---

# 9. Choice Fairness Gate

중요한 선택은 다음을 통과한다.

- 선택 전에 필요한 정보가 관찰 가능했는가?
- 적어도 두 선택이 합리적 이유를 갖는가?
- 결과가 완전히 예측 가능할 필요는 없지만 자의적이지 않은가?
- 결과를 본 뒤 앞선 조건과 연결할 수 있는가?
- 특정 선택만 핵심 역사 콘텐츠를 독점하지 않는가?
- 특정 선택만 좋은 관계/좋은 감정 보상을 독점하지 않는가?

불확실성은 허용하지만 **무작위 처벌**은 피한다.

---

# 10. 선택 결과의 네 층

## 즉시 결과

- 사람 반응
- 위치 변화
- 정보
- 시간 경과

## 장면 후 결과

- 위험 맥락
- 피로
- 거리
- 운반 부담

## 관계 결과

- 이후 대사
- 도움/망설임
- 귀환 반응

## 통합 결과

- Perspective Bridge
- Common Evening
- 며칠 변화

모든 선택이 네 층을 다 바꿀 필요는 없다.

그러나 **즉시도 이후도 아무 차이가 없는 선택은 삭제 후보**다.

---

# 11. Learning Invariants를 분기로 잃지 않는다

Narrative Variant가 달라도 핵심 역사 학습은 보존한다.

예:

- Hunt에서 어느 경로를 선택해도 사냥의 불확실성·시간/거리 부담·공동체 귀환 의미를 경험한다.
- 학생이 특정 선택을 하지 않았다는 이유로 불 사용, 협력, 이동 생활 같은 핵심 개념에 접근하지 못하게 하지 않는다.

# **분기는 역사 사실의 잠금장치가 아니다.**

---

# 12. 획일적 결론을 피하는 방법

`성공/실패` 두 엔딩만 두지 않는다.

Hunt 예:

- 먹을 것 확보 + 비교적 일찍 귀환
- 먹을 것 확보 + 늦은 귀환
- 먹을 것 확보 + 높은 위험 노출
- 빈손 + 일찍 귀환
- 빈손 + 먼 추적
- 빈손 + 강한 협력 기억

이 상태들은 같은 거처로 돌아올 수 있다.

하지만

- 내 몸
- 들고 있는 것
- 사람 위치
- 대사
- 저녁 분위기
- 다음 관점

이 달라질 수 있다.

# **같은 장소에 도착해도 같은 의미로 끝나지 않는다.**

---

# 13. 재수렴형 서사의 이유

완전 자유분기는 개발·QA 비용을 급격히 증가시킨다.

기본 구조:

```text
공통 상황
→ 소수의 중요한 판단
→ 질적 상태/관계 기억
→ 짧은 변주
→ 큰 생활 흐름에서 재수렴
→ 이전 상태를 대사/몸/사람/다음 관점에서 회수
```

재수렴은 선택을 지우는 장치가 아니라 **개발 가능성과 의미 보존을 함께 얻는 방식**이다.

---

# 14. Perspective Recontextualization

강한 결과는 다른 관점에서 이전 선택의 반대편을 볼 때 생긴다.

예:

Hunt에서 늦게 귀환.

Camp에서는 같은 시간에

- 해가 낮아짐
- 비어 있는 자리
- 밖을 살피는 사람
- 생활을 계속 이어가야 함

을 경험한다.

목표는 `네 선택은 틀렸다`가 아니다.

# **같은 선택도 다른 사람에게 다른 의미가 있다는 것을 이해하게 하는 것**

이다.

---

# 15. Common Evening 통합

질적 신호를 아이콘/점수가 아니라 장면으로 번역한다.

예:

`returned-empty-handed`

→ 빈손 아이콘이 아니라 기다리던 사람이 내 손보다 먼저 얼굴을 봄.

`returned-late`

→ 지각 패널티가 아니라 해가 거의 진 상태와 걱정 섞인 짧은 반응.

`shared-carry-burden`

→ 협력 +1이 아니라 함께 내려놓는 행동.

---

# 16. 관계의 역사적 안전성

구체 친족/권력 구조를 근거 없이 사실처럼 단정하지 않는다.

- `엄마`, `아빠`, `족장` 같은 관계는 근거와 교육적 필요 검토 후 사용
- 초기에는 `익숙한 사람`, `함께 나가는 사람`, `기다리는 사람` 같은 기능 관계 사용 가능
- 가상 개인 관계는 내부적으로 `[재구성]`

관계가 재구성이라고 해서 약하게 만들 필요는 없다. 단, 재구성을 역사적 보편 사실로 포장하지 않는다.

---

# 17. 기술적 Guardrail

과설계하지 않는다.

- 범용 NPC AI 금지
- 복잡한 호감도 경제 금지
- 대규모 대화 트리 금지
- 무한 분기 금지
- 절차 생성 서사 금지

초기 구현은 **작은 질적 상태 + 명시적 변주 + 테스트 가능한 규칙**으로 충분하다.

---

# 18. Acceptance Gate

- 기억되는 주변 인물이 최소 1~2명 있는가?
- 그 인물이 내 행동에 반응하는가?
- 관계가 죄책감/도덕 채점으로 작동하지 않는가?
- 위협이 UI 설명보다 먼저 상황으로 느껴지는가?
- 위협 강도가 초등학생에게 적절한가?
- 주요 고민에 실제 장단점이 존재하는가?
- 학생에게 선택에 필요한 정보가 사전에 제공되는가?
- 선택 결과가 이후 최소 한 번 회수되는가?
- 같은 큰 결론으로 가도 의미 차이가 남는가?
- 모든 경로에서 Learning Invariants가 유지되는가?
- 이전 역할의 행동을 다음 관점에서 비난 없이 재해석할 수 있는가?
- 점수/호감도 숫자 없이 관계 변화가 느껴지는가?

이 Gate를 통과하지 못하면 `Immersion Complete`가 아니다.
