# 1. 몰입의 정의

몰입은 예쁜 그림, 긴 스토리, 효과의 양이 아니다.

# **학생이 UI를 해석하는 대신, 자기 몸이 있는 상황 속에서 사람과 환경을 보고 판단하면서도 무엇을 배워야 하는지 놓치지 않는 상태**

다.

내적 질문이

> `다음 버튼이 뭐지?`

보다

> **`지금 나는 무엇을 보고 어떻게 해야 하지?`**

에 가까워야 한다.

---

# 2. 장면 제작 순서

모든 주요 장면은 다음 순서로 설계한다.

1. **Learning Evidence** — 이 장면에서 역사 이해에 남길 것은 무엇인가?
2. **Situation** — 어디/언제/무슨 상태인가?
3. **Primary Attention Target** — 무엇을 가장 먼저 봐야 하는가?
4. **Body / Actor** — 내 몸과 사람이 어떻게 존재하는가?
5. **Action / Decision** — 학생이 무엇을 직접 하는가?
6. **Response / Consequence** — 세계와 사람이 어떻게 반응하는가?
7. **Treatment** — 필요한 최소 색/초점/움직임은 무엇인가?
8. **Scaffold Fallback** — 학생이 못 찾으면 어떻게 돕는가?
9. **Callback** — 뒤에서 무엇을 다시 회수하는가?
10. **Safety / Accessibility** — 효과·위협·조작에 장벽은 없는가?

효과나 대사를 먼저 만들고 의미를 나중에 붙이지 않는다.

---

# 3. Opening Gate

첫 20~30초 안에:

- 내 몸 일부
- 구체 장소
- 가까운 사람
- 첫 직접 행동
- 생활 문제 신호

이 존재한다.

동시에 첫 행동을 학생이 지나치게 헤매면 안 된다.

피할 것:

- 학습목표 화면
- 역할 메뉴
- 긴 시대 설명
- Stage/Version
- 아무 cue 없는 숨겨진 hotspot

---

# 4. Body Gate

몸은 자세와 행동에 맞게 보인다.

- 불: 손/무릎
- 걷기: 팔/도구
- 흔적: 손/무릎/지면
- 위험: 정지/낮은 자세
- 운반: 양손/부담
- 귀환: 피로한 자세

고정 손 PNG를 모든 장면에 붙이지 않는다.

몸이 안 보이는 순간도 자연스러우면 허용한다.

몸 외형이 성별·연령 역할 고정관념을 만들지 않는지 검토한다.

---

# 5. Relationship Gate

최소 한 명의 사람이:

- 처음 만난 뒤 다시 등장
- 시선/물건/행동을 직접 주고받음
- 학생 행동에 반응
- 뒤에서 기억이 회수됨

관계는 숫자가 아니다.

또한 관계를 이용해 학생에게 죄책감이나 도덕적 정답을 강요하지 않는다.

---

# 6. Clarity Gate

학생은 다음을 알 수 있어야 한다.

- 어디에 있는가
- 무엇을 살펴볼 수 있는가
- 왜 행동할 이유가 있는가

지원 순서:

1. actor/environment cue
2. 은은한 visual cue
3. 짧은 행동 문구
4. 반복 막힘 시 명확한 hint

Diegetic 우선이지만 이해 불가능한 diegetic UI보다 최소한의 명확한 UI가 낫다.

---

# 7. Primary Attention Gate

한 장면에는 가장 중요한 시선 목표가 하나 있어야 한다.

예:

- 상대 손 → 도구 → 내 손
- 지면의 흔적
- 멈춘 동행자 → 이상한 방향
- 먼 불빛

몸·대사·사운드·screen effect가 서로 다른 곳으로 주의를 빼앗지 않는다.

---

# 8. Dilemma Gate

선택지 표시 전에 학생이 볼 수 있어야 한다.

- 원하는 것
- 얻을 가능성
- 비용/부담
- 시간/공간 조건
- 다른 사람의 상태

좋은 선택은 선택지만 읽어도 되는 것이 아니라 **상황을 봐야 판단할 수 있는 것**이다.

---

# 9. Choice Fairness Gate

- 필요한 정보가 사전에 관찰 가능함
- 적어도 두 선택이 합리적임
- 결과가 자의적이지 않음
- 특정 선택만 핵심 콘텐츠를 독점하지 않음
- 특정 선택만 긍정적 관계를 독점하지 않음
- 불확실성은 있어도 무작위 처벌은 없음

---

# 10. Threat Gate

기본 문법:

# **징후 → 사람 반응 → 몸 반응 → 관찰 → 판단 → recovery**

위험 UI나 red flash가 먼저 나오지 않는다.

초등학생용 상한:

- 비그래픽 긴장
- 전투/처치 없음
- 고어 없음
- 반복 jump scare 없음
- 장시간 공포 없음

위협 뒤 recovery beat를 둔다.

---

# 11. Consequence Gate

중요한 선택은 다음 중 하나 이상을 바꾼다.

- 사람 반응
- 관계 기억
- 시간
- 거리
- 몸 상태
- 보는 정보
- 위험 맥락
- 귀환 장면
- 다음 관점

선택 직후도 뒤에서도 아무 차이가 없다면 삭제 후보다.

---

# 12. Learning Invariant Gate

Narrative Variant가 달라도 핵심 역사 학습은 유지한다.

분기는

- 누가 말하는지
- 언제 돌아오는지
- 몸이 얼마나 피곤한지
- 무엇을 들고 있는지
- 관계 반응

을 바꿀 수 있다.

하지만 학생이 선택 하나 때문에 핵심 역사 개념 전체를 보지 못하게 하지 않는다.

---

# 13. Reconvergence Gate

큰 플롯은 다시 만날 수 있다.

그러나 재수렴 뒤에도 최소 하나 이상의 의미 차이를 남긴다.

- 사람 위치
- 대사
- 몸 상태
- 물건
- 감정 beat
- 다음 관점 callback

모두 같아지면 선택이 무효화된다.

---

# 14. Perspective Recontextualization Gate

역할 전환은 같은 하루의 반대편을 보여준다.

관점 전환 anchor:

- 같은 사람
- 같은 불/물건
- 같은 대사/소리
- 같은 사건의 반대편
- 달라진 손/몸

학생이 혼란스러우면 짧은 orientation 허용.

> 같은 아침. 이번에는 불 옆이다.

몰입보다 이해가 우선이다.

---

# 15. Screen Treatment Gate

기본 순서:

# **World/Actor → Body → Treatment**

허용:

- 따뜻한 색온도
- 시간대 명암 변화
- 약한 focus
- 미세 sway
- 제한적 blink/fade

금지:

- HP식 red flash
- 반복 flashing
- 강한 지속 shake/blur/zoom
- 모든 장면 효과 겹침

기본 intensity:

- none
- subtle
- accent

Reduced effects에서도 같은 정보와 진행이 유지된다.

---

# 16. 문장/대사 원칙

우선순위:

1. 시야에 보이는 것
2. 사람이 할 법한 짧은 말
3. 학생 행동
4. 필요한 최소 내레이션
5. 체험 뒤 개념화

NPC 대사는 정답 해설이 아니다.

대사의 역할:

- 관계
- 의도
- 망설임
- 안도
- 다른 판단

---

# 17. 역사 정확성

관계·대사·구체 사건은 `[재구성]`일 수 있다.

근거 없이 고정하지 않는다.

- 친족 구조
- 성별 역할
- 지도자 체계
- 특정 동물/식생
- 의복 세부

Teacher/Concept Bridge에서 `아는 것 / 재구성한 것 / 게임화한 것`을 구분 가능하게 한다.

---

# 18. 역할별 몰입 차이

## Hunt

멀어짐 / 추적 / 위험 / 귀환.

## Gather

가까운 관찰 / 손 / 장소 기억 / 범위 확대.

## Camp

같은 장소 / 불 / 생활 / 빈자리 / 시간 / 재회.

1인칭이라는 이유로 같은 레이아웃을 복제하지 않는다.

---

# 19. Reflection Gate

몰입 뒤 짧은 reflection이 필요하다.

질문은 자기 경험을 근거로 한다.

예:

- 왜 돌아갈지 고민했어?
- 다른 사람 입장에서 보니 무엇이 달랐어?
- 왜 여러 역할이 필요했을까?

그 뒤 역사 개념을 연결한다.

# **Experience → Reflection → Historical Concept**

---

# 20. Teacher / Classroom Gate

- 안정된 checkpoint
- 재시작 가능
- reduced effects 가능
- 학생 막힘 확인 가능
- 학생별 다른 경로여도 공통 토론 가능한 Learning Invariants

Teacher/Debug UI는 player 화면과 분리한다.

---

# 21. QA 질문

교사/학생 플레이 후 확인한다.

- 첫 행동을 이해했는가?
- 화면 속에 내가 있다는 느낌이 있었는가?
- 몸이 자연스러웠는가?
- 기억나는 사람이 있는가?
- 그 사람이 내 행동에 반응한다고 느꼈는가?
- 선택 전에 실제로 고민했는가?
- 선택에 필요한 정보가 충분했는가?
- 위험이 글보다 상황으로 느껴졌는가?
- 위험이 과하지 않았는가?
- 내 선택 때문에 뒤가 달라졌다고 느꼈는가?
- 다른 몸으로 바뀐 이유를 이해했는가?
- 효과가 불편하거나 과하지 않았는가?
- 체험 뒤 역사 이유를 자기 경험으로 설명했는가?

---

# 22. Immersion Complete 판정

기능이 정상이어도 다음이면 완료가 아니다.

- 몸이 장식처럼 보임
- NPC가 안내자일 뿐임
- 학생이 첫 행동을 못 찾음
- 선택지가 상황보다 먼저 나옴
- 숨겨진 정답 루트가 있음
- 위험이 경고 UI/효과로만 전달됨
- 선택이 뒤에서 기억되지 않음
- 역할 전환이 혼란스럽거나 메뉴처럼 보임
- 모든 경로가 같은 의미로 끝남
- 효과를 줄이면 정보가 사라짐
- Reflection 없이 몰입만 끝남

Immersion Complete는 교사/학생 플레이 관찰로 판정한다.
