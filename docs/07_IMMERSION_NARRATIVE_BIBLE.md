# 구석기 역사 체험 웹게임
## 몰입·내러티브 설계 바이블 v1

> 문서 목적: 이 프로젝트의 모든 공통 장면과 역할별 STORY / PLAYFLOW / UI / 사운드 / 시각 자산이 학생을 `설명을 읽는 관찰자`가 아니라 `그 공동체의 하루를 살아보는 사람`으로 만들도록 공통 몰입 원칙을 고정한다.
>
> 적용 범위: 공통 아침, Hunt / Gather / Camp, Perspective Bridge, 공통 저녁, 며칠 변화, 이동, 새 거처, 최종 역사 개념화.
>
> 상위 기준: `docs/01_PROJECT_CORE.md`, `docs/02_EXPERIENCE_STRUCTURE.md`.

# 1. 최상위 목표

이 프로젝트의 몰입 목표는 화려한 그래픽이 아니다.

## **학생이 잠시라도 `구석기 시대를 공부하는 나`보다 `지금 이 공동체의 한 사람인 나`로 사고하고 행동하게 만드는 것**

이다.

학생이 시작 20~30초 안에 최소한 다음을 느껴야 한다.

- 나는 이미 어떤 장소 안에 있다.
- 내 주변에 함께 살아가는 사람들이 있다.
- 지금 해결해야 할 생활 문제가 있다.
- 내 손과 몸으로 무엇인가 해야 한다.
- 내가 하는 일은 다른 사람들의 하루와 연결되어 있다.

이를 **Role Embodiment Gate**라고 한다.

---

# 2. 몰입의 8개 층

## 2-1. 즉시 상황 진입

설명 화면 → 역할 선택 → 튜토리얼 → 시작 순서보다, 가능한 한 **상황 속에서 시작**한다.

좋은 시작:

- 날이 밝기 직전의 어둠
- 남은 불
- 차가운 공기
- 부족한 먹을거리
- 일어나는 사람들
- 누군가가 건네는 도구
- 나에게 직접 건네는 한마디

학생이 먼저 경험하고, 필요한 정보는 이후 행동 속에서 이해한다.

금지에 가까운 시작:

- `구석기 시대에 오신 것을 환영합니다.`
- `오늘의 학습목표`
- `당신의 역할은 사냥꾼입니다.`
- 장문의 시대 설명
- Stage 번호 / Vertical Slice / RoleEntry 같은 개발 메타 정보 노출

---

## 2-2. 몸과 감각

플레이어가 화면 밖의 마우스 사용자로만 남지 않게 한다.

활용 가능한 감각 앵커:

- 손에 쥔 돌의 거친 느낌
- 새벽 공기의 차가움
- 불 가까이의 따뜻함
- 발밑 흙과 풀
- 먼 곳의 소리
- 오래 걸은 뒤의 피로
- 해의 위치와 밝기

모든 장면에 감각 문장을 넣지는 않는다. **장면 전환과 감정 변화가 필요한 순간**에 짧게 사용한다.

---

## 2-3. 관계

몰입은 `내가 누구인가`뿐 아니라 `누구와 함께 있는가`에서 강해진다.

각 역할에는 최소한 다음 관계가 살아 있어야 한다.

- 함께 행동하는 사람
- 내가 돌아오기를 기다리거나 내 결과에 영향을 받는 사람
- 내가 직접 보지 못하는 다른 역할의 사람

관계는 인물 소개 카드로 외우게 하지 않는다. 행동과 짧은 대사로 드러낸다.

예:

> “같이 가자.”

> “저쪽은 내가 볼게.”

> “해가 지기 전에 돌아와.”

---

## 2-4. 개인적 필요와 즉각적 이유

학생에게 `임무를 수행하라`고 지시하기보다 **왜 지금 행동해야 하는지**를 생활 속에서 느끼게 한다.

- 먹을 것이 충분하지 않다.
- 불을 계속 살려야 한다.
- 밖에 나간 사람들이 돌아오지 않았다.
- 해가 낮아지고 있다.
- 주변에서 이전처럼 쉽게 먹을 것을 찾기 어렵다.

목표는 UI 퀘스트 문구보다 상황에서 먼저 발생해야 한다.

---

## 2-5. 행동으로 드러나는 정보

역사 정보는 가능한 한 다음 순서로 전달한다.

## **행동 → 결과/감각 → 짧은 해석 → 필요 시 개념화**

예:

`사냥감이 안 보임 → 흔적을 찾음 → 시간이 흐름 → 사냥은 찾는 일부터 시작된다는 이해`

설명문을 먼저 읽고 정답을 클릭하는 구조를 피한다.

교육적 설명이 필요한 경우에도 플레이 도중 긴 강의를 삽입하지 않는다. 최종 개념화 단계에서 학생이 경험한 사건을 교과 개념과 연결한다.

---

## 2-6. 선택의 결과감

선택은 정답 문제가 아니라 **내 판단이 세계의 다음 상태를 바꾸는 행위**처럼 느껴져야 한다.

좋은 선택은 다음 중 하나 이상을 바꾼다.

- 시간
- 거리
- 내가 보는 정보
- 동행자의 반응
- 위험의 형태
- 이후 대사의 의미
- 결과의 질적 상태

선택 직후 아무 변화가 없으면 선택의 존재 이유를 재검토한다.

단, 결과감 ≠ 점수화다.

---

## 2-7. 시간·공간의 연속성

장면이 카드 묶음처럼 분절되면 몰입이 깨진다.

따라서 다음이 이어져야 한다.

- 거처의 불빛이 멀어짐 / 다시 보임
- 해의 위치 변화
- 걸어온 거리
- 앞에서 본 자연 단서
- 동행자의 상태
- 앞에서 들은 말

특히 `출발한 곳`과 `돌아갈 곳`이 같은 공간이라는 감각이 중요하다.

---

## 2-8. 감정의 회수

강한 몰입은 사건을 추가하는 것보다 **앞에서 심은 의미를 뒤에서 회수**할 때 생긴다.

대표 모티프:

> **“해가 지기 전에 돌아와.”**

아침: 가벼운 당부 / 기대

귀환: 시간 압박 / 기다리는 사람 / 공동체

같은 불:

아침: 일상의 배경

저녁: 돌아갈 장소 / 안도

이러한 `motif callback`을 각 역할에 설계한다.

# 3. 서사 강화 원칙

## 3-1. Plot은 사건 목록이 아니라 욕구와 변화의 연결이다

모든 역할 STORY는 최소한 다음을 가진다.

1. **내가 지금 원하는 것**
2. **왜 필요한가**
3. **처음 예상과 다른 어려움**
4. **판단을 요구하는 변화**
5. **내 행동의 질적 결과**
6. **공동체로의 연결**
7. **다음 관점/며칠 변화로 남는 질문**

---

## 3-2. 역할마다 고유한 Dramatic Question을 둔다

- Hunt: **오늘 먹을 것을 구하고 무사히 돌아갈 수 있을까?**
- Gather: **오늘 주변에서 필요한 먹을 것을 찾을 수 있을까, 얼마나 멀리 가야 할까?**
- Camp: **밖에 나간 사람들이 돌아올 때까지 이곳의 하루를 어떻게 이어갈까?**

공통 저녁 이후:

- **이곳에서 우리는 계속 살아갈 수 있을까?**

---

## 3-3. 플레이어는 특별한 영웅이 아니다

학생을 `선택받은 영웅`으로 만들지 않는다.

학생은 공동체의 한 사람이다.

그렇기 때문에 몰입의 힘은 `세상을 구하는 나`가 아니라

## **내가 한 작은 일이 다른 사람들의 삶과 연결되는 경험**

에서 나온다.

---

# 4. 문장·대사 원칙

학생 화면에서는 다음 우선순위를 따른다.

1. 짧은 현재형
2. 몸과 주변에서 시작
3. 설명보다 관찰 가능 사실
4. 사람이 말할 법한 대사
5. 한 화면 한 감정/한 행동

예:

나쁨:

> 구석기 시대 사람들은 식량을 구하기 위해 사냥을 했으며 사냥에는 많은 위험이 따랐습니다.

좋음:

> 아무것도 보이지 않는다.
>
> 옆 사람이 땅을 가리킨다.
>
> “여기, 방금 지나간 흔적일까?”

교과 개념은 체험 뒤에 연결한다.

# 5. UI 몰입 원칙

## Player-facing UI

학생에게 보여야 하는 것:

- 세계 안의 상황
- 관찰 대상
- 현재 판단에 필요한 정보
- 자연스러운 행동 문구
- 최소한의 진행 신호

## Development UI

학생 체험에서 숨겨야 하는 것:

- Stage 08-B
- Vertical Slice
- role id
- state key
- debug label
- test route
- 내부 signal

필요하면 개발 모드에서만 표시한다.

## Diegetic 우선, 과잉 금지

모든 UI를 세계 안 물체로 위장할 필요는 없다. 초등학생이 이해하기 어려워지면 실패다.

목표는 **UI가 사라지는 것**이 아니라 **UI가 세계를 방해하지 않는 것**이다.

# 6. 상호작용 몰입 원칙

다음은 우선 고려한다.

- 직접 주변을 눌러 살피기
- 짧은 드래그/홀드가 실제 행동 의미를 가질 때 사용
- 소리의 방향이나 변화에 주의하기
- 앞에서 본 단서를 뒤에서 다시 사용하기
- 동행자의 움직임과 내 선택을 연결하기

금지:

- 의미 없는 클릭 수 늘리기
- 반응속도 게임으로 역사 경험 대체
- 정답 버튼 찾기
- 점수/콤보/별로 참여를 강제
- 실패하면 콘텐츠를 못 보게 하는 구조

# 7. 사운드와 시각의 역할

최종 아트/사운드는 몰입의 **증폭기**다. 몰입의 기초를 대신하지 않는다.

## 사운드 우선순위

1. 공간을 느끼게 하는 앰비언스
2. 행동 피드백
3. 중요한 관계 대사
4. 위험 신호
5. 감정 음악

음악이 모든 장면을 감정적으로 지시하지 않도록 한다.

## 시각 우선순위

1. 플레이어가 어디에 있는지 알 수 있는 공간
2. 시간/거리 변화
3. 사람들의 존재
4. 상호작용 가능한 자연 단서
5. 감정 변화에 필요한 구도

`예쁜 배경`보다 **행동과 이야기의 정보를 가진 장면**을 우선한다.

---

# 8. 역사 정확성과 몰입의 관계

몰입을 위해 사실을 꾸며내는 방향으로 가지 않는다.

내부 태그:

- `[교과서]` 직접 확인되는 생활 사실
- `[재구성]` 사실과 충돌하지 않는 가상의 하루/인물/사건
- `[게임]` 체험을 위한 상호작용

구체 동물 종, 의복, 거처, 도구, 식생, 계절 등 시각적으로 강한 세부는 역사 검토 후 확정한다.

불확실한 세부를 `사실`처럼 설명하지 않는다.

---

# 9. 몰입을 깨는 대표 안티패턴

- 시작 전에 학습목표를 길게 설명
- `역할을 선택했습니다` 같은 메타 문장
- 모든 화면에 제목 + 설명 + 다음 버튼 반복
- 선택했는데 장면 변화가 거의 없음
- NPC가 정답을 대신 설명
- 감정이 생기기 전에 해설로 의미를 말해버림
- 개발용 상태/Stage 노출
- 성공 화면을 크게 축하하고 빈손을 실패처럼 처리
- 이미지만 사실적이고 행동은 퀴즈형
- 역할마다 동일한 UI/루프를 복제

# 10. Immersion Acceptance Criteria

각 역할 Vertical Slice는 기능 테스트뿐 아니라 다음을 통과해야 한다.

## Opening Gate

- 시작 20~30초 안에 장소·사람·문제·첫 행동이 모두 드러난다.
- 학생에게 역할 정의를 설명하지 않아도 `내가 무엇을 하는 사람인지` 짐작 가능하다.
- 개발 메타 정보가 Player-facing 화면에 없다.

## Embodiment Gate

- 최소 2개의 몸/감각 앵커가 장면 전환과 연결된다.
- 첫 30초 안에 플레이어가 직접 하는 의미 있는 행동이 있다.

## Relationship Gate

- 적어도 한 명과의 관계가 행동/대사로 형성된다.
- 역할 결과가 다른 사람과 연결된다는 장면이 존재한다.

## Continuity Gate

- 시간, 거리 또는 공간의 변화가 체감된다.
- 앞에서 본/들은 요소가 뒤에서 최소 한 번 의미 있게 회수된다.

## Learning Gate

- 핵심 역사 이해가 설명을 읽어서만 생기지 않는다.
- 플레이 경험을 근거로 학생이 `왜 그랬을까`를 말할 수 있어야 한다.

---

# 11. 플레이테스트 질문

학생/교사에게 단순히 `재미있었나요?`만 묻지 않는다.

핵심 질문:

- 시작 후 언제부터 `게임을 하는 나`보다 `그 상황의 나`에 가까워졌는가?
- 내가 누구인지 설명 없이 알 수 있었는가?
- 주변 사람 중 기억나는 사람이 있는가? 왜 기억나는가?
- 내 선택 때문에 실제로 달라졌다고 느낀 것은 무엇인가?
- 가장 멀리 와 있다고 느낀 순간은 언제인가?
- 불빛을 다시 봤을 때 어떤 느낌이었는가?
- 빈손으로 돌아와도 이야기가 계속된다고 느꼈는가?
- 어떤 문장이나 UI가 갑자기 게임 밖으로 끌어냈는가?

---

# 12. 개발 단계 적용 규칙

앞으로 모든 역할은 다음 순서를 통과한다.

## **Historical Core → Role Identity → Story → Immersion Script → PLAYFLOW → Functional Prototype → Teacher Immersion Test → Student Test → Final Art/Sound → Final QA**

`STORY → 바로 코드`로 가지 않는다.

STORY와 PLAYFLOW 사이에 **Immersion Script**를 둔다.

Immersion Script는 다음을 장면마다 지정한다.

- 플레이어가 어디에 있는가
- 무엇을 보고/듣고/느끼는가
- 누가 함께 있는가
- 지금 원하는 것은 무엇인가
- 플레이어가 직접 무엇을 하는가
- 앞선 장면의 무엇이 이어지는가
- 이 장면이 끝났을 때 감정/이해가 어떻게 변하는가

---

# 13. 최종 판단

이 프로젝트에서 몰입은 장식이 아니다.

## **몰입은 학생이 역사적 생활 조건을 자기 행동의 이유로 이해하게 만드는 학습 장치다.**

따라서 기능이 정상 작동하더라도 역할 빙의가 약하고, 장면이 설명 카드처럼 느껴지고, 사람과 장소가 기억되지 않는다면 해당 Vertical Slice는 완성으로 판정하지 않는다.
