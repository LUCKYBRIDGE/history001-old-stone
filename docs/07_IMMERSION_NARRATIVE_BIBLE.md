# 1. 장면을 만드는 순서

```text
Historical / Curriculum Fact
→ Dramatic Need
→ Embodied Situation
→ Person / Relationship
→ World / Person Action
→ Player Perception
→ Direct Player Action
→ World / Person Response
→ Memory
→ Terminology Reveal (필요할 때)
→ Reuse / Consequence
→ Callback / Concept Connection
```

예: 도구

```text
Fact: 뗀석기 사용 / 주먹도끼는 대표적인 구체 예
→ Dramatic Need: 익숙한 사람과의 도구 전달
→ Person Action: 상대가 돌의 잡는 면/날을 한번 보고 내 쪽으로 내밈
→ Embodied: 상대의 손 + 돌도구 + 내 손
→ Action: 받는다
→ World Response: 같은 도구가 내 손에 남음
→ Memory: 누가 어떤 상황에서 건넸는지 남음
→ Name: '뗀석기' 상위 개념 + '주먹도끼' 대표 예
→ Reuse: Stage 08 이후 실제 생활 행동
→ Callback: 귀환 / 다른 관점 / 실제 유물 연결
```

# **교과 내용은 장면 위에 붙이는 스티커가 아니라 장면의 물리적·사회적 재료가 되어야 한다.**

# 2. 몰입의 15개 층

1. **Role Embodiment** — 지금 누구의 몸인지 제목으로 설명받는 것이 아니라 몸·감각·행동·기억으로 느끼는가.
2. **Sensory Presence** — 무엇을 보고 듣고 느끼는가.
3. **Body Continuity** — 손/팔/도구가 같은 몸으로 이어지는가.
4. **Spatial Continuity** — 장소가 서로 이어지는가.
5. **Relationship Presence** — 사람이 기능 버튼이 아니라 실제 존재인가.
6. **Social Continuity** — 이 사람들과 오늘 이전에도 살아왔다는 느낌이 있는가.
7. **World Independence** — 내가 보고 있지 않아도 사람들이 자기 일을 하고 있을 것 같은가.
8. **Need / Desire** — 왜 행동해야 하는가.
9. **Uncertainty** — 결과를 미리 모르는가.
10. **Limited Knowledge** — 이 몸이 실제로 알 수 있는 것만 아는가.
11. **Meaningful Choice** — 상황을 보고 판단하는가.
12. **Persistent Consequence** — 행동과 shared memory가 뒤에 남는가.
13. **Emotional Reality** — 공포·후회·죄책감·안도 등이 상황에서 생기는가.
14. **Perceptual Treatment** — 색·명암·focus·motion이 사건을 증폭하는가.
15. **Curriculum Recognition** — 이미 겪은 것에 정확한 역사 용어가 붙는가.

어느 하나가 다른 것을 압도하면 실패할 수 있다.

# 3. 첫 20~30초

학생은 첫 20~30초 안에:

- 역할명을 읽지 않아도 지금 이 몸이 놓인 상황
- 내 몸이 있다는 것
- 가까운 사람이 있다는 것
- 사람들이 이미 자기 생활을 하고 있다는 것
- 생활 공간 안에 있다는 것
- 첫 행동이 무엇인지

를 느껴야 한다.

권장:

```text
검은/어두운 시야
→ 불 냄새·장작 소리·발소리
→ Player에게 정보를 주기 위한 것이 아닌 짧은 사람들 대화
→ 눈을 뜸
→ 모두가 나를 바라보지 않음
→ 일부 사람은 계속 자기 일을 함
→ 한 사람과만 자연스럽게 시선/행동이 연결됨
```

피할 것:

- `사냥을 나선 사람의 관점`처럼 역할을 먼저 선언하는 제목
- 학습 목표 목록
- 긴 시대 설명
- 유물 목록 먼저 제시
- Stage/Prototype 메타데이터
- Player가 나타나자 모든 NPC가 멈추고 동시에 바라보는 연출

# **첫 장면의 목표는 세계를 소개하는 것이 아니라, 이미 진행 중이던 삶 속에서 눈을 뜨게 하는 것이다.**

# 4. Terminology Reveal

# **Experience before Explanation. Naming before Testing.**

좋은 도구 reveal:

> **뗀석기**  
> 돌을 깨뜨리거나 떼어 만든 도구를 뗀석기라고 한다. 지금 손에 든 것은 그 대표적인 예인 **주먹도끼**다.

특징:

- 1~2문장
- 화면 전체를 막지 않음
- 이미 경험한 대상과 연결
- 다음 행동과 공존
- 감정/위협 peak와 겹치지 않음
- 직전 사람/행동의 기억을 지우지 않음

나쁜 reveal:

- 장문의 설명 modal
- 즉시 객관식/OX
- 모든 장면 용어 카드화
- `뗀석기 · 주먹도끼`만 병렬 제목으로 제시하고 관계를 생략
- 개념 카드가 도구를 건넨 사람과 contact 장면보다 더 강한 Primary Attention이 됨

---

# 5. 유물은 생활 물건이자 관계 기억이 될 수 있다

```text
누군가의 손에서 처음 봄
→ 받음
→ 이름을 알게 됨
→ 손에 계속 있음
→ 실제 행동에 사용
→ 건네준 사람/다른 사람이 다시 봄
→ 실제 유물/교과 개념과 연결
```

Stage 07의 receive/naming proof를 실제 다용도 사용 완료로 과장하지 않는다.

주먹도끼를 `교과 유물 아이템`보다 **오늘 누군가가 내 손에 쥐여 준 생활 물건**으로 먼저 느끼게 한다.

---

# 6. 사람과 관계가 개념을 세계 안에 놓는다

좋은 예:

- 익숙한 사람이 돌도구를 건넴.
- 같이 걷던 사람이 위험 앞에서 갑자기 가까워짐.
- 앞서 가던 사람이 멈추고 먼 곳을 봄.
- Camp 인물이 현재 임시 거처를 직접 손질함.

나쁜 예:

- NPC가 교과서 문단을 암송.
- 한 사람이 항상 정답을 알려줌.
- `도구를 건네는 사람`, `관찰하는 사람`처럼 기능 자체를 character description으로 사용.

사람은 설명자보다 함께 살아가는 사람이어야 한다.

## 6.1 Player-facing Character Writing Invariant

`R`, `H1`, `H2`, `Camp`와 각 인물의 기능은 **제작자용 authoring metadata**다.
Player가 읽어야 하는 캐릭터 소개가 아니다.

Player-facing 문장은 다음을 금지한다.

- `사냥을 나선 사람의 관점`
- `도구를 건넨 사람의 관점`
- `함께 나가는 사람`
- `주변을 살피는 사람`
- `기다리는 사람`
- 인물을 기능으로 먼저 정의한 뒤 그 기능을 따라 읽게 하는 서술

같은 정보가 필요하면 역할명이 아니라 **이름·현재 지각 가능한 단서·shared event·callback**으로 전달한다.

# **역할은 내부 설계에 존재해도 되지만, Player는 역할을 읽는 것이 아니라 사람과 사건을 기억해야 한다.**

## 6.2 이름은 라벨이 아니라 기억의 고리다

핵심 반복 인물에게 fictional Player-facing name을 사용할 수 있다.

좋은 이름 노출:

```text
다른 사람이 짧게 이름을 부름
→ 해당 인물이 고개를 돌림
→ 이후 같은 이름/목소리/몸짓이 반복됨
```

피할 것:

```text
[이름]
도구 담당 / 관찰 담당 / 동행자
```

이름을 처음부터 반드시 외워야 진행되는 구조도 피한다.

학생이 이름을 놓쳐도 몸·위치·목소리·shared event로 사람을 따라갈 수 있어야 한다.

## 6.3 한국어 대사는 의미 번역이다

게임의 한국어 대사는 실제 선사 언어를 복원한 것이 아니다.

# **알 수 없는 당시 구체 언어의 의미를 학생이 이해할 수 있도록 현대 한국어로 번역해 보여준다.**

피할 것:

- `우가! 우우! (같이 가자)` 같은 원시인 caricature
- 괴성/단순 음절을 실제 선사 언어처럼 취급
- 서로 이미 아는 정보를 설명하기 위한 긴 현대식 exposition dialogue

권장 대사는 짧고 상황 의존적이다.

> `가자.`

> `잠깐.`

> `저기.`

> `늦어.`

> `왔네.`

## 6.4 성격은 반복 행동으로 느끼게 한다

Player에게:

- `다정한 사람`
- `용감한 사람`
- `신중한 사람`
- `관찰력이 좋은 사람`

이라고 설명하지 않는다.

대신:

- 걱정할수록 말이 짧아짐
- 먼저 걸어도 내가 늦으면 기다림
- 대화 중 시선이 다른 곳으로 빠짐
- 위험 때 말없이 가까워짐

같은 habit을 여러 장면에서 반복한다.

# **학생이 성격을 추론할 여지를 남긴다.**

## 6.5 NPC Autonomy

사람은 Player를 위해서만 행동하지 않는다.

- NPC끼리 대화 가능
- Player에게 정보가 되지 않는 짧은 대화도 가능
- Player가 눈을 뜨기 전 행동 가능
- Player가 오더라도 하던 일을 계속할 수 있음
- 모든 사람이 Player를 바라볼 필요 없음
- background actor는 이름 없이도 생활 행동을 계속할 수 있음

# **세계는 Player가 버튼을 누를 때만 살아나는 무대가 아니다.**

# 7. 현재 임시 거처 → 막집

Stage 07에서는 현재 생활 공간의 존재를 먼저 느낀다.

이 시점의 player-facing 기본 표현은:

> **현재 임시 거처**

다.

하지만 가능하면 Player narration보다:

- 사람이 덮개를 만짐
- 바람 때문에 일부가 움직임
- 불과 생활 물건이 가까이 있음
- 사람들이 실제로 그 주변에서 생활함

으로 먼저 공간 의미를 만든다.

Camp에서 실제로:

- 덮개가 흔들림
- 틈을 막음
- 나뭇가지/재료를 손질
- 날씨에 따른 불편을 경험

한 뒤:

> **막집**

이라는 교과 용어를 짧게 붙이는 것을 기본으로 한다.

# **placeholder silhouette를 보았다는 이유만으로 막집 학습 완료를 선언하지 않는다.**

# 8. 동굴 / 바위 그늘 발견 문법

```text
한동안 이동
→ 사람/거처 소리가 사라짐
→ 큰 바위 아래 어두운 공간
→ 함께 있던 사람의 정지/시선 변화
→ 내가 그 변화를 알아차림
→ 내가 가까이 감
→ 입구/바닥/안쪽/바람/주변 길을 살핌
→ 넓음/마름/보호 가능성을 느낌
→ 어둠/동물 흔적/거리의 불확실성도 남음
→ 생활 공간 후보로 판단
→ 짧은 역사 연결
```

Reveal:

> **동굴 / 바위 그늘**  
> 구석기 사람들은 이런 자연 공간도 생활 공간으로 이용했다.

핵심:

- 동굴이 유일한 집 아님.
- 막집의 업그레이드 아님.
- 자동 새 집 아님.
- 자동 공포 던전도 아님.
- 이 특정 Day 1 발견 사건은 재구성임.
- `누가 먼저 발견하는 역할`보다 실제 위치/시선/상황이 우선.

# 9. 불은 반복 경험이자 사회적 motif다

- 새벽: 따뜻함 / 사람들이 이미 모여 있는 생활 중심
- Camp: 유지해야 하는 생활 중심
- 음식: 익혀 먹음
- 어둠/위험: 안정/보호
- Hunt 출발: 뒤에 남는 사람과 장소
- Hunt 귀환: 멀리서 다시 보이는 사람/거처의 anchor

같은 불이 장면마다 다른 의미를 가져야 한다.

```text
새벽의 불 = 익숙함
떠나는 불 = 멀어지는 곳
보이지 않는 불 = 거리 부담
저녁의 불 = 돌아갈 수 있다는 신호
Camp의 불 = 계속 지켜야 했던 생활
```

후속 개념화에서 정확한 교과 표현으로 정리한다.

# 10. 시간과 거리는 HUD보다 세계로 느낀다

가능하면 다음을 우선한다.

시간:

- 햇빛 각도
- 그림자 길이
- 색/공기 변화
- 주변 소리 변화
- 불빛의 상대적 밝기
- 사람의 짧은 말 `늦어.`

거리:

- 처음에는 불/거처/사람 소리가 보이고 들림
- 점차 작아짐
- 더 멀어지면 사라짐
- 특정 랜드마크를 지나침
- 귀환 때 같은 랜드마크가 다시 나타남

`현재 17:30`, `거처까지 3.2km` 같은 HUD는 기본 문법이 아니다.

# **학생이 시간과 거리를 계산하기 전에 몸과 환경으로 부담을 느끼게 한다.**

# 11. 감정과 학습

학습이 강해질수록 감정을 제거하지 않는다.

도구를 들고 멀리 감
→ 해가 낮아짐
→ 함께 온 사람의 상태가 달라짐
→ 위험을 겪음
→ 새 공간을 발견함
→ 아침의 말이 다시 떠오를 조건이 생김
→ 돌아갈 길을 생각함

학생은 동시에:

- 도구
- 이동 거리
- 자연 위험
- 거처 판단
- 공동체 관계

를 경험한다.

# **감정이 역사 조건과 연결되면 이해가 깊어진다.**

---

# 12. 공포 / 긴장

허용:

- 어둠
- 보이지 않는 안쪽
- 동물 흔적 가능성
- 갑작스러운 정적
- 가까운 소리
- 다른 사람의 갑작스러운 정지
- 짧은 strong-accent

규칙:

- 원인이 세계 안에 먼저 존재.
- 사람의 반응이 효과보다 먼저 올 수 있음.
- 효과가 위험을 대신하지 않음.
- 같은 효과를 반복하지 않음.
- 공포 뒤에도 판단/관계/결과가 남음.

---

# 13. Choice Fairness

좋은 선택은 숨은 정답 문제가 아니다.

예: 자연 거처 후보

```text
넓고 일부 마름
BUT
안쪽은 어둡고 위험 여부 모름
AND
물/먹을거리 거리 모름
```

예: 더 추적할지 고민

```text
흔적은 이어짐
BUT
해는 낮아짐
AND
거처는 안 보임
AND
사람들의 상태도 달라짐
AND
아침의 귀환 말이 기억될 조건이 생김
```

학생은 선택 전에 판단 근거를 봐야 한다.

# **결과 평등이 아니라 인과의 납득 가능성이 필요하다.**

---

# 14. Limited Knowledge와 Narrative Variant

# **World Truth ≠ Character Knowledge**

현재 body가 직접:

- 본 것
- 함께 겪은 것
- 나중에 들은 것

을 구분한다.

다른 역할에서 일어난 사건을 전지적으로 자동 공유하지 않는다.

예:

```text
Hunt가 자연 거처 후보를 직접 봄
→ Camp는 모름
→ Hunt 귀환 뒤 누군가 이야기함
→ 그 뒤 Camp가 '들어서 아는 정보'가 됨
```

필수 교과 개념을 한 관점의 knowledge에만 가두지는 않는다.

Hunt에서 자연 거처 후보를 못 본다면:

- Gather에서 바위 그늘을 이용하거나
- Camp에서 다른 사람의 발견 이야기를 듣거나
- Common Evening/Conceptualization에서 회수

할 수 있다.

# **핵심 개념은 보존하되, 사람마다 어떻게 알게 되었는지는 다를 수 있다.**

---

# 15. Callback 문법

좋은 관계/역사 몰입은 앞 장면의 사소한 요소가 뒤에서 다른 의미를 가질 때 강해진다.

권장 motif:

- 불
- 주먹도끼
- `해가 지기 전에 와.` 같은 짧은 말
- 반복 랜드마크
- 특정 사람의 habit

예:

```text
아침:
“해가 지기 전에 와.”
= 일상적인 말

오후:
해가 낮아짐 + 불이 안 보임
= 시간/거리 압박

귀환:
멀리 같은 불빛
= 사람들에게 돌아가는 감각

다른 관점:
사람들이 돌아오지 않는 시간을 직접 겪음
= 기다림과 걱정의 의미
```

# **Callback은 텍스트 복습이 아니라 의미 변화다.**

---

# 16. Perspective Shift는 설명보다 발견이어야 한다

관점 전환에서 다음을 피한다.

> `이제 도구를 건넨 사람의 관점입니다.`

권장:

```text
transition
→ 새로운 몸/손
→ 아까 내 손에 있던 물건이 없음
→ 같은 불/같은 공간
→ 멀리 떠나는 사람 손에 같은 물건이 보임
→ 같은 이름/목소리/말이 다른 위치에서 이어짐
→ 학생이 어느 자리인지 스스로 연결
```

필요하면 접근성을 위한 최소 보조 설명은 제공할 수 있지만, Primary Reveal은 body/object/spatial/social continuity다.

다른 관점에서 새롭게 알게 되는 정보와 감정이 있어야 한다.

# **Perspective Shift = camera change가 아니라 social recontextualization.**

---

# 17. 실제 유물·유적 연결

구조:

```text
내가 겪은 재구성
→ 정확한 교과 용어
→ 실제 유물/유적 증거
```

구체 유적/유물 명칭은 source 확인 뒤 사용한다.

체험 속 가상의 하루와 fictional character를 실제 특정 유적의 실존 사건/인물로 단정하지 않는다.

---

# 18. Fact / Reconstruction

Scene 제작 시 구분한다.

## Fact

- 교과서/유물/유적이 직접 뒷받침하는 생활 조건/개념

## Reconstruction

- R/H1/H2 authoring identity에 대응하는 fictional character
- Player-facing 이름
- character habit/shared past
- 특정 아침 도구 전달
- 현재 장면의 구체 거처 배치/공동체 구성
- 특정 자연 거처 후보 발견
- 구체 대사·감정·결과
- 구체 knowledge transfer

Player를 관리 라벨로 끊지 않는다.
`R/H1/H2`, 역할 기능명, `○○의 관점` 같은 제작용 설명도 Player에서는 관리 라벨로 본다.
Teacher/Debug에서 구분 가능하게 한다.

---

# 19. Scene 제작 체크리스트

1. Historical / Curriculum Fact는 무엇인가?
2. Reconstructed Event/Character는 무엇인가?
3. Player character가 이미 알고 있을 것과 학생이 아직 모르는 것은 무엇인가?
4. 학생이 먼저 무엇을 몸으로 경험하는가?
5. 주변 사람은 Player와 무관하게 무엇을 하고 있는가?
6. 이 scene에 NPC-to-NPC interaction이 필요한가?
7. 사람의 이름/습관/shared memory가 기능 label보다 앞서는가?
8. 사람/세계의 행동이 설명문보다 먼저인가?
9. 직접 Player 행동은 무엇인가?
10. 세계/사람은 어떻게 반응하는가?
11. 어떤 memory가 남는가?
12. Primary Attention은 하나인가?
13. 용어를 지금 반드시 짚어야 하는가?
14. terminology reveal은 경험 뒤인가?
15. 상위/하위 개념 관계가 정확한가?
16. 그 개념은 나중에 다시 사용되는가?
17. 선택 결과가 뒤에서 회수되는가?
18. 시간/거리를 숫자보다 세계에서 느낄 수 있는가?
19. 현재 character가 알 수 없는 정보를 보여주고 있지 않은가?
20. screen treatment가 의미보다 앞서지 않는가?
21. Player에 내부 관리 정보가 노출되지 않는가?
22. Player 문장이 인물을 행동 기능으로 요약하고 있지 않은가?
23. 관점 전환을 제목으로 설명하기보다 몸/물건/공간/사람 continuity로 느끼게 하는가?
24. 앞 장면의 말/물건/사람/장소가 callback으로 다른 의미를 얻는가?

# 20. 역할별 몰입 문법

아래 `Hunt / Gather / Camp`는 제작 분류다. Player가 자기 역할명을 계속 읽어야 한다는 뜻이 아니다.

## Hunt

- 멀어짐
- 주먹도끼 continuity
- 사람과 함께 움직임
- 흔적
- 위험
- 새 장소 발견
- 귀환
- 아침 관계 callback

## Gather

- 손/지면
- 반복 탐색
- 뿌리/열매
- 도구 재사용/가공
- 장소 기억
- Hunt/Camp와 다른 정보

## Camp

- 불
- 현재 임시 거처
- 막집 경험/명명
- 손질
- 시간 변화
- 빈자리
- 기다림
- 재회
- Hunt에서 보지 못한 반대편 감정

# 21. Stage 07.5 Human QA

공식 Gate는 여전히 실제 사람이 브라우저에서 확인한다.

질문:

- current temporary shelter가 현대 집/텐트 아이콘처럼 읽히지 않는가?
- `뗀석기 → 대표적인 예: 주먹도끼` 관계가 자연스럽게 이해되는가?
- terminology cue가 몰입을 과도하게 끊지 않는가?
- 도구가 같은 물건으로 이어지는가?
- 자연 거처 후보가 실제 공간처럼 느껴지는가?
- 장점과 불확실성이 함께 읽히는가?
- cave cue가 탐색 뒤 나오는가?
- Fact와 Reconstruction을 교사가 구분할 수 있는가?
- 다른 관점에서 정보를 전지적으로 자동 공유하지 않는가?
- Player에 internal evidence/anchor/reconstruction/event metadata가 보이지 않는가?
- Player가 공동체에 처음 온 관광객보다 이미 여기서 살아온 사람처럼 느껴지는가?
- 핵심 인물을 이름·목소리·습관·shared event로 기억할 수 있는가?
- 인물의 기능을 설명문으로 읽어야만 누가 누구인지 알 수 있는가?
- NPC가 Player가 없어도 자기 생활을 할 것처럼 느껴지는가?
- 모든 NPC가 Player만 바라보거나 Player에게만 말하지 않는가?
- 이름이 NPC 카드 암기처럼 느껴지지 않는가?
- 짧은 한국어 대사가 상황 안에서 자연스럽고 원시인 caricature를 만들지 않는가?
- 시간/거리가 HUD보다 환경으로 느껴지는가?
- 아침의 말/사람/물건/불이 후반에 callback되는가?
- 역할/관점 제목을 제거해도 몸·물건·공간·사람 continuity로 현재 자리를 이해할 수 있는가?
- Perspective Shift가 `다른 화면`보다 같은 사건의 사회적 재해석으로 느껴지는가?

# **자동 테스트가 이 질문들의 Human PASS를 대신할 수 없다.**
