# 1. 몰입의 정의

몰입은 예쁜 그림이나 긴 스토리가 아니다.

# **학생이 화면의 정보를 처리하는 대신, 자기 몸이 있는 상황 속에서 사람과 환경을 보고 판단하는 상태**

다.

학생의 내적 질문이

> “다음 버튼이 뭐지?”

보다

> **“지금 나는 어떻게 해야 하지?”**

에 가까워야 한다.

---

# 2. 몰입의 11개 층

## 1. 즉시 상황 진입

학습 안내보다 세계가 먼저 존재한다.

## 2. Embodied POV

내 손·팔·다리·도구가 행동과 자세에 맞게 시야에 들어온다.

## 3. 공간

앞/뒤/가까움/멀어짐/돌아갈 방향이 이어진다.

## 4. 관계

반복 등장 인물이 나를 보고, 함께 행동하고, 내 선택에 반응한다.

## 5. 생활상의 욕구

`미션`보다 먹을거리, 불, 시간, 기다림 같은 상황이 행동 이유를 만든다.

## 6. 행동

학생이 손과 시선으로 직접 살핀다/받는다/움직인다/기다린다.

## 7. 고민

선택 전에 서로 충돌하는 가치가 충분히 보인다.

## 8. 위협

위험 설명보다 징후와 사람의 행동 변화가 먼저다.

## 9. 기억과 결과

선택의 흔적이 몸, 사람, 시간, 공간, 이후 대사에 남는다.

## 10. 재해석

다른 역할에서 같은 사건의 반대편을 다시 경험한다.

## 11. Perceptual Treatment

색·명암·초점·짧은 blink·미세 움직임 같은 작은 화면 변화가 장면의 몸/환경 상태를 조용히 강화한다.

---

# 3. Opening Gate

시작 20~30초 안에 다음이 있어야 한다.

- 내 몸 일부
- 하나의 구체 장소
- 나와 가까운 사람
- 손으로 하는 첫 행동
- 오늘의 생활 문제 신호

피할 것:

- `구석기 시대에 오신 것을 환영합니다`
- 학습 목표
- 역할 메뉴
- Stage/Version
- 긴 세계관 설명

---

# 4. Body Gate

몸은 장면마다 자연스럽게 달라져야 한다.

예:

- 불: 손/무릎
- 걷기: 팔/도구
- 흔적: 손/무릎/지면
- 위험: 낮아진 자세
- 운반: 양손/부담
- 귀환: 피로한 팔/걸음

고정된 손 PNG가 모든 Scene에 붙는다면 실패다.

---

# 5. Relationship Gate

최소 한 명의 인물이 다음을 만족해야 한다.

- 처음 만난 뒤 다시 등장
- 학생과 직접 물건/시선/행동을 주고받음
- 학생 선택을 보고 반응
- 이후 장면에서 기억이 회수됨

인물 소개 카드로 관계를 대신하지 않는다.

---

# 6. Dilemma Gate

선택지 표시 전 학생이 다음을 볼 수 있어야 한다.

- 원하는 것
- 얻을 가능성
- 비용/부담
- 다른 사람의 상태
- 시간/공간 조건

좋은 고민은 선택지만 읽어도 되는 것이 아니라 **상황을 보아야 판단할 수 있는 것**이다.

---

# 7. Threat Gate

기본 문법:

# **징후 → 다른 사람의 반응 → 내 몸의 긴장 → 내 관찰 → 판단**

위험이 등장할 때 즉시 진한 붉은 경고 UI나 damage flash를 띄우지 않는다.

필요하면 위협을 인식한 순간 아주 짧은 focus shift, 주변부 명암 변화, 움직임의 정지 같은 연출을 보조적으로 사용할 수 있다.

중요 정보를 색/사운드/효과 하나에만 의존하지 않는다.

---

# 8. Consequence Gate

모든 중요한 선택은 다음 중 하나 이상을 바꾼다.

- 사람의 반응
- 관계 기억
- 시간
- 거리
- 몸의 피로/부담
- 보는 정보
- 위험 맥락
- 귀환 장면
- 다음 관점

선택 직후 아무 변화도 없고 뒤에서도 회수되지 않으면 삭제 후보다.

---

# 9. Reconvergence Gate

큰 플롯은 다시 만날 수 있다.

그러나 다음까지 같으면 선택이 무효화된다.

- 같은 사람 위치
- 같은 대사
- 같은 몸 상태
- 같은 물건
- 같은 감정 Beat

재수렴 뒤에도 최소 하나 이상의 의미 차이가 남아야 한다.

---

# 10. Perspective Recontextualization Gate

역할 전환은 같은 하루의 반대편을 보여줘야 한다.

예:

Hunt:

> R이 나를 보고 `해가 지기 전에 돌아와`라고 말함.

Camp:

> 이제 R의 손과 몸이 내 몸. 밖으로 나가는 Hunt 사람의 뒷모습을 봄.

이후 늦은 오후:

> 그 사람이 아직 보이지 않음.

이 순간 학생은 설명 없이 같은 관계를 양쪽에서 이해한다.

관점 전환은 필요하면 한 번의 자연스러운 blink, 짧은 darkness, 동일 인물/불을 anchor로 한 노출 변화로 연결할 수 있다.

---

# 11. Screen Treatment Gate

화면 연출은 다음 질문을 통과해야 한다.

- 이 효과가 없다면 장면 의미 자체가 사라지는가? 그렇다면 세계/몸/사람 설계를 먼저 보강한다.
- 효과가 몸 상태나 환경 변화를 더 빨리 체감하게 하는가?
- 효과가 HP/위험 게이지 같은 비서사적 UI로 보이지 않는가?
- 효과가 짧고 제한적으로 사용되는가?
- 몸·사운드·사람 반응과 같이 작동하는가?
- 저감 모드에서도 진행과 의미가 유지되는가?

추천 언어:

- 색온도/Color wash
- 노출/명암 변화
- 짧은 blink
- 약한 vignette
- 선택적 blur/focus
- 약한 sway
- 순간적인 motion stop

주의:

- 진한 전체 화면 red flash 남용 금지
- 반복 flashing 금지
- 지속적 강한 shake/blur 금지
- 모든 장면에 effect를 깔지 않음

기본 효과 강도는 `none / subtle / accent`로 사고한다.

---

# 12. 문장 원칙

우선순위:

1. 시야에 보이는 것
2. 사람이 실제로 할 법한 짧은 말
3. 학생 행동
4. 필요한 최소 내레이션
5. 체험 뒤 역사 개념화

나쁨:

> 자연 속에서 인간은 위험할 수 있었습니다.

좋음:

> H2가 갑자기 멈춘다.
>
> 내 오른쪽 수풀이 크게 흔들린다.

---

# 13. 인물 대사 원칙

대사는 정보를 전달하기 위해 존재하지 않는다.

대사의 역할:

- 관계
- 의도
- 망설임
- 안도
- 서로 다른 판단

NPC가 정답을 말하지 않는다.

한 인물이 언제나 현명하고 다른 인물이 언제나 무모한 구조도 피한다.

---

# 14. 시각 원칙

최종 이미지의 단위는 `배경`이 아니다.

# **POV composition = environment + body + actor + action + light**

이다.

이미지 제작 전 확인:

- POV 높이
- gaze
- visible body parts
- held item
- actor 위치
- 광원
- 앞/뒤 continuity
- screen treatment가 이미지/레이어의 광원과 충돌하지 않는지

---

# 15. 사운드 원칙

사운드는 공간과 관계를 만든다.

- 내 가까이의 손/발 소리
- 앞/옆에서 들리는 사람 목소리
- 멀어지는 거처 소리
- 이상한 자연 신호
- 귀환 때 다시 들리는 익숙한 불/사람 소리

작은 화면 연출은 사운드와 결합할 때 의미가 분명해질 수 있다.

예:

- 수풀 소리 + 동행자 정지 + 짧은 focus 변화
- 불소리 + 따뜻한 색온도 + 내 손의 자세
- 긴 귀환 발소리 + 피로한 팔 + 약한 sway

음악은 감정을 대신 설명하지 않는다.

---

# 16. 역사 정확성

관계·감정·구체 사건은 `[재구성]`일 수 있다.

하지만

- 친족 구조
- 성별 역할
- 지도자 체계
- 특정 종/식생
- 의복 세부

를 근거 없이 일반 사실처럼 고정하지 않는다.

몰입을 위해 사실성을 희생하지 않는다.

---

# 17. 역할별 몰입의 차이

## Hunt

멀어지는 공간 / 추적 / 위험 / 귀환.

화면 연출 후보: 따뜻함이 사라지는 출발, 해질녘 색, 위협 순간의 정지/focus, 귀환 불빛의 밝기 회복.

## Gather

가까운 환경 / 반복 관찰 / 손으로 살핌 / 장소 기억 / 범위 확대.

화면 연출 후보: 가까운 대상 focus, 시간대별 빛 변화, 익숙한 장소와 먼 장소의 대비.

## Camp

같은 공간 / 손질 / 불 / 빈자리 / 시간 / 멀리 바라보기 / 재회.

화면 연출 후보: 불빛의 따뜻함, 같은 화면의 시간대 변화, 기다림에서 큰 효과보다 정적과 빈자리.

1인칭이라는 이유로 세 역할을 같은 화면 템플릿으로 만들지 않는다.

---

# 18. QA 질문

교사/학생 플레이 후 묻는다.

- 화면 속에 내가 있다는 느낌이 있었는가?
- 내 손/몸이 자연스러웠는가?
- 기억나는 사람이 있는가?
- 그 사람이 나를 기억하는 것 같았는가?
- 위험하다고 쓰여 있지 않아도 긴장된 순간이 있었는가?
- 선택 전에 실제로 고민했는가?
- 내 선택 때문에 뒤의 장면이 달라졌다고 느꼈는가?
- 다른 역할을 하면서 앞의 행동을 다시 생각한 순간이 있었는가?
- 같은 결과 화면으로 정리된다는 느낌이 들지는 않았는가?
- 화면 색/명암/초점/미세 움직임이 상황을 자연스럽게 강화했는가?
- 화면 효과가 너무 눈에 띄거나 불편하지는 않았는가?

---

# 19. Immersion Complete 판정

기능이 정상이어도 다음이면 Immersion Complete가 아니다.

- 몸이 장식처럼 보임
- NPC가 안내자처럼만 보임
- 선택지가 먼저 나오고 고민은 나중에 설명됨
- 위험이 경고 UI로만 전달됨
- 선택이 뒤에서 기억되지 않음
- 역할 전환이 게임 메뉴처럼 보임
- 모든 경로가 같은 대사/같은 결론으로 느껴짐
- 화면 효과가 장면보다 앞서거나 반복적으로 과하게 사용됨

Immersion Complete는 실제 교사/학생 플레이 관찰로 판정한다.
