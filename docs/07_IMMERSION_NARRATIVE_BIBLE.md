# 1. 장면을 만드는 순서

```text
Historical / Curriculum Fact
→ Dramatic Need
→ Embodied Situation
→ Person / Relationship
→ Direct Action
→ World Response
→ Terminology Reveal (필요할 때)
→ Reuse / Consequence
→ Callback / Concept Connection
```

예: 도구

```text
Fact: 뗀석기 사용 / 주먹도끼는 대표적인 구체 예
→ Dramatic Need: R과의 도구 전달
→ Embodied: R의 손 + 돌도구 + 내 손
→ Action: 받는다
→ World Response: 같은 도구가 내 손에 남음
→ Name: '뗀석기' 상위 개념 + '주먹도끼' 대표 예
→ Reuse: Stage 08 이후 실제 생활 행동
→ Callback: 귀환 / 다른 역할 / 실제 유물 연결
```

# **교과 내용은 장면 위에 붙이는 스티커가 아니라 장면의 물리적 재료가 되어야 한다.**

# 2. 몰입의 12개 층

1. **Role Embodiment** — 지금 누구의 몸인가.
2. **Sensory Presence** — 무엇을 보고 듣고 느끼는가.
3. **Body Continuity** — 손/팔/도구가 같은 몸으로 이어지는가.
4. **Spatial Continuity** — 장소가 서로 이어지는가.
5. **Relationship Presence** — 사람이 기능 버튼이 아니라 실제 존재인가.
6. **Need / Desire** — 왜 행동해야 하는가.
7. **Uncertainty** — 결과를 미리 모르는가.
8. **Meaningful Choice** — 상황을 보고 판단하는가.
9. **Persistent Consequence** — 행동 흔적이 뒤에 남는가.
10. **Emotional Reality** — 공포·후회·죄책감·안도 등이 상황에서 생기는가.
11. **Perceptual Treatment** — 색·명암·focus·motion이 사건을 증폭하는가.
12. **Curriculum Recognition** — 이미 겪은 것에 정확한 역사 용어가 붙는가.

어느 하나가 다른 것을 압도하면 실패할 수 있다.

# 3. 첫 20~30초

학생은 첫 20~30초 안에:

- 지금 누구 관점인지
- 내 몸이 있다는 것
- 가까운 사람이 있다는 것
- 생활 공간 안에 있다는 것
- 첫 행동이 무엇인지

를 느껴야 한다.

피할 것:

- 학습 목표 목록
- 긴 시대 설명
- 유물 목록 먼저 제시
- Stage/Prototype 메타데이터

# 4. Terminology Reveal

# **Experience before Explanation. Naming before Testing.**

좋은 도구 reveal:

> **뗀석기**  
> 돌을 깨뜨리거나 떼어 만든 도구를 뗀석기라고 한다. 지금 손에 든 것은 그 대표적인 예인 **주먹도끼**다.

특징:

- 1~2문장
- 화면 전체를 막지 않음
- 이미 경험한 대상과 연결
- 다음 행동과 공존
- 감정/위협 peak와 겹치지 않음

나쁜 reveal:

- 장문의 설명 modal
- 즉시 객관식/OX
- 모든 장면 용어 카드화
- `뗀석기 · 주먹도끼`만 병렬 제목으로 제시하고 관계를 생략

---

# 5. 유물은 생활 물건

```text
처음 봄
→ 받음
→ 이름을 알게 됨
→ 손에 계속 있음
→ 실제 행동에 사용
→ 다른 사람이 다시 봄
→ 실제 유물/교과 개념과 연결
```

Stage 07의 receive/naming proof를 실제 다용도 사용 완료로 과장하지 않는다.

---

# 6. 사람과 관계가 개념을 세계 안에 놓는다

좋은 예:

- R이 돌도구를 건넴.
- H1이 위험 앞에서 멈춤.
- H2가 자연 거처 후보를 바라봄.
- Camp 인물이 현재 임시 거처를 직접 손질함.

나쁜 예:

- R이 교과서 문단을 암송.
- H2가 항상 정답을 알려줌.

사람은 설명자보다 함께 살아가는 사람이어야 한다.

---

# 7. 현재 임시 거처 → 막집

Stage 07에서는 현재 생활 공간의 존재를 먼저 느낀다.

이 시점의 player-facing 기본 표현은:

> **현재 임시 거처**

다.

Camp에서 실제로:

- 덮개가 흔들림
- 틈을 막음
- 나뭇가지/재료를 손질
- 날씨에 따른 불편을 경험

한 뒤:

> **막집**

이라는 교과 용어를 짧게 붙이는 것을 기본으로 한다.

# **placeholder silhouette를 보았다는 이유만으로 막집 학습 완료를 선언하지 않는다.**

---

# 8. 동굴 / 바위 그늘 발견 문법

```text
한동안 이동
→ 큰 바위 아래 어두운 공간
→ 동행자 반응
→ 내가 가까이 감
→ 입구/바닥/안쪽/바람/주변 길을 살핌
→ 넓음/마름/보호 가능성을 느낌
→ 어둠/동물 흔적/거리의 불확실성도 남음
→ 생활 공간 후보로 판단
→ 짧은 역사 연결
```

Reveal:

> **동굴 / 바위 그늘**  
> 구석기 사람들은 이런 자연 공간도 생활 공간으로 이용했다.

핵심:

- 동굴이 유일한 집 아님.
- 막집의 업그레이드 아님.
- 자동 새 집 아님.
- 자동 공포 던전도 아님.
- 이 특정 Day 1 발견 사건은 재구성임.

# 9. 불은 반복 경험

- 새벽: 따뜻함
- Camp: 유지해야 하는 생활 중심
- 음식: 익혀 먹음
- 어둠/위험: 안정/보호
- 귀환: 사람/거처의 시각적 anchor

후속 개념화에서 정확한 교과 표현으로 정리한다.

---

# 10. 감정과 학습

학습이 강해질수록 감정을 제거하지 않는다.

도구를 들고 멀리 감
→ 해가 낮아짐
→ 위험을 겪음
→ 새 공간을 발견함
→ 돌아갈 길을 생각함

학생은 동시에:

- 도구
- 이동 거리
- 자연 위험
- 거처 판단
- 공동체 관계

를 경험한다.

# **감정이 역사 조건과 연결되면 이해가 깊어진다.**

---

# 11. 공포 / 긴장

허용:

- 어둠
- 보이지 않는 안쪽
- 동물 흔적 가능성
- 갑작스러운 정적
- 가까운 소리
- 짧은 strong-accent

규칙:

- 원인이 세계 안에 먼저 존재.
- 효과가 위험을 대신하지 않음.
- 같은 효과를 반복하지 않음.
- 공포 뒤에도 판단/관계/결과가 남음.

---

# 12. Choice Fairness

좋은 선택은 숨은 정답 문제가 아니다.

예: 자연 거처 후보

```text
넓고 일부 마름
BUT
안쪽은 어둡고 위험 여부 모름
AND
물/먹을거리 거리 모름
```

학생은 선택 전에 판단 근거를 봐야 한다.

# **결과 평등이 아니라 인과의 납득 가능성이 필요하다.**

---

# 13. Learning Invariant와 Narrative Variant

필수 교과 개념을 한 분기에 가두지 않는다.

Hunt에서 자연 거처 후보를 못 본다면:

- Gather에서 바위 그늘을 이용하거나
- Camp에서 다른 사람의 발견 이야기를 듣거나
- Common Evening/Conceptualization에서 회수

할 수 있다.

---

# 14. 실제 유물·유적 연결

구조:

```text
내가 겪은 재구성
→ 정확한 교과 용어
→ 실제 유물/유적 증거
```

구체 유적/유물 명칭은 source 확인 뒤 사용한다.

체험 속 가상의 하루를 실제 특정 유적의 사건으로 단정하지 않는다.

---

# 15. Fact / Reconstruction

Scene 제작 시 구분한다.

## Fact

- 교과서/유물/유적이 직접 뒷받침하는 생활 조건/개념

## Reconstruction

- R/H1/H2
- 특정 아침 도구 전달
- 현재 장면의 구체 거처 배치
- 특정 자연 거처 후보 발견
- 구체 대사·감정·결과

Player를 관리 라벨로 끊지 않는다.
Teacher/Debug에서 구분 가능하게 한다.

---

# 16. Scene 제작 체크리스트

1. Historical / Curriculum Fact는 무엇인가?
2. Reconstructed Event는 무엇인가?
3. 학생이 먼저 무엇을 몸으로 경험하는가?
4. 주변 사람은 무엇을 하는가?
5. 직접 행동은 무엇인가?
6. 세계는 어떻게 반응하는가?
7. Primary Attention은 하나인가?
8. 용어를 지금 반드시 짚어야 하는가?
9. terminology reveal은 경험 뒤인가?
10. 상위/하위 개념 관계가 정확한가?
11. 그 개념은 나중에 다시 사용되는가?
12. 선택 결과가 뒤에서 회수되는가?
13. screen treatment가 의미보다 앞서지 않는가?
14. Player에 내부 관리 정보가 노출되지 않는가?
