# 1. 장면을 만드는 기본 순서

모든 주요 Scene을 다음 순서로 점검한다.

```text
Historical / Curriculum Fact
→ Dramatic Need
→ Embodied Situation
→ Person / Relationship
→ Direct Action
→ World Response
→ Terminology Reveal (필요할 때)
→ Reuse / Consequence
→ Callback / Concept Connection
```

예: 주먹도끼

```text
Fact: 구석기 대표 뗀석기, 여러 생활 용도
→ Dramatic Need: 아침에 R과 관계를 만드는 물건 전달
→ Embodied: 상대 손 + 돌도구 + 내 손
→ Action: 받는다
→ World Response: 내 손에 도구가 남음
→ Name: '뗀석기 · 주먹도끼'
→ Reuse: 이후 이동/관찰/가공에서 다시 사용
→ Callback: 귀환/다른 역할/실제 유물 연결
```

# **교과 내용은 장면 위에 붙이는 스티커가 아니라 장면의 물리적 재료가 되어야 한다.**

# 2. 몰입의 12개 층

1. **Role Embodiment** — 지금 누구의 몸인가.
2. **Sensory Presence** — 무엇을 보고 듣고 느끼는가.
3. **Body Continuity** — 내 손/팔/도구가 같은 몸으로 이어지는가.
4. **Spatial Continuity** — 장소가 서로 연결되어 있는가.
5. **Relationship Presence** — 주변 사람이 기능 버튼이 아니라 실제 존재처럼 느껴지는가.
6. **Need / Desire** — 지금 왜 행동해야 하는가.
7. **Uncertainty** — 결과를 미리 모르는가.
8. **Meaningful Choice** — 상황을 보고 판단하는가.
9. **Persistent Consequence** — 행동의 흔적이 뒤에 남는가.
10. **Emotional Reality** — 공포·후회·죄책감·안도 등이 상황에서 생기는가.
11. **Perceptual Treatment** — 색·명암·focus·motion이 사건을 증폭하는가.
12. **Curriculum Recognition** — 이미 겪은 것에 정확한 역사 용어가 자연스럽게 붙는가.

어느 하나가 다른 것을 압도하면 실패할 수 있다.

---

# 3. 첫 20~30초

학생은 첫 20~30초 안에 다음을 느껴야 한다.

- 지금 누구 관점인지
- 내 몸이 있다는 것
- 가까운 사람이 있다는 것
- 생활 공간에 이미 들어와 있다는 것
- 내가 해야 할 첫 행동이 있다는 것

피할 것:

- 학습 목표 목록
- 긴 시대 설명
- 유물 목록 먼저 제시
- Stage/Prototype 메타데이터

교과 개념은 첫 행동 뒤에 들어올 수 있다.

---

# 4. 용어 reveal은 몰입을 끊지 않는 짧은 ‘이름 붙이기’

`뗀석기`, `주먹도끼`, `막집`처럼 반드시 알고 넘어갈 용어는 숨기지 않는다.

다만 다음 순서를 지킨다.

# **Experience before Explanation. Naming before Testing.**

좋은 reveal:

> **뗀석기 · 주먹도끼**
> 돌을 깨뜨리거나 떼어 만든 대표적인 구석기 도구

특징:

- 작음
- 짧음
- 화면 전체를 막지 않음
- 이미 본 물건 옆/후속 영역에서 나타남
- 다음 행동과 공존 가능

나쁜 reveal:

- 5문단 설명 모달
- “주먹도끼의 용도는?” 즉시 객관식
- 모든 장면의 용어 카드화

---

# 5. 유물은 ‘사용 전시물’이 아니라 생활 물건

핵심 유물은 다음 continuity를 갖는다.

```text
처음 봄
→ 받음
→ 이름을 알게 됨
→ 손에 계속 있음
→ 실제 행동에 사용
→ 다른 사람이 다시 봄
→ 후속 개념과 연결
```

주먹도끼가 `아이템 획득!` 후 inventory로 사라지면 몰입과 학습이 모두 약해진다.

---

# 6. 사람과의 관계가 교과 개념을 전달하게 한다

좋은 예:

- R이 주먹도끼를 건넴.
- H1이 위험 앞에서 멈춤.
- H2가 동굴 입구를 바라봄.
- Camp 인물이 막집 덮개를 손질함.

나쁜 예:

- R이 교과서 문단을 암송.
- H2가 항상 정답을 알려줌.

사람은 **설명자보다 함께 살아가는 사람**이어야 한다.

---

# 7. 동굴 발견 장면의 몰입 문법

좋은 흐름:

```text
바위 면 아래 어두운 공간이 보임
→ 동행자가 먼저 멈춤
→ 내가 가까이 감
→ 입구/바닥/안쪽을 봄
→ 넓음/마름/바람 차단을 느낄 수 있음
→ 어둠/동물 흔적/거리의 불확실성도 남음
→ '생활하기 괜찮아 보일 수도 있다'는 판단
→ 짧은 역사 연결
```

핵심:

- `동굴 발견!` 시스템 배너가 먼저 나오지 않음.
- 동굴이 무조건 좋은 새 집이 아님.
- 동굴이 무조건 공포 던전도 아님.
- 보호 가능성과 위험 가능성이 동시에 존재.

---

# 8. 막집 장면의 몰입 문법

막집은 이미지 배경이 아니라 손질해야 하는 임시 생활 공간이다.

가능한 경험:

- 덮개가 바람에 흔들림
- 틈을 막음
- 나뭇가지/가죽을 조정
- 비가 오면 불편함 증가

그 뒤 짧게 `막집`이라는 용어를 붙인다.

학생은

> “왜 임시 거처라고 했는지”

를 먼저 몸으로 이해해야 한다.

---

# 9. 불은 설명보다 반복 경험

불의 의미는 여러 장면에서 나눠 경험한다.

- 새벽: 따뜻함
- Camp: 유지해야 하는 생활 중심
- 음식: 익혀 먹음
- 어둠/위험: 안정과 보호
- 귀환: 사람과 거처의 시각적 anchor

후속 개념화에서 불의 기능을 정리하면 이미 경험과 연결된다.

---

# 10. 감정과 교과 학습을 분리하지 않는다

예:

주먹도끼를 들고 멀리 감
→ 해가 낮아짐
→ 위험을 겪음
→ 동굴을 발견함
→ 돌아올 길을 생각함

학생은 동시에

- 도구 사용
- 이동 거리
- 자연 위험
- 거처 판단
- 공동체 관계

를 경험한다.

# **학습이 강해질수록 감정이 사라져야 하는 것이 아니다. 감정이 역사 조건과 연결되면 이해가 깊어진다.**

---

# 11. 공포 / 긴장

허용:

- 어둠
- 안 보이는 안쪽
- 동물 흔적
- 갑작스러운 정적
- 가까운 소리
- 짧은 strong-accent

규칙:

- 원인이 세계 안에 먼저 존재.
- 화면 효과가 위험을 대신하지 않음.
- 같은 효과 반복으로 둔감하게 만들지 않음.
- 공포 뒤에도 판단과 관계가 남음.

---

# 12. Choice Fairness

좋은 선택은 `정답이 숨은 선택`이 아니다.

예: 동굴

```text
넓고 마름
BUT
안쪽은 어둡고 위험 여부 모름
AND
물/먹을거리 거리 모름
```

학생이 선택하기 전에 장단점의 근거를 충분히 봐야 한다.

결과 평등은 필요 없다.

납득 가능한 인과가 필요하다.

---

# 13. 교과서 핵심은 한 분기에 가두지 않는다

Hunt에서 동굴을 못 봤다고 전체 체험에서 `동굴/바위 그늘 생활` 개념을 못 배우면 안 된다.

대체 경로:

- Gather에서 바위 그늘을 이용
- Camp에서 다른 사람이 발견한 장소 이야기
- Common Evening에서 실제 생활 공간 다양성 회수

# **Narrative Variant와 Learning Invariant를 분리한다.**

---

# 14. 실제 유물·유적은 ‘증거의 현실성’을 더한다

체험 후:

- 전곡리 주먹도끼
- 구석기 동굴 유적

등과 연결할 수 있다.

하지만 체험 속 가상의 하루를 실제 특정 유적의 역사적 사건으로 단정하지 않는다.

구조:

```text
내가 겪은 재구성
→ 교과 용어
→ 실제 유물/유적
```

---

# 15. Scene 제작 체크리스트

새 Scene을 만들 때 답한다.

1. 이 Scene의 역사적/교과 핵심은 무엇인가?
2. 학생이 먼저 무엇을 몸으로 경험하는가?
3. 주변 사람은 무엇을 하는가?
4. 학생의 직접 행동은 무엇인가?
5. 세계는 어떻게 반응하는가?
6. 현재 Primary Attention은 하나인가?
7. 용어를 반드시 짚어야 하는가?
8. 그렇다면 어느 순간 짧게 이름을 붙이는가?
9. 그 개념은 나중에 다시 쓰이는가?
10. 선택 결과가 뒤에서 회수되는가?
11. screen treatment가 의미보다 앞서지 않는가?
12. 사실과 재구성이 구분되는가?

# 16. Role별 몰입 문법 요약

## Hunt

- 멀어짐
- 주먹도끼 continuity
- 흔적
- 위험
- 동굴/새 장소 발견
- 귀환

## Gather

- 손과 지면
- 반복 탐색
- 뿌리/열매
- 도구 가공
- 장소 기억

## Camp

- 불
- 막집
- 손질
- 시간 변화
- 기다림
- 재회

같은 Curriculum Anchor가 역할마다 다른 감정과 행동으로 나타나야 한다.

# 17. Stage 07 Skeleton QA 질문

- `뗀석기/주먹도끼` reveal이 너무 교과서 카드처럼 보이지 않는가?
- 도구를 먼저 받은 뒤 이름을 보는가?
- 이름을 본 뒤에도 손에 같은 도구가 남는가?
- 동굴이 실제 공간처럼 보이는가, 단순 아이콘처럼 보이는가?
- 동굴의 장점과 불확실성을 텍스트 없이도 어느 정도 읽을 수 있는가?
- `동굴/바위 그늘` 교과 cue가 탐색 뒤에 나오는가?
- cave 장면이 공포로만 읽히지 않는가?
- 다른 관점으로 전환할 때 발견 정보가 전지적으로 새 인물에게 자동 전달되지 않는가?
- Player 화면에 내부 evidence가 노출되지 않는가?
