# 1. 프로젝트의 출발점

이 프로젝트는 구석기 시대를 설명하는 웹도, 교과서 문제를 게임처럼 꾸민 앱도, 화면 밖에서 캐릭터를 조종하는 일반 게임도 아니다.

# **학생이 구석기 공동체 한 사람의 몸과 눈으로 그 순간을 살아보고, 다른 사람의 관점도 차례로 경험하면서 당시 삶의 조건·도구·관계·위험·감정·판단을 상상하고 이해하는 신체화된 1인칭 역사 체험 웹게임**

이다.

학생의 첫 질문은

> `구석기에는 무엇이 있었지?`

보다

> **`지금 내 앞에서 무슨 일이 일어나고 있지?`**
>
> **`나는 왜 이 사람들과 함께 움직이고 있지?`**
>
> **`이 돌도구는 왜 손에 쥐고 있지?`**
>
> **`이 장소는 왜 머물기에 괜찮아 보이지?`**
>
> **`이 상황에서 나는 어떻게 해야 하지?`**

에 가까워야 한다.

---

# 2. 학습의 핵심 흐름

기본 흐름:

# **Immersion → Historical Imagination → Understanding → Naming / Conceptualization**

학생은 먼저 몸·도구·사람·공간·사건을 경험한다.

그 경험 속에서

- 왜 뗀석기 같은 도구가 필요했는지
- 왜 한 도구를 여러 생활 행동에 활용했는지
- 왜 불이 생활의 중심이었는지
- 왜 막집이나 동굴·바위 그늘 같은 거처가 중요했는지
- 왜 먹을 것을 찾아 이동해야 했는지
- 왜 다른 사람과 함께 판단하고 움직여야 했는지
- 왜 위험과 귀환이 실제 고민이 되었는지

를 자연스럽게 이해한다.

그 뒤 핵심 교과 용어에 **짧고 정확하게 이름을 붙인다.**

예:

```text
먼저 돌도구를 받음
→ 손에 쥐고 이동함
→ '뗀석기 / 주먹도끼'를 짧게 명명
→ 실제 생활 행동에 다시 사용
→ 후속 개념화에서 교과서와 연결
```

# **교과 개념은 숨기지 않는다. 그러나 개념 설명이 체험보다 먼저 세계를 지배하지 않는다.**

Reflection은 필요할 수 있지만 모든 장면 뒤에 강제하지 않는다.

---

# 3. Curriculum / Textbook Anchor

교과서와의 연계는 부가 기능이 아니라 핵심 학습 계약이다.

현재 구석기 체험에서 우선 보존할 Curriculum Anchor:

- **뗀석기**
- **주먹도끼**
- **불의 이용**
- **막집**
- **동굴 / 바위 그늘 생활**
- **먹을 것을 찾아 옮겨 다니는 생활**
- **사냥 + 채집 + 생활 가공**
- **선사 시대의 역사적 재구성이라는 성격**

교과서 Anchor의 기본 문법:

# **Experience → Name → Reuse → Connect**

즉 학생이 먼저 만지고 보고 판단한 뒤, 핵심 용어를 짧게 짚고, 다시 삶 속에서 사용하며, 마지막에 교과 개념과 실제 유물·유적에 연결한다.

세부 기준은 `docs/01E_CURRICULUM_TEXTBOOK_ANCHORS.md`가 소유한다.

# 4. Historical Imagination

학생이 단순히 사실을 암기하는 것보다

> `그 시대 사람이라면 왜 그렇게 했을까?`

를 당시 조건 안에서 상상하게 한다.

좋은 역사적 상상력:

- 당시 이용 가능한 도구와 환경을 고려함
- 먹을거리와 시간의 불확실성을 고려함
- 함께 살아가는 사람들의 관계를 고려함
- 거처가 영구적이고 하나의 형태였다고 단정하지 않음
- 자연 지형을 생활 공간으로 이용할 가능성을 생각함
- 내가 모르는 일이 다른 장소에서 동시에 일어날 수 있음을 이해함
- 한 개인의 재구성된 사건을 시대 전체의 보편 규칙으로 단정하지 않음

# **Historical imagination은 자유로운 판타지가 아니라 역사적 증거와 조건 안에서 가능한 삶을 상상하는 것이다.**

---

# 5. Historical Fact와 Reconstructed Event 구분

교과서·유물·유적이 직접 뒷받침하는 사실과, 프로젝트가 체험을 위해 구성한 하루 사건을 구분한다.

## Historical / Curriculum Fact

예:

- 뗀석기 사용
- 주먹도끼의 다용도성
- 이동 생활
- 막집
- 동굴/바위 그늘 생활
- 불을 이용한 난방·보호·조리

## Reconstructed Event

예:

- R이 아침에 주먹도끼를 건네는 장면
- H1/H2와 특정 흔적을 찾는 하루
- 이동 중 넓은 동굴을 발견하는 사건
- “여기 머물기 괜찮겠다”라고 생각하는 순간
- 특정 날 늦게 돌아와 미안함을 느끼는 사건

# **사실은 학습 불변조건으로 보존하고, 사건은 역사적 상상력을 위한 재구성으로 사용한다.**

---

# 6. Role-True Perspective

역할 진입 시 현재 누구의 관점인지 짧게 알려줄 수 있다.

예:

> **사냥을 나선 사람의 관점**

그 뒤에는 반복 설명하지 않는다.

Hunt를 플레이하면 사냥하는 사람이 실제로

- 보고
- 듣고
- 알고
- 모르는 것
- 걱정하는 것
- 할 수 있는 것

의 범위 안에서 스토리가 진행된다.

Camp에서 벌어지는 실제 내부 상황은 Hunt 시점에서 전지적으로 보여주지 않는다.

나중에 Camp 관점을 플레이하면서 같은 날의 반대편을 새롭게 경험한다.

# **각 역할은 하나의 완전한 제한 시점이다.**

---

# 7. Embodied First-Person

기본 player-facing 시점은 신체화된 1인칭이다.

화면은 단순 풍경이 아니다.

# **환경 + 자연스럽게 보이는 내 몸 + 들고 있는 물건 + 주변 사람 + 행동 + 빛/소리**

가 하나의 장면을 이룬다.

예:

- 불 앞: 손/무릎/불/맞은편 사람
- 도구 전달: 상대 손 + 주먹도끼 + 내 손
- 흔적 관찰: 내 손/무릎 + 지면
- 걷기: 도구 든 손 + 동행자
- 동굴 발견: 내 손/바위 입구/먼저 들어가는 동행자
- 위험: 갑자기 멈춘 몸과 시야
- 귀환: 피로한 팔 + 멀리 보이는 불

몸은 HUD가 아니라 **세계 안에 내가 존재한다는 증거**다.

---

# 8. 핵심 유물은 몸의 일부처럼 반복된다

주먹도끼 같은 핵심 유물은 한 번 설명하고 사라지는 카드가 아니다.

좋은 continuity:

```text
R에게 받음
→ 짧게 '뗀석기 / 주먹도끼' 명명
→ 손에 들고 이동
→ 땅/나무/먹을거리 가공 등에 실제 사용
→ 귀환 때도 같은 도구 유지
→ Camp 또는 Common Evening에서 다시 보임
```

핵심 유물의 학습은

> **이름 + 형태 + 사용 + 상황 + 기억**

이 함께 남아야 한다.

---

# 9. 관계는 핵심 체험 장치다

구석기 생활을 개인 생존 이야기로만 만들지 않는다.

반복 등장하는 사람들과 실제 관계를 만든다.

관계는

- 물건을 주고받고
- 같이 보고
- 같이 움직이고
- 기다리고
- 걱정하고
- 의견이 갈리고
- 새로운 장소를 함께 판단하고
- 이전 선택을 기억하고
- 나중에 다시 만나는

과정으로 생긴다.

호감도 숫자로 표현하지 않는다.

---

# 10. 감정은 제거 대상이 아니다

역사적 상황에서 자연스럽게 생기는 감정을 적극 활용한다.

허용 가능한 핵심 감정:

- 두려움
- 긴장
- 죄책감
- 후회
- 걱정
- 책임감
- 안도
- 애착
- 아쉬움
- 성취감
- 발견의 흥분
- 새로운 장소에 대한 기대와 경계

예:

> 늦게까지 추적한 뒤 돌아오니 누군가 오랫동안 기다리고 있었다.

학생이 미안함이나 죄책감을 느낄 수 있다.

또는:

> 비를 피할 만한 넓은 동굴을 발견했지만 안쪽은 어둡고 다른 동물이 사용했는지 알 수 없다.

학생이 기대와 불안을 동시에 느낄 수 있다.

피할 것은 감정 자체가 아니라

- 모욕
- 낙인
- 심리적 강압
- 죄책감으로 정답을 강요하는 구조

다.

---

# 11. 고민과 선택

학생이 고민해야 하는 것은 버튼 문구가 아니라 상황이다.

좋은 딜레마에서는 동시에 여러 조건이 존재한다.

예: Hunt

- 먹을 것이 필요함
- 흔적은 더 뚜렷해짐
- 해는 낮아짐
- 거처는 멀어짐
- 동행자는 지침
- 누군가는 기다림

예: 동굴 발견

- 넓고 비바람을 피하기 좋아 보임
- 안쪽은 어두움
- 바닥 상태는 확인해야 함
- 동물 흔적 여부를 모름
- 물과 먹을거리까지 거리를 모름
- 지금 거처보다 나을 수도 있음

그 상태에서 판단한다.

모든 선택이 동일하게 좋은 결과를 가질 필요는 없다.

# **Choice Fairness는 결과 평등이 아니라 결과의 납득 가능성이다.**

---

# 12. Persistent Consequence / Reconverging Narrative

기본 구조:

# **Bounded Agency + Persistent Consequence + Emotional Reality + Reconverging Narrative**

완전 자유분기는 만들지 않는다.

같은 거처로 돌아올 수 있다.

하지만 다음은 달라질 수 있다.

- 무엇을 들고 있는가
- 얼마나 늦었는가
- 몸 상태
- 동행자 상태
- 누가 나를 바라보는가
- 어떤 말 또는 침묵이 있는가
- 죄책감/후회/안도
- 새 동굴/바위 그늘을 발견했는가
- 그 장소에 대해 어떤 판단을 했는가
- 다음 관점에서 그 발견이 어떤 의미로 회수되는가

# **같은 장소에 도착해도 같은 이야기가 아니다.**

---

# 13. 위협과 공포

공포게임 같은 순간이 있어도 된다.

특히 Hunt에서는 자연 속 인간의 취약성을 강하게 체감할 수 있어야 한다.

가능한 요소:

- 어둠
- 시야 밖 소리
- 정체를 모르는 움직임
- 동행자의 갑작스러운 정지
- 동굴 안쪽의 알 수 없는 흔적
- 가까워지는 위험
- 순간적 놀람
- 짧은 회피/도주
- strong screen/sound accent
- 사건 뒤 남는 긴장

피할 것:

- 고어와 잔혹함 자체를 볼거리로 삼기
- 의미 없는 jump scare 반복
- 적 HP/처치 중심 구조
- 공포가 시대 경험을 완전히 덮는 구성

# **무서워도 된다. 왜 무서운지가 역사적 상황과 연결되어 있어야 한다.**

---

# 14. Screen Treatment

큰 VFX보다 작은 지각 변화가 기본이지만 강한 순간도 허용한다.

원칙:

# **Subtle by default. Strong when earned.**

강도:

- `none`
- `subtle`
- `accent`
- `strong-accent`

사용 가능:

- 불빛의 색
- 시간대 명암
- 동굴 입구/안쪽의 exposure 차이
- focus/vignette
- blink/fade
- sway/jolt
- 짧은 red/dark accent

강한 효과는 앞선 상황과 사건이 충분히 쌓였을 때 사용한다.

---

# 15. Learning Invariants / Narrative Variants

분기가 달라도 전체 구석기 체험에서 다음 조건은 충분히 드러나야 한다.

## Core Learning Invariants

- **뗀석기와 생활 행동**
- **주먹도끼라는 대표 유물과 다용도 사용**
- **불의 중요성**
- **먹을거리 확보의 불확실성**
- **공동체의 상호의존**
- **자연·시간·거리 제약**
- **막집 + 동굴/바위 그늘이라는 다양한 생활 공간**
- **한 장소 생활 부담의 누적**
- **먹을 것을 찾아 이동하는 생활의 이유**

학생마다 같은 장면·같은 대사·같은 감정을 볼 필요는 없다.

# **공통 역사 조건 + 서로 다른 개인 경험**

을 목표로 한다.

---

# 16. 세 역할

## Hunt

핵심:

**거리 / 흔적 / 추적 / 도구 / 위험 / 발견 / 공포 / 협력 / 귀환**

Curriculum Anchor:

- 뗀석기 / 주먹도끼
- 이동 거리
- 동굴·바위 그늘 발견 가능성
- 불로 돌아가는 귀환

## Gather

핵심:

**가까운 환경 / 분별 / 반복 탐색 / 장소 기억 / 도구 사용 / 범위 확대**

Curriculum Anchor:

- 풀뿌리·열매 등 채집
- 땅파기·두들기기 같은 도구 활용
- 가까운 자원이 줄어드는 경험
- 이동 범위 확대

## Camp

핵심:

**불 / 생활 유지 / 손질 / 거처 / 빈자리 / 시간 / 기다림 / 재회**

Curriculum Anchor:

- 불 유지
- 음식 익히기
- 막집과 임시 거처
- 가죽·도구·먹을거리 손질
- 다른 생활 공간 후보에 대한 공동체 논의

세 역할은 중요도가 동등하지만 같은 플레이 문법을 사용하지 않는다.

---

# 17. Perspective Recontextualization

한 역할에서 몰랐던 사실을 다른 역할에서 새롭게 경험한다.

예:

Hunt에서 멀리 이동하며 동굴을 발견한다.

그 순간 학생은 Camp에 남은 사람들이 그 장소를 어떻게 받아들일지 모른다.

나중에 Camp에서는

- 돌아온 사람들이 새로운 공간을 이야기함
- 현재 막집을 손질하는 수고
- 가까운 자원의 감소
- 새로운 거처 후보의 장단점

을 다른 사람의 몸으로 경험할 수 있다.

같은 사실이 관점에 따라 다른 의미를 가진다.

---

# 18. 거처는 하나의 정답이 아니다

구석기 주생활을

> `막집 = 정답`

또는

> `동굴 = 정답`

으로 단순화하지 않는다.

환경·이동·자원·안전 조건에 따라

- 한데의 임시 막집
- 동굴
- 바위 그늘

등을 이용할 수 있었다는 생활 적응으로 이해하게 한다.

동굴 발견 장면의 목적은

> `구석기인은 동굴에서 살았다.`

를 외우게 하는 것이 아니라

> **`왜 이런 자연 공간을 생활에 이용했을지`**

를 직접 판단하게 하는 것이다.

---

# 19. 실제 유물·유적과의 연결

체험 속 하루는 특정 유적의 역사적 사건을 그대로 재현했다고 주장하지 않는다.

실제 자료는 후속 연결에 사용한다.

예:

- 전곡리에서 발견된 주먹도끼
- 단양 금굴 유적 같은 구석기 동굴 유적

구조:

```text
재구성된 체험
→ 용어·개념 명명
→ 실제 유물/유적 연결
```

이때 학생이 `내가 방금 실제 전곡리의 특정 인물이었다`고 오해하지 않게 한다.

---

# 20. 학생 경험과 교사/Debug 정보 분리

Player 화면:

- 시대 체험에 필요한 짧은 용어 reveal은 가능
- Stage 번호·내부 state·evidence ID는 노출하지 않음

Teacher/Debug:

- 어떤 Curriculum Anchor를 경험했는지 확인 가능
- source / reconstruction 구분 QA 가능
- reduced effects와 테스트 상태 확인 가능

---

# 21. 금지되는 방향

- 교과서 문장을 그대로 장문 팝업으로 반복
- 모든 장면을 OX/객관식 문제로 전환
- 주먹도끼를 한 번 보여주고 다시 쓰지 않음
- 막집과 동굴을 서로 배타적인 정답으로 제시
- 동굴을 무조건 안전하고 좋은 새 집으로 확정
- 실제 유적과 재구성된 스토리를 구분하지 않음
- 교과 연계를 위해 관계·위험·스토리를 중단
- 학생이 용어를 모른다는 이유로 몰입 장면마다 설명을 먼저 띄움

---

# 22. Stage 01 Acceptance Gate

Stage 01은 다음을 만족해야 한다.

- 신체화된 1인칭이 기본인가?
- 역할 내부가 제한 시점을 지키는가?
- 관계와 감정이 실제 사건에서 생기는가?
- 죄책감·공포·후회 같은 감정을 역사적 맥락 안에서 허용하는가?
- 선택 결과가 점수보다 질적 결과로 남는가?
- `뗀석기`, `주먹도끼`를 명확히 짚되 설명이 체험을 지배하지 않는가?
- 주먹도끼가 반복적인 생활 행동 속에서 사용되는가?
- 불이 배경이 아니라 생활 기능으로 경험되는가?
- 막집과 동굴/바위 그늘을 모두 구석기 생활 공간으로 다루는가?
- 동굴 발견이 탐색·판단·관계 사건으로 설계되는가?
- 이동 생활이 거리·자원·거처 문제로 체감되는가?
- 사실과 재구성을 구분하는가?
- Student Play Order와 World Time을 혼동하지 않는가?
- 몰입과 학습이 서로 경쟁하지 않고 연결되는가?

이 Gate를 통과한 설계만 Stage 02 이후의 기준이 된다.
