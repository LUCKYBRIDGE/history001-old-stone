# 1. 프로젝트의 출발점

이 프로젝트는 구석기 시대를 설명하는 웹도, 화면 속 캐릭터를 조종하는 일반 게임도 아니다.

# **학생이 같은 공동체의 여러 사람의 몸과 눈을 잠시 빌려 그들의 하루를 직접 살아보고, 그 경험을 다른 관점과 연결한 뒤 역사 개념으로 정리하는 신체화된 1인칭 역사 체험 웹게임**

이다.

학생의 첫 질문은

> `구석기 사람들은 무엇을 사용했지?`

보다

> **`지금 내 앞에서 무슨 일이 일어나고 있지?`**
>
> **`저 사람과 나는 왜 함께 움직이고 있지?`**
>
> **`이 상황에서 나는 무엇을 해야 하지?`**

에 가까워야 한다.

그러나 몰입 자체가 교육 목표는 아니다.

## **Experience → Reflection → Historical Concept**

까지 이어져야 학습이 완성된다.

---

# 2. 대상과 사용 맥락

주 대상은 **초등학생**이다.

따라서 다음을 기본 전제로 둔다.

- 긴 텍스트보다 관찰·행동·짧은 대사
- 조작 숙련보다 상황 판단
- 공포/전투보다 생활·협력·불확실성
- 숨겨진 인터페이스보다 자연스럽지만 발견 가능한 행동
- 점수 경쟁보다 서로 다른 경험을 비교하는 토론
- 교사가 수업에서 재시작·관찰·효과 저감을 할 수 있는 구조

학생이 UI를 이해하느라 역사적 상황을 놓치면 실패다.

---

# 3. 최상위 학습 메커니즘

# **내 몸으로 상황에 들어간다 → 사람과 관계를 맺는다 → 주변을 관찰한다 → 고민이 생긴다 → 판단하고 행동한다 → 세계와 사람이 반응한다 → 결과의 흔적을 기억한다 → 다른 관점에서 다시 본다 → 짧게 성찰한다 → 역사적 이유와 개념을 이해한다**

피해야 할 구조:

- 설명 → 문제 → 정답
- 시대 정보 → 퀴즈
- 긴 텍스트 → 다음 버튼
- 선택 → 점수
- NPC 소개 카드 → 호감도
- 위험 설명 → 공격 버튼
- 성공/실패 두 화면으로 끝
- 몰입 장면만 보여주고 역사적 정리를 생략

# 4. 네 가지 비타협 기준

프로젝트의 모든 기능은 다음 네 축을 동시에 만족해야 한다.

## Historical Integrity

확인 가능한 역사 사실과 재구성을 구분한다.

## Learner Safety & Accessibility

초등학생에게 불필요한 공포·신체적 불편·접근성 장벽을 만들지 않는다.

## Learning Clarity

학생이 세계 안에서 무엇을 볼 수 있고 무엇을 할 수 있는지 이해할 수 있다.

## Embodiment & Agency

학생의 몸과 판단이 세계 안에서 의미 있는 행동으로 느껴진다.

몰입이 나머지 세 기준을 침해하면 몰입 연출을 줄인다.

---

# 5. Learning Invariants와 Narrative Variants

분기가 많아져도 역사 학습이 운에 따라 사라지면 안 된다.

## Learning Invariants — 경로와 무관하게 보존할 핵심

- 도구가 실제 생활 행동과 연결됨
- 불이 생활의 중요한 요소로 사용됨
- 먹을거리 확보가 언제나 확실하지 않음
- 여러 사람이 서로 다른 일을 하며 의존함
- 자연·시간·거리 조건을 완전히 통제할 수 없음
- 한 장소에서 계속 생활하기 어려워지는 맥락이 누적됨
- 이동 생활이 앞선 경험과 연결됨

## Narrative Variants — 학생 경험에 따라 달라질 수 있음

- 관계 반응
- 대사
- 귀환 시점
- 위험 노출
- 몸의 피로/운반 상태
- 들고 돌아오는 것
- 같은 저녁의 분위기
- 다음 관점에서 회수되는 장면

# **선택은 역사적 사실을 바꾸는 것이 아니라 같은 생활 조건을 다른 개인적 경험으로 만나게 한다.**

---

# 6. 기본 시점 — Embodied First-Person

기본 player-facing 시점은 **신체화된 1인칭**이다.

화면은 단순 풍경이 아니라

## **환경 + 자연스럽게 보이는 내 신체 일부 + 들고 있는 물건 + 내 앞의 사람 + 현재 행동 + 빛/소리/상태**

가 한 장면을 이룬다.

예:

- 불 앞: 두 손 + 무릎 + 불 + 맞은편 사람
- 도구 전달: 상대 손 + 도구 + 내 손
- 흔적 관찰: 아래로 향한 시야 + 손/무릎 + 지면
- 걷기: 도구 든 손 + 앞의 동행자 + 이동하는 환경
- 귀환: 피로한 팔/운반 상태 + 멀리 보이는 거처

몸은 HUD가 아니다.

# **몸은 존재감과 행동·피로·긴장·부담을 보여주는 세계 안의 증거다.**

세부는 `01A`를 따른다.

---

# 7. Player Body Identity는 사회적 역할을 고정하지 않는다

역할마다 다른 사람의 몸을 사용할 수 있지만 그 몸이 근거 없는 역사적 고정관념을 가르치면 안 된다.

- Hunt = 남성, Gather/Camp = 여성 같은 기본 배치 금지
- 특정 연령/성별/친족 구조가 학습에 필요하지 않으면 과도한 외형 표지를 피함
- 피부·의복·장식은 역사/지역 검토 전에 확정하지 않음
- 다른 몸은 관점 차이를 만들지만 역할의 중요도·용기·능력 차이를 암시하지 않음

---

# 8. 역할 전환은 다른 사람의 관점으로 이동하는 것

Hunt / Gather / Camp는 같은 사람이 하루 동안 세 업무를 하는 구조가 아니다.

# **같은 공동체의 같은 하루를 서로 다른 구성원의 몸과 눈으로 경험한다.**

한 관점에서 본 사람이 다음 관점에서는 `나`가 될 수 있다.

관점 전환은

- 같은 사람
- 같은 불/물건
- 같은 소리/대사
- 같은 사건의 반대편 위치
- 달라진 손/몸

을 이용해 연결한다.

몰입을 지키기 위해 설명을 숨기는 것보다, 혼란이 생기면 짧은 orientation 문장을 허용한다.

예:

> 같은 아침. 이번에는 불 옆이다.

---

# 9. 관계는 핵심 학습 장치다

관계는 호감도 시스템이 아니다.

# **관계 = 함께 겪은 사건을 서로 기억하고 이후의 시선·행동·대사·기다림의 의미가 달라지는 것**

이다.

관계가 느껴지는 방식:

- 서로 바라봄
- 물건을 주고받음
- 함께 같은 대상을 봄
- 위험에서 위치를 조정함
- 판단을 기억함
- 귀환 뒤 반응이 달라짐
- 다른 역할에서 그 사람의 시간을 다시 경험함

관계는 선택의 무게를 만들되 학생에게 죄책감을 강요하거나 도덕적 정답을 강제하지 않는다.

세부는 `01B`, 정서 안전은 `01D`를 따른다.

---

# 10. 위협은 설명 전에 상황으로 느껴져야 한다

기본 문법:

# **이상한 징후 → 주변 사람의 행동 변화 → 내 몸의 반응 → 내 관찰 → 불확실성 → 판단**

위험은 전투 이벤트가 아니다.

목표는

# **자연 속에서 사람도 완전히 통제할 수 없는 조건에 놓였지만 관찰·도구·협력·판단으로 살아갔다는 감각**

이다.

초등학생용 위협은 비그래픽 긴장 수준을 기본으로 하고 고어·반복 jump scare·장시간 공포·죽음 게임오버를 사용하지 않는다.

---

# 11. 고민은 가치 충돌이어야 한다

좋은 선택은 `좋은 답 / 나쁜 답`이 아니다.

예: Hunt

- 흔적은 더 분명함
- 먹을 것이 필요함
- 해는 낮아짐
- 거처는 멀어짐
- 동행자는 지침
- 기다리는 사람이 있음

이 정보가 먼저 존재한 뒤 학생이 판단한다.

선택은 적어도 둘 이상의 합리적 이유를 가져야 한다.

금지:

- 용감/비겁 라벨
- 좋은 아이/나쁜 아이 라벨
- 특정 선택만 핵심 콘텐츠/관계를 독점
- 관찰할 수 없었던 정보 때문에 학생을 사후 처벌

---

# 12. Bounded Agency + Persistent Consequence + Reconverging Narrative

완전 자유분기로 개발량을 폭발시키지 않는다.

큰 흐름은 다시 만날 수 있지만 선택 흔적은 남는다.

예:

- 먹을 것을 구함 + 일찍 귀환
- 먹을 것을 구함 + 늦은 귀환
- 빈손 + 위험을 크게 피함
- 빈손 + 멀리까지 추적
- 동행자와 운반 부담을 나눔

같은 거처에 돌아와도

- 몸 상태
- 들고 있는 것
- 동행자의 반응
- 기다리던 사람의 말
- 저녁 분위기
- 다음 관점에서 보이는 흔적

이 달라질 수 있다.

# **같은 장소에 도착해도 같은 이야기는 아니다.**

---

# 13. Perspective Recontextualization

학생은 이전 행동의 의미를 점수표가 아니라 **다른 사람의 시간**을 통해 다시 생각한다.

예:

Hunt에서 더 오래 추적해 늦게 돌아옴.

Camp에서는 같은 시간 동안

- 낮아지는 해
- 비어 있는 자리
- 바깥을 보는 사람
- 계속 이어가야 하는 생활
- 돌아오지 않는 사람에 대한 걱정

을 경험한다.

이 장치는 학생을 비난하기 위한 것이 아니라 **한 선택에 여러 사람의 관점이 존재함을 이해하게 하는 것**이다.

---

# 14. Subtle Screen Treatment

화려한 VFX 없이도 작은 지각 변화로 몸과 상황을 강화할 수 있다.

허용 예:

- 불의 따뜻한 색
- 새벽/해질녘의 점진적 색온도 변화
- 위협을 알아차린 뒤의 아주 약한 focus/vignette 변화
- 피로한 귀환의 미세 sway
- 자세/시간/관점 전환의 짧은 blink
- 먼 불빛 발견 뒤의 미세 밝기 회복

원칙:

# **World → Body/Actor → Perception Treatment**

순서로 의미가 형성된다.

효과가 먼저 `위험`, `피로`, `정답`을 알려주지 않는다.

빠른 flashing, HP식 red damage flash, 강한 지속 shake/blur/zoom은 사용하지 않는다.

세부는 `01C`, 접근성 상한은 `01D`를 따른다.

---

# 15. Clarity와 Progressive Scaffolding

몰입은 조작법을 숨기는 것이 아니다.

학생은 최소한 다음을 이해할 수 있어야 한다.

- 지금 어디에 있는가
- 무엇을 살펴보거나 할 수 있는가
- 왜 지금 행동할 이유가 있는가

지원 순서:

1. 사람/환경의 자연스러운 유도
2. 은은한 시각 cue
3. 짧은 행동 문구
4. 반복 막힘 시 명확한 hint

중요한 상호작용을 pixel hunting으로 만들지 않는다.

장면마다 **Primary Attention Target**을 하나 정해 몸·NPC·사운드·효과·텍스트가 서로 경쟁하지 않게 한다.

---

# 16. 세 역할은 동등하지만 몸·관계·고민의 문법은 다르다

## Hunt

**멀어짐 / 흔적 / 추적 / 위험 / 협력 / 귀환**

몸: 걷기, 몸 낮추기, 도구, 긴장, 운반, 피로.

## Gather

**가까운 공간 / 반복 탐색 / 분별 / 작은 발견 / 범위 확대 / 돌아갈 시간**

몸: 손으로 살피기, 담기, 반복해서 자세 바꾸기, 장소 비교.

## Camp

**불 / 생활 유지 / 손질 / 빈자리 / 시간 / 기다림 / 재회**

몸: 불 가까이의 손, 손질, 같은 공간의 자세 변화, 멀리 바라보기, 물건 받기.

먼저 개발된 Hunt의 플레이 문법을 다른 역할에 복제하지 않는다.

---

# 17. 핵심 단위는 하나의 공동체가 보내는 하루

세 역할은 독립 게임 세 개가 아니다.

공통 저녁은 결과표가 아니라

# **서로 다른 하루와 관계 기억이 다시 같은 사람들 사이에서 만나는 장면**

이어야 한다.

학생은 `내 역할이 전체 생활의 전부가 아니었다`는 것을 사람·물건·몸 상태·대사로 느껴야 한다.

---

# 18. 성공과 실패를 다시 정의한다

이 프로젝트에는 `완벽한 하루`가 없다.

- 사냥에 성공해도 늦을 수 있음
- 빈손이어도 위험을 피하고 일찍 돌아올 수 있음
- 많이 가져와도 운반 부담이 커질 수 있음
- 한 역할의 부족을 다른 역할이 일부 메울 수 있음

결과는 승패보다 **공동체가 어떤 상태로 저녁을 맞았는가**로 본다.

금지:

- GAME OVER
- HP/EXP/랭킹/별점
- 최적 선택 루트
- 하나의 진짜 엔딩

---

# 19. 이동 생활은 누적된 맥락의 결론

학생에게 처음부터 `구석기 사람들은 이동 생활을 했다`는 답을 주지 않는다.

며칠의 변화에서

- Hunt의 거리/귀환 부담
- Gather의 탐색 범위 변화
- Camp의 기다림/생활 부담
- 여러 역할 결과의 상호의존

이 쌓인 뒤 공동체 질문이 생긴다.

# **“여기서 계속 살아갈 수 있을까?”**

이동은 단일 실패나 정답 버튼 때문에 일어나지 않는다.

---

# 20. 역사적 사실과 재구성

내부 태그:

- `[교과서]` — 직접 확인되는 핵심 역사 사실
- `[재구성]` — 사실과 충돌하지 않는 가상 인물·관계·하루·대사·사건
- `[게임]` — 관찰·선택·분기·연출

근거 없이 사실처럼 단정하지 않을 것:

- 친족 관계
- 족장/권력 구조
- 성 역할
- 특정 연령의 역할
- 특정 동물·식생·계절
- 의복/장식 세부

학생 화면에 태그를 계속 띄우지는 않지만 교사/개념화 단계에서는 **우리가 아는 것과 재구성한 것**을 구분할 수 있어야 한다.

---

# 21. Reflection / Historical Concept Bridge

몰입 이후 반드시 짧은 reflection이 온다.

좋은 질문:

- 왜 더 따라갈지 돌아갈지 고민했어?
- 사냥하지 않은 사람들의 일은 왜 필요했을까?
- 같은 사건을 다른 사람의 입장에서 보니 무엇이 달랐어?
- 왜 이곳에서 계속 지내기 어렵다고 느꼈어?

그 뒤 교과 개념을 학생의 플레이 기억에 연결한다.

개념화는 시험이 아니라 **내가 겪은 일에 역사적 이름을 붙이는 단계**다.

---

# 22. 접근성과 정서 안전

- 효과를 꺼도 모든 정보와 진행이 유지됨
- `prefers-reduced-motion` 또는 동등한 저감 설정 지원 가능
- 빠른 반복 flashing 금지
- 색 하나에 핵심 의미 의존 금지
- 강한 blur/shake로 조작 방해 금지
- 고어/그래픽 부상/반복 jump scare 금지
- 관계를 이용한 모욕·죄책감 조작 금지
- 학생이 막힐 때 단계적 도움 제공

몰입 완성보다 먼저 통과해야 할 기준이다.

---

# 23. 최종 성공 기준

학생이 체험 후 다음과 비슷하게 말할 수 있으면 성공에 가깝다.

> “내가 진짜 거기 있는 것 같았어.”

> “그 사람이 기다리고 있어서 늦게 가는 게 신경 쓰였어.”

> “더 따라가면 얻을 수도 있었는데 해가 져서 고민됐어.”

> “사냥할 때는 몰랐는데 기다리는 쪽에서 해보니까 생각이 달라졌어.”

> “빈손이라고 무조건 실패는 아닌 것 같아.”

> “사람들이 서로 다른 일을 해서 같이 살 수 있었던 것 같아.”

> “그래서 계속 같은 곳에만 있기는 어려웠을 것 같아.”

그리고 최종 판정은 다음이다.

# **학생이 역사 개념을 화면에서 읽어서 말하는가, 아니면 자기 몸·관계·판단·다른 관점에서 겪은 일을 근거로 말하는가?**
