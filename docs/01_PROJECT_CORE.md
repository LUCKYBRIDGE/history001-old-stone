# 1. 프로젝트의 출발점

이 프로젝트는 구석기를 설명하는 웹도, 교과서 문제를 게임처럼 꾸민 앱도, 화면 밖에서 캐릭터를 조종하는 일반 게임도 아니다.

# **학생이 구석기 공동체 한 사람의 몸과 눈으로 그 순간을 살아보고, 다른 사람의 관점도 차례로 경험하면서 당시 삶의 조건·도구·관계·위험·감정·판단을 상상하고 이해하는 신체화된 1인칭 역사 체험 웹게임**

이다.

학생의 첫 질문은:

- 지금 내 앞에서 무슨 일이 일어나고 있지?
- 나는 왜 이 사람들과 함께 움직이지?
- 이 돌도구는 왜 손에 있지?
- 이 공간은 왜 머물 만해 보이지?
- 이 상황에서 무엇을 해야 하지?

에 가까워야 한다.

# 2. 학습 흐름

# **Immersion → Historical Imagination → Understanding → Naming / Conceptualization**

교과 연결은:

# **Experience → Name → Reuse → Connect**

로 진행한다.

학생은 먼저 몸·도구·사람·공간·사건을 경험한다.

그 경험 속에서:

- 왜 뗀석기 같은 도구가 필요했는지
- 왜 한 도구를 여러 생활 행동에 활용했는지
- 왜 불이 중요한지
- 왜 임시 거처와 자연 거처가 중요했는지
- 왜 먹을 것을 찾아 이동했는지
- 왜 사람들과 함께 판단하고 움직였는지
- 왜 위험·거리·귀환이 실제 고민이 되었는지

를 이해한다.

그 뒤 핵심 용어를 짧고 정확하게 붙인다.

# **교과 개념은 숨기지 않는다. 그러나 개념 설명이 체험보다 먼저 세계를 지배하지 않는다.**

# 3. Curriculum Anchor

현재 핵심:

- 뗀석기
- 주먹도끼
- 불의 이용
- 막집
- 동굴 / 바위 그늘 생활
- 먹을 것을 찾아 옮겨 다니는 생활
- 사냥·채집·생활 가공
- 선사 시대의 재구성 성격

정확한 도구 관계:

```text
뗀석기
└─ 대표적인 예: 주먹도끼
```

좋은 명명:

> **뗀석기**  
> 돌을 깨뜨리거나 떼어 만든 도구를 뗀석기라고 한다. 지금 손에 든 것은 그 대표적인 예인 **주먹도끼**다.

금지:

- `뗀석기 = 주먹도끼`
- 두 용어를 관계 설명 없이 같은 급으로 병렬 제시

세부는 `docs/01E_CURRICULUM_TEXTBOOK_ANCHORS.md`가 소유한다.

# 4. Historical Imagination

역사적 상상력은 자유 판타지가 아니다.

좋은 상상력은:

- 당시 이용 가능한 도구와 환경을 고려하고
- 먹을거리·시간·거리의 불확실성을 고려하고
- 공동체 관계를 고려하고
- 거처가 하나의 고정 형태였다고 단정하지 않고
- 자연 지형을 생활 공간으로 이용할 가능성을 생각하고
- 다른 장소에서 동시에 다른 일이 일어날 수 있음을 이해하고
- 한 재구성 사건을 시대 전체의 보편 규칙으로 확대하지 않는다.

# **Historical Imagination = 역사적 증거와 조건 안에서 가능한 삶을 상상하는 것**

---

# 5. Fact와 Reconstruction

## Historical / Curriculum Fact

예:

- 뗀석기 사용
- 주먹도끼의 다용도성
- 이동 생활
- 막집
- 동굴/바위 그늘 생활
- 불의 이용

## Reconstructed Event

예:

- R/H1/H2라는 인물
- R이 특정 아침에 주먹도끼를 건네는 사건
- 특정 Hunt에서 자연 거처 후보를 발견하는 사건
- 특정 날 늦게 돌아와 미안함을 느끼는 사건

# **사실은 학습 불변조건으로, 사건은 역사적 상상력을 위한 재구성으로 다룬다.**

Player는 매 장면 `[재구성]` 라벨로 끊지 않는다.
Teacher/Debug에서는 경계를 확인 가능하게 한다.

# 6. Role-True Perspective

역할 진입 시 현재 누구의 관점인지 짧게 알려줄 수 있다.

예:

> **사냥을 나선 사람의 관점**

그 뒤에는 그 사람이 실제로:

- 보고
- 듣고
- 알고
- 모르는 것
- 걱정하는 것
- 할 수 있는 것

범위에서 진행한다.

다른 역할의 사건은 나중에 그 역할을 플레이하면서 새롭게 이해한다.

# 7. Same-Day World

# **Student Play Order ≠ In-World Time**

```text
Same Day 1
├─ Hunt
├─ Gather
└─ Camp
```

- 역할 완료는 play progress.
- 역할마다 새로운 하루가 시작되지 않음.
- role order가 달라도 같은 `dayId`.
- cross-role signal이 이미 일어난 과거를 소급 변경하지 않음.

# 8. Embodied First-Person

기본 player-facing 장면:

# **환경 + 자연스럽게 보이는 내 몸 + 들고 있는 물건 + 주변 사람 + 행동 + 빛/소리**

예:

- 불 앞: 손/무릎/불/사람/현재 임시 거처
- 도구 전달: 상대 손 + 돌도구 + 내 손
- 흔적 관찰: 손/무릎 + 지면
- 걷기: 주먹도끼 든 손 + 동행자
- 자연 거처 발견: 내 몸 + 바위 입구 + 반응하는 동행자
- 위험: 멈춘 몸과 시야
- 귀환: 피로한 팔 + 불빛

몸은 HUD가 아니라 세계 안에 내가 존재한다는 증거다.

---

# 9. 핵심 유물의 continuity

주먹도끼 같은 핵심 유물은 설명 후 사라지는 카드가 아니다.

```text
R에게 받음
→ 뗀석기 상위 개념 + 주먹도끼 대표 예 명명
→ 손에 들고 이동
→ Stage 08 이후 땅파기·두들기기·자르기/손질 등에 실제 사용
→ 귀환 때 continuity
→ 다른 역할/저녁에서 다시 등장
```

학습은:

> **이름 + 형태 + 사용 + 상황 + 기억**

이 함께 남아야 한다.

Stage 07의 `receive/naming proof`를 `실제 다용도 사용 학습 완료`로 과장하지 않는다.

# 10. 거처의 다양성

공식 용어:

- **현재 임시 거처**: Stage 07 초기 player-facing 중립 표현
- **막집**: Camp에서 실제 생활/손질 뒤 명명할 교과 용어
- **동굴 / 바위 그늘**: 자연 지형을 이용한 생활 공간

# **막집과 동굴/바위 그늘은 경쟁 정답이 아니다.**

동굴 발견은:

```text
공간 발견
→ 넓이/바닥/바람/어둠/흔적/거리 살핌
→ 생활 가능성 판단
→ 짧은 역사 개념 연결
```

로 경험한다.

새 장소 발견 즉시 이사 완료로 만들지 않는다.

# 13. 고민과 선택

학생이 고민해야 하는 것은 버튼 문구가 아니라 상황이다.

좋은 선택 전에는 여러 조건이 동시에 존재한다.

예: Hunt

- 먹을 것이 필요함
- 흔적은 이어짐
- 해가 낮아짐
- 거처는 멀어짐
- 동행자는 지침
- 누군가는 기다림

# **Choice Fairness = 결과 평등이 아니라 인과의 납득 가능성**

더 나쁜 결과나 후회도 가능하다.

---

# 14. Threat / Horror

공포게임 같은 순간을 허용한다.

- 어둠
- 시야 밖 소리
- 갑작스러운 정적
- 미지의 안쪽
- 가까워지는 위험
- 짧은 회피/도주
- rare strong-accent

위협은 UI 경고가 아니라 세계의 징후와 사람/몸 반응에서 시작한다.

동굴을 항상 공포 장소로 고정하지 않는다.

# 15. Screen Treatment

# **Subtle by default. Strong when earned.**

효과는 세계 사건을 대신하지 않는다.

순서:

```text
World / Actor
→ Body
→ Treatment
```

Reduced Effects에서도 사건·판단·학습이 유지돼야 한다.

# 16. Scene ≠ Beat

## Scene

- 목표
- 직접 행동
- 위치/시간
- 결과
- relationship/world memory

가 의미 있게 달라지는 상태 단위.

## Beat

- actor stop
- gaze
- sound drop
- dialogue
- body shift
- terminology reveal
- focus/jolt

같은 Scene 내부 표현 변화.

# 17. 세 역할의 차이

## Hunt

거리 / 흔적 / 주먹도끼 / 추적 / 위험 / 새 장소 / 귀환

## Gather

가까운 관찰 / 채집 / 도구 재사용 / 가공 / 반복 / 공간 기억 / 범위 확대

## Camp

불 / 현재 임시 거처 / 막집 / 생활 유지 / 손질 / 시간 / 빈자리 / 기다림 / 재회 / 새 장소 재평가

Hunt의 추적/공포 구조를 다른 역할에 복제하지 않는다.

# 18. 몰입과 교과의 우선순위

Textbook Anchor가 스토리를 지배하지 않는다.

좋은 순서:

```text
좋은 역사적 상황
→ 필요한 실제 물건/행동/공간
→ 교과서 핵심이 자연스럽게 들어감
→ 경험 뒤 짧게 이름 붙임
```

피할 것:

```text
가르칠 단어 목록
→ 단어마다 장면 강제 생성
```

# 21. Stage 01 Acceptance Gate

- 프로젝트가 외부 관찰형 학습이 아닌가?
- 역할 제한 시점이 명확한가?
- 몸/사람/도구/공간이 하나의 체험으로 연결되는가?
- `뗀석기 → 주먹도끼` 관계가 정확한가?
- 현재 임시 거처/막집/동굴·바위 그늘 용어가 혼동되지 않는가?
- 사실과 재구성이 구분되는가?
- 공포·죄책감 등 감정이 역사적 조건에 연결되는가?
- 선택 결과가 인과적으로 납득 가능한가?
- 교과 용어가 경험보다 먼저 세계를 지배하지 않는가?
- 자동 구현 proof와 실제 학습 완료를 구분하는가?

이 Gate를 이후 모든 Stage가 보존한다.
