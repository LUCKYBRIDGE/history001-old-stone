# 1. 가장 중요한 우선순위

이 프로젝트에서 몰입은 중요한 학습 장치지만 절대 목표가 아니다.

다음 네 가지는 동시에 만족해야 한다.

1. **Historical Integrity** — 역사적으로 확인 가능한 것과 재구성을 구분한다.
2. **Learner Safety & Accessibility** — 학생에게 신체적·정서적 불편을 강요하지 않는다.
3. **Learning Clarity** — 학생이 세계 안에서 무엇을 보고 무엇을 할 수 있는지 이해할 수 있다.
4. **Embodiment & Agency** — 학생이 자기 몸과 선택이 있는 상황으로 경험한다.

충돌할 경우:

- 몰입 때문에 역사적 사실을 왜곡하지 않는다.
- 몰입 때문에 진행 방법을 지나치게 숨기지 않는다.
- 몰입 때문에 위험·깜빡임·흔들림을 과도하게 만들지 않는다.
- 접근성을 위해 몰입 효과를 줄여도 핵심 학습은 유지되어야 한다.

## **Immersion is a means, not the curriculum.**

---

# 2. 학습 불변조건과 서사 변주를 분리한다

비획일적 결과를 강화해도 모든 경로에서 핵심 역사 학습이 사라지면 안 된다.

## Learning Invariants

역할/전체 체험에서 반드시 경험하거나 뒤에서 개념화해야 하는 핵심 증거.

예:

- 도구가 생활 행동과 연결됨
- 불이 생활의 중심 요소로 사용됨
- 먹을거리 확보가 확실하지 않음
- 여러 사람이 서로 다른 일을 하며 의존함
- 자연과 시간·거리 조건을 완전히 통제할 수 없음
- 한 장소에서 계속 생활하기 어려워지는 맥락이 누적됨
- 이동 생활이 앞선 경험과 연결됨

## Narrative Variants

학생 선택에 따라 달라질 수 있는 것.

- 누가 먼저 반응하는가
- 어떤 대사가 나오는가
- 귀환 시점
- 관계 기억
- 위험을 얼마나 가까이 경험했는가
- 무엇을 들고 돌아오는가
- 같은 저녁의 분위기

원칙:

## **분기는 역사적 사실을 바꾸는 것이 아니라, 같은 생활 조건을 서로 다른 개인적 경험으로 만나게 한다.**

# 3. 초등학생용 Clarity Gate

학생이 몰입하려면 먼저 막히지 않아야 한다.

학생은 항상 다음 세 질문에 최소한의 답을 얻을 수 있어야 한다.

- 지금 어디쯤 있는가?
- 무엇을 살펴보거나 할 수 있는가?
- 왜 지금 그것을 할 이유가 있는가?

이를 위해 다음을 허용한다.

- 시선/사람의 손짓
- 은은한 hotspot 반응
- 짧은 동행자 행동
- 필요한 경우 한 줄 이하의 관찰 문장
- 같은 행동에서 두 번 이상 막힐 때 단계적 hint

피할 것:

- pixel hunting
- 중요한 조작을 설명 없이 숨김
- 클릭 가능한 것과 배경이 구별되지 않아 반복 오작동
- 관계/서사를 핑계로 튜토리얼을 완전히 제거

## **Diegetic 우선이지만, 이해 불가능한 diegetic UI보다 명확한 최소 UI가 낫다.**

---

# 4. Progressive Scaffolding

처음부터 모든 조작과 정보를 보여주지 않는다.

기본 단계:

1. **환경/사람이 먼저 유도**
2. **미세한 시각 cue**
3. **짧은 행동 문구**
4. **필요한 경우 명확한 hint**

한 번에 너무 많은 선택·단서·텍스트를 경쟁시키지 않는다.

중요한 딜레마에서는 선택지를 읽기 전에 이미 상황 정보를 충분히 보게 한다.

반대로 학생이 정보를 놓쳤을 때는 다시 살펴볼 기회를 제공한다.

---

# 5. 인지부하 Budget

몰입 요소가 많아질수록 다음이 동시에 경쟁할 수 있다.

- 몸
- NPC
- 환경 단서
- 대사
- 소리
- 화면 효과
- 선택지

따라서 장면마다 **Primary Attention Target**을 하나 정한다.

예:

- 도구 전달 장면: `상대 손 → 도구 → 내 손`
- 위협 build-up: `동행자의 멈춤 → 이상한 방향`
- 귀환: `멀리 보이는 불빛`

보조 효과는 Primary Target을 가리지 않는다.

학생이 한 장면에서 `무엇을 봐야 하는지`를 찾느라 역사적 판단을 놓치면 설계 실패다.

---

# 6. Player Body Identity의 역사·표현 안전성

1인칭 몸이 강해질수록 학생은 몸의 특징을 역사적 사실로 받아들일 수 있다.

초기 기본 원칙:

- 특정 성별 역할을 몸 외형으로 고정하지 않는다.
- Hunt = 남성, Gather/Camp = 여성 같은 배치를 기본값으로 만들지 않는다.
- 나이·성별·친족 관계가 학습에 필수적이지 않으면 과도한 시각 표지를 줄인다.
- 피부·의복·장식의 세부는 시대/지역 근거 검토 전 확정하지 않는다.
- 역할별 다른 몸을 사용하더라도 `능력/용기/중요도`의 차이로 읽히지 않게 한다.

## **Body identity는 관점 차이를 만드는 장치이지 사회적 역할 고정관념을 가르치는 장치가 아니다.**

---

# 7. Perspective Transition Clarity

다른 사람의 몸으로 전환하는 구조는 강력하지만 초등학생에게 혼란을 줄 수 있다.

따라서 관점 전환은 다음 anchor 중 2개 이상을 사용한다.

- 같은 사람
- 같은 불/물건
- 같은 대사/소리
- 같은 사건의 반대편 위치
- 다른 손/몸의 명확한 변화

필요한 경우 짧은 문장으로 최소한의 orientation을 허용한다.

예:

> 같은 아침. 이번에는 불 옆이다.

이 문장은 `역할 설명 화면`이 아니라 시점 혼란을 막는 scaffold다.

학생이 `왜 갑자기 손이 바뀌었지?`만 생각한다면 Perspective Recontextualization은 실패다.

---

# 8. 관계의 정서적 안전

관계는 학생에게 선택의 의미를 느끼게 해야 하지만 죄책감을 조작하는 장치가 되어서는 안 된다.

금지:

- 선택 하나 때문에 NPC가 학생을 모욕/비난
- `네가 잘못해서 모두가 굶었다` 같은 과도한 책임 전가
- 특정 선택을 도덕적으로 열등하게 만드는 연출
- 반복적인 불안/걱정으로 학생을 압박해 정답 루트를 유도

허용:

- 걱정
- 아쉬움
- 의견 차이
- 결과의 부담
- 서로 다른 판단

## **관계는 판단의 무게를 만들되 학생을 처벌하지 않는다.**

---

# 9. Threat Intensity Ceiling

위협은 실제 고민이 되어야 하지만 공포 체험이 목적은 아니다.

초등학생용 기본 상한:

- 징후와 긴장은 허용
- 비그래픽 위험 상황 허용
- 자연 속 취약함과 협력 강조
- 전투/처치 쾌감 중심 금지
- 고어/그래픽 부상 금지
- 반복 jump scare 금지
- 장시간 강한 공포/무력감 금지
- 선택 실패를 죽음/게임오버로 연결하지 않음

위협 후에는 학생이 `무엇이 일어났는지` 이해할 수 있는 회복 beat를 둔다.

---

# 10. Screen Effect Safety Baseline

`01C`의 연출은 접근성 기준을 침해할 수 없다.

최소 기준:

- 빠른 반복 flashing을 사용하지 않는다.
- 특히 saturated red flash를 반복하지 않는다.
- WCAG의 three-flashes threshold를 넘는 연출을 허용하지 않는다.
- interaction-triggered motion은 reduced-motion 환경에서 억제/단순화 가능해야 한다.
- 색 변화만으로 중요한 상태를 전달하지 않는다.
- blur/shake 때문에 읽기·클릭·시선 이동이 어려워지지 않게 한다.
- `reduced effects` 상태에서도 모든 경로와 정보가 유지된다.

프로젝트 내부 기준은 WCAG 최소치보다 보수적으로 운용한다.

기본 철학:

## **blink는 짧은 눈 감기처럼, flash는 사용하지 않는 쪽을 기본으로 한다.**

---

# 11. Agency의 한계와 공정성

학생이 선택했다고 느끼면서 실제로는 숨겨진 정답으로 조종하면 안 된다.

모든 주요 선택은 다음을 확인한다.

- 선택 전에 필요한 정보가 관찰 가능했는가?
- 적어도 두 선택이 합리적인 이유를 가지는가?
- 결과가 완전히 예측 가능할 필요는 없지만 자의적이지 않은가?
- 나중에 결과를 봤을 때 앞의 상황과 연결할 수 있는가?
- 특정 선택만 핵심 콘텐츠/긍정적 관계를 독점하지 않는가?

불확실성은 허용하지만 **무작위 처벌**은 피한다.

---

# 12. Reflection / Concept Bridge는 필수다

몰입만으로 학습 완료를 선언하지 않는다.

K–6 체험 이후에는 짧은 reflection과 scaffolding이 필요하다.

체험 뒤 질문은 정답 퀴즈보다 자기 경험을 근거로 한다.

예:

- 왜 더 따라갈지 돌아갈지 고민했어?
- 사냥하지 않은 사람들의 일이 왜 필요했을까?
- 같은 장면을 다른 사람의 입장에서 보니 무엇이 달라졌어?
- 며칠 뒤 이곳을 떠날 생각이 왜 생겼을까?

그 뒤 교과 개념을 연결한다.

## **Experience → Reflection → Historical Concept**

을 전체 학습 루프로 고정한다.

---

# 13. 역사적 불확실성 전달 원칙

학생 화면에 모든 장면마다 `[재구성]` 태그를 띄울 필요는 없다.

하지만 교사/개념화/보조 정보에서는 다음을 구분할 수 있어야 한다.

- 우리가 자료로 비교적 분명히 아는 것
- 여러 가능성 중 하나로 재구성한 것
- 체험을 위해 만든 상호작용

특정 가상 인물의 대사와 관계를 `구석기 사람들은 반드시 이랬다`는 근거로 사용하지 않는다.

---

# 14. Teacher / Classroom Readiness

초등 수업에서 사용될 수 있으므로 다음을 고려한다.

- 짧게 재시작 가능
- 음소거/효과 저감 가능
- 학생이 막혔을 때 교사가 현재 진행 위치를 확인할 수 있는 debug/teacher surface
- 결과를 점수로 비교하지 않음
- 학생마다 다른 경로를 경험해도 공통 토론이 가능하도록 Learning Invariants 유지

교사 surface가 학생 화면에 노출되어 몰입을 깨지 않게 분리한다.

---

# 15. Stage 01D Acceptance Gate

다음 모두 YES여야 한다.

- 몰입과 학습이 충돌할 때 무엇을 우선할지 명확한가?
- 모든 분기에서 핵심 역사 학습이 보존되는가?
- 초등학생이 무엇을 해야 하는지 지나치게 숨기지 않는가?
- 장면마다 주의 초점이 과밀하지 않은가?
- 몸의 외형이 근거 없는 성/역할 고정관념을 만들지 않는가?
- 관점 전환이 이해 가능한가?
- 관계가 죄책감/도덕 채점으로 변질되지 않는가?
- 위협 강도가 초등학생 체험에 적절한가?
- 화면 효과가 접근성/안전을 침해하지 않는가?
- 체험 뒤 reflection과 역사 개념화가 있는가?

하나라도 NO면 `Immersion Complete`보다 먼저 수정한다.
