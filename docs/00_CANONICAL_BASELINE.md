# 4. 공식 용어

## 뗀석기

상위 도구 개념.

## 주먹도끼

`뗀석기`의 대표적인 구체 예.

정확한 관계:

```text
뗀석기
└─ 대표적인 예: 주먹도끼
```

학생용 핵심 문장:

> **뗀석기**  
> 돌을 깨뜨리거나 떼어 만든 도구를 뗀석기라고 한다. 지금 손에 든 것은 그 대표적인 예인 **주먹도끼**다.

주먹도끼를 사냥 전용 무기로 축소하지 않는다.

## 현재 임시 거처

학생이 처음 보는 공동체 생활 공간의 중립적 표현.

## 막집

교과 핵심 용어. Camp에서 거처를 실제로 보고/손질한 뒤 명명하는 것이 기본 경로.

## 동굴 / 바위 그늘

자연 지형을 이용한 생활 공간.

막집과 동굴/바위 그늘을 경쟁 정답으로 만들지 않는다.

# 5. Historical Fact / Reconstruction

## Historical / Curriculum Fact

- 뗀석기 사용
- 주먹도끼의 다용도성
- 이동 생활
- 불 이용
- 막집
- 동굴/바위 그늘 생활

## Reconstructed Event

- 아루/다무/누아라는 fictional call-name
- 특정 아침의 구체 대사와 행동
- 아루가 Player에게 주먹도끼를 건네는 사건
- Day 1 공동체의 정확한 배치
- 특정 route / landmark
- Hunt에서 특정 자연 거처 후보를 발견하는 사건
- Player right-hand dominance production attribute

Player flow를 `[재구성]` 라벨로 반복 중단하지 않는다.
Teacher/Debug에서 사실/재구성 경계를 확인 가능하게 한다.

Player에게 들리는 한국어는 실제 선사 언어 복원이 아니라 **의미 번역 convention**이다.
Pseudo-primitive speech를 사용하지 않는다.

# 7. Same-Day / Limited Knowledge

# **Student Play Order ≠ In-World Time**

```text
Same Day 1
├─ Hunt
├─ Gather
└─ Camp
```

- 역할 완료마다 하루가 지나지 않음
- 역할 순서가 달라도 동일 `dayId`
- 한 역할 결과가 다른 역할의 이미 일어난 과거를 소급 변경하지 않음
- 세 관점 뒤 Common Evening 한 번

# **World Truth ≠ Character Knowledge**

현재 캐릭터가 아는 정보는:

- 직접 본 것
- 함께 겪은 것
- 다른 사람이 나중에 알려 준 것

범위 안에서만 제공한다.

- R/H1/H2는 authoring ID
- provisional Player-facing call-name = `아루 / 다무 / 누아`
- Player 자신의 이름은 Stage 07.5에서 고정하지 않음
- NPC는 Player만 기다리는 tutorial object가 아님
- NPC-to-NPC interaction 허용
- background community autonomy 허용
- 관계 = shared event / memory / callback
- 호감도 점수 없음

# 9. Embodied First-Person / Visual Composition

기본 시야:

# **환경 + 자연스럽게 보이는 내 몸 + 들고 있는 것 + 주변 사람 + 현재 행동 + 빛/소리**

Production composition:

```text
World Plate
+ Spatial / Occlusion
+ Actor
+ Embodied Body
+ Held / Contact Item
+ Environmental Light
+ Perceptual Treatment
+ Minimal Player UI
```

학생에게는 하나의 물리적 공간처럼 보여야 한다.

핵심:

- body is not HUD
- 모든 Beat에 고정 손 PNG 금지
- same body/tool/light identity continuity
- contact-heavy 장면은 실제 손-물체-상대 손 관계가 보여야 함
- occlusion은 depth 정보
- 매 Beat마다 새 full-frame image를 갈아끼우는 slideshow 금지
- action affordance도 fixed HUD/footer가 되어서는 안 됨

Screen Treatment:

# **Subtle by default. Strong when earned.**

Reduced Effects에서도 사건/판단/학습은 동일해야 한다.

# 11. Stage 07.5 Current Integrated Proof

현재 main에 통합된 causal proof:

```text
ambient community life
→ 눈을 뜸
→ 생활 속에서 아루 이름 인식
→ 아루 handaxe handoff
→ Experience 뒤 뗀석기 / 주먹도끼 naming
→ 다무/누아와 출발
→ 아루 귀환 모티프
→ 다무가 먼저 멈춤
→ Player가 몸을 낮춤
→ ground evidence reveal
→ 누아 attention shift
→ Player가 직접 방향을 봄
→ natural shelter reveal
→ inspection / 동굴·바위 그늘 naming
→ same-moment Aru-side perspective proof
```

현재 runtime은 **causal/social prototype**이다.

자동 테스트가 증명하는 것:

- state/causal ordering
- Player/Teacher/Debug separation
- terminology relation
- held-item logical continuity
- Same-Day regressions

자동 테스트가 증명하지 않는 것:

- 사람처럼 보이는가
- 손/팔/도구가 자연스러운가
- 실제 depth/contact가 자연스러운가
- dialogue/curriculum cue가 몰입을 깨지 않는가
- production assets가 responsive에서 안정적인가
- 학생이 실제 교과 개념을 이해했는가

# 15. 기술 / 완료 판정 용어

- **Curriculum Anchor**: 교과 개념과 구현/QA를 연결하는 내부 안정 ID
- **Terminology Reveal**: 경험 뒤 학생에게 이름을 붙이는 beat
- **Learning Evidence**: 학생 점수가 아닌 QA/자동검증용 내부 증거
- **Shared Day Event**: 동일 Day 1에서 발생한 질적 사건
- **Perspective Knowledge**: 현재 캐릭터가 알 수 있는 정보 범위
- **Scene**: 목표/직접 행동/위치/결과/world memory가 의미 있게 변하는 상태
- **Beat**: Scene 내부의 대사/시선/손/용어/효과 변화
- **Embodied Composite**: world/body/actor/item/treatment를 동일 공간 논리로 합성하는 production 문법
