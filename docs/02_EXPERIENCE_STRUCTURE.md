# 1. 전체 체험의 핵심

이 프로젝트의 핵심은

# **같은 공동체의 같은 하루를 서로 다른 사람의 몸과 눈으로 살아보고, 서로의 경험을 다시 연결해 역사적 이유를 이해하는 것**

이다.

학생은 세 관점을 순서대로 플레이하지만 세계 안에서는 여러 사람이 같은 시간에 다른 장소에서 하루를 보낸다.

관점이 바뀌면

- 다른 손과 몸
- 다른 위치
- 다른 가까운 사람
- 다른 걱정
- 다른 행동 가능성

을 가진다.

그러나

- 같은 불
- 같은 해
- 같은 거처
- 같은 사람
- 같은 물건/소리
- 같은 사건의 흔적

이 세계를 하나로 묶는다.

---

# 2. 전체 한 줄 구조

# **Embodied Cold Open → 첫 관점의 같은 하루 → Micro Reflection → Perspective Recontextualization → 두 번째 관점 → Micro Reflection → Perspective Recontextualization → 세 번째 관점 → 관계/결과가 반영된 Common Evening → Shared Reflection → 며칠의 변화 → 공동체 고민 → 이동 → 새 거처 → Historical Concept Bridge**

역할 메뉴보다 **시점과 관계의 이동**이 중심이다.

그러나 학생이 시점 전환을 이해하지 못하면 최소 orientation을 허용한다.

---

# 3. Learning Invariants는 전체 구조가 보장한다

각 역할 분기가 달라도 전체 체험은 다음 핵심 증거를 반드시 제공해야 한다.

- 도구가 생활 행동과 연결됨
- 불이 생활의 중요한 요소임
- 먹을거리 확보가 불확실함
- 여러 사람이 서로 다른 일을 하며 의존함
- 자연·시간·거리 조건을 완전히 통제할 수 없음
- 한 장소에서 계속 생활하기 어려워지는 맥락이 누적됨
- 이동 생활이 앞선 경험의 결과로 이해됨

개별 선택 때문에 핵심 역사 개념을 놓치는 구조를 만들지 않는다.

---

# 4. Opening — 세계와 몸이 먼저 존재한다

권장 리듬:

# **어둠/공간 소리 → 내 몸 일부 → 불/사람 → 손으로 하는 작은 행동 → 관계 상호작용 → 오늘의 생활 문제 신호**

첫 20~30초 안에 느껴야 할 것:

- 나는 여기 있다.
- 내 몸이 있다.
- 가까운 사람이 있다.
- 오늘도 생활을 이어가야 한다.
- 내가 할 수 있는 첫 행동이 있다.

보여주지 않을 것:

- Stage 번호
- 학습목표 목록
- 세 역할 메뉴
- 긴 구석기 소개

단, 학생이 첫 행동을 찾지 못하면 단계적 cue/hint를 제공한다.

---

# 5. Shared Morning Event와 Perspective Morning Echo

## Shared Morning Event

세계 안에서 한 번 일어나는 아침 사건.

- 같은 불
- 같은 먹을거리 상태
- 같은 사람들
- 같은 날씨/해
- 사람들이 움직이기 시작함

## Perspective Morning Echo

각 역할 진입에서 같은 아침을 **다른 몸과 위치에서 5~20초 정도** 다시 본다.

설명을 반복하지 않고 같은 사건을 반대편에서 보여준다.

예:

### Hunt

- 도구를 받음
- 밖으로 나갈 사람들과 가까이 있음
- 남는 사람의 말을 들음

### Camp

- 불 가까이에 있음
- 밖으로 나갈 사람을 바라봄
- 같은 도구 전달을 반대편에서 볼 수 있음

이 장치는 `같은 하루`를 체감시키는 핵심이다.

---

# 6. Perspective Orientation Rule

시점 전환은 몰입적이어야 하지만 **혼란스러우면 안 된다.**

각 전환은 다음 anchor 중 2개 이상을 사용한다.

- 같은 사람
- 같은 불/물건
- 같은 대사/소리
- 같은 사건의 반대편 위치
- 달라진 손/몸

필요하면 한 줄 orientation을 허용한다.

> 같은 아침. 이번에는 불 옆이다.

학생이 `왜 손이 바뀌었지?`에만 집중하면 실패다.

---

# 7. Perspective Bridge

Perspective Bridge는 다음 역할 메뉴가 아니다.

기능:

# **방금 겪은 사건을 다른 사람의 위치에서 다시 의미 있게 보도록 시점을 이동한다.**

예:

Hunt에서 불빛을 보며 귀환
→ 불 가까이 있는 사람을 바라봄
→ 같은 불을 anchor로 짧은 transition
→ 다음 관점에서는 불 가까이 있는 사람의 손이 내 손이 됨

Bridge는 가능한 한 짧다.

---

# 8. 같은 하루의 Cast Network

반복 등장하는 소수의 사람을 사용한다.

필요한 것은 많은 NPC가 아니라 **같은 사람이 계속 같은 사람으로 느껴지는 것**이다.

반복 인물은 다음으로 continuity를 갖는다.

- 외형/목소리/자세
- 반복 손짓/말투
- 이전 사건의 기억
- 역할이 바뀌어도 동일한 위치 관계

친족/권력 구조는 역사 검토 전 사실처럼 고정하지 않는다.

---

# 9. 역할별 Dramatic Question

## Hunt

# **“먹을 것을 더 좇을 것인가, 시간·거리·사람의 상태를 생각할 것인가?”**

상위:

> 오늘 먹을 것을 구하고 무사히 돌아갈 수 있을까?

## Gather

# **“가까운 곳에서 충분히 찾지 못할 때 어디까지 더 살펴볼 것인가?”**

상위:

> 오늘 필요한 것을 어디까지 가야 찾을 수 있을까?

## Camp

# **“생활을 이어가면서 돌아오지 않는 사람을 어떻게 기다릴 것인가?”**

상위:

> 밖에 나간 사람들이 돌아올 때까지 이곳의 하루를 어떻게 이어갈까?

전체:

# **“이곳에서 우리는 계속 살아갈 수 있을까?”**

---

# 10. 역할별 Embodied Grammar

## Hunt

- 먼 시야
- 걷기
- 지면을 보기 위해 몸 낮추기
- 도구 든 손
- 위험 때 정지/자세 변화
- 운반
- 피곤한 귀환

## Gather

- 가까운 지면/식생
- 손으로 살피기
- 담기
- 반복해서 자세 바꾸기
- 같은 장소를 다른 각도로 비교

## Camp

- 불 가까이의 손/무릎
- 손질/정리
- 같은 공간의 반복 시야
- 빈자리
- 멀리 바라보기
- 돌아온 사람과 물건 주고받기

같은 1인칭 템플릿을 복사하지 않는다.

---

# 11. Clarity / Primary Attention

각 주요 장면은 **Primary Attention Target**을 하나 가진다.

예:

- 도구 전달: 상대 손 → 도구 → 내 손
- 흔적: 지면의 변화
- 위험: 갑자기 멈춘 동행자 → 이상한 방향
- 귀환: 먼 불빛

몸·대사·사운드·screen treatment는 이 대상을 지원한다.

학생이 무엇을 봐야 하는지 모르면 단계적으로 유도한다.

---

# 12. 선택과 결과 구조

각 역할은 소수의 중요한 판단을 가진다.

질적 상태 예:

- 관계 기억
- 시간/거리 부담
- 관찰한 정보
- 위험 경험
- 들고 있는 것
- 귀환 시점
- 협력 방식

이 기억은 다음에서 회수될 수 있다.

1. 역할 내부 후속 장면
2. 귀환/재회
3. Perspective Bridge
4. Common Evening
5. 며칠 변화

선택은 핵심 역사 콘텐츠를 잠그는 열쇠로 사용하지 않는다.

---

# 13. Choice Fairness

중요 선택 전에 학생은 판단에 필요한 정보를 볼 수 있어야 한다.

- 가능성
- 비용/부담
- 시간
- 거리
- 사람의 상태

완벽한 예측은 불가능해도 결과가 자의적으로 느껴지지 않아야 한다.

특정 선택만 `좋은 사람과 친해지는 길`, `핵심 콘텐츠를 보는 길`이 되지 않게 한다.

---

# 14. Threat Build-up

기본 순서:

# **이상 징후 → 사람 반응 → 내 몸의 정지/변화 → 관찰 → 위협 이해 → 판단**

빨간 화면/경고 문구가 먼저 나오지 않는다.

위협은 초등학생용 비그래픽 긴장 수준을 유지하고, 강한 공포 뒤에는 recovery beat를 둔다.

---

# 15. Micro Reflection

역할 사이에 긴 퀴즈를 넣지 않는다.

필요한 경우 짧게 자기 경험을 정리한다.

예:

- `무엇 때문에 돌아갈지 고민했지?`
- `누가 가장 기억에 남았지?`

Reflection은 몰입을 끊는 시험이 아니라 다음 관점에서 재해석할 준비다.

매 역할마다 반드시 화면을 멈출 필요는 없고, 이야기 흐름과 교실 사용성을 보고 위치를 조정한다.

---

# 16. Common Evening — 같은 장소, 다른 의미

공통 저녁은 고정 엔딩 컷신이 아니다.

달라질 수 있는 것:

- 누가 먼저 바라보는지
- 어떤 물건을 내려놓는지
- 늦었는지
- 누가 부담을 나눴는지
- 어떤 대사가 나오는지
- 불 주변의 물건/사람 위치

금지:

- 총점
- 별점
- `오늘의 성공도`
- 역할 순위

핵심 이해:

# **내 역할의 결과만으로 오늘이 결정되지 않았다.**

---

# 17. Shared Reflection

세 관점이 만난 뒤 짧게 경험을 연결한다.

좋은 질문:

- 사냥하는 동안 거처에서는 무엇이 계속되고 있었나?
- 기다리는 관점에서 보니 늦은 귀환이 어떻게 느껴졌나?
- 어느 역할이 더 중요하다기보다 왜 서로 필요했나?

정답 채점보다 학생의 플레이 근거를 사용한다.

---

# 18. 며칠의 변화

반복 클릭이 아니라 **비교 가능한 변화**를 보여준다.

## Hunt

- 더 먼 흔적
- 더 늦은 귀환 가능성
- 동행자의 반응 변화

## Gather

- 익숙한 가까운 곳에서 이전처럼 쉽게 찾기 어려움
- 더 넓은 범위

## Camp

- 기다림 증가
- 돌아오는 사람의 피로/부담
- 남은 먹을거리/생활 준비 변화

관계 기억은 일부 누적될 수 있지만 RPG 관계 시뮬레이터로 확장하지 않는다.

---

# 19. 이동 결정

이동은 정답 퀴즈가 아니다.

앞선 경험 때문에 학생이

> `여기서 계속 지내기 쉽지 않겠는데.`

라고 예상할 수 있어야 한다.

공동체의 사람·물건·거리·먹을거리 상태를 보고 이동 고민이 발생한다.

---

# 20. 이동 경험

이동도 1인칭이다.

- 가져갈 것/두고 갈 것
- 손에 든 물건
- 함께 걷는 사람
- 익숙한 불/공간을 떠나는 감각
- 새로운 장소를 살피는 행동

새 장소는 자동으로 안전한 `보상 스테이지`가 아니다.

---

# 21. Historical Concept Bridge

마지막에는 학생이 경험한 장면을 다시 근거로 사용한다.

# **Experience → Reflection → Historical Concept**

연결 대상:

- 뗀석기/도구 사용
- 불
- 먹을거리 확보
- 협력과 역할
- 생활 공간
- 이동 생활

`구석기 특징 5개`를 새로 외우게 하는 별도 강의로 만들지 않는다.

---

# 22. 역사적 재구성의 가시성

학생에게 모든 장면마다 `[재구성]` 태그를 띄우지 않는다.

그러나 Teacher/Concept Bridge에서는

- 자료로 비교적 분명히 아는 것
- 가능한 한 방식으로 재구성한 것
- 게임 상호작용

을 구분할 수 있어야 한다.

---

# 23. Screen Treatment 위치

색·명암·focus·blink·micro motion은 전체 구조의 독립 이벤트가 아니다.

장면 의미를 보조한다.

- Opening: 불의 따뜻함
- 시간 변화: 색온도/그림자
- 위협: 세계/몸 반응 뒤 약한 attention treatment
- 귀환: 어두운 공간과 먼 불빛
- Perspective Bridge: 제한적 blink/fade

Reduced effects에서도 동일한 정보가 유지된다.

---

# 24. Classroom Session Boundary

수업 사용을 고려해 큰 체험 단위에는 안정된 checkpoint를 둔다.

후보:

- Cold Open 완료
- 역할 완료
- Common Evening 완료
- 며칠 변화 완료
- 이동 결정 전/후

교사가 중단/재개하기 쉬워야 한다.

짧은 대사/animation 중간 상태까지 저장하지 않는다.

---

# 25. 전체 Acceptance Criteria

- 첫 30초가 학습 안내보다 세계 진입으로 느껴짐
- 첫 행동을 학생이 지나치게 헤매지 않음
- 세 역할이 다른 몸/관계/고민을 가짐
- 관점 전환에서 현재 위치와 몸을 이해함
- 같은 사람/불/시간이 관점을 연결함
- 모든 경로에서 Learning Invariants가 유지됨
- 중요한 선택은 필요한 정보를 사전에 제공함
- 위협이 UI보다 상황으로 먼저 느껴짐
- 위협 강도가 초등학생에게 적절함
- 공통 저녁이 결과표가 아님
- Reflection이 플레이 경험과 역사 개념을 연결함
- 이동 생활이 누적 경험의 결과로 이해됨
- reduced effects에서도 전체 체험이 가능함
- 교실에서 중단/재개 가능한 checkpoint가 있음

이 조건을 만족해야 Stage 02를 완료로 유지한다.
