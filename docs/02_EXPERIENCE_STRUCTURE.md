# 1. 전체 경험의 한 문장

# **같은 구석기 공동체의 같은 하루를 서로 다른 사람의 몸과 제한된 시야로 차례로 살아보며, 도구·불·먹을거리·거처·이동·위험·관계가 한 사람의 생활을 넘어 공동체 전체에서 어떻게 이어지는지 이해하는 역사 체험.**

---

# 2. Student Play Order ≠ In-World Time

학생이 역할을 다음 순서로 플레이할 수 있다.

```text
Hunt → Gather → Camp
```

그러나 세계 안에서는 세 개의 다른 날이 아니다.

```text
Same Day 1
├─ Hunt perspective
├─ Gather perspective
└─ Camp perspective
```

규칙:

- 역할 완료는 `학생이 이 관점을 경험했다`는 세션 상태다.
- 역할 완료가 세계 시간을 하루씩 진행시키지 않는다.
- 역할 순서를 바꿔도 모두 같은 `dayId`를 공유한다.
- 한 역할의 결과가 다른 역할에서 이미 발생한 과거를 소급 변경하지 않는다.
- cross-role signal은 후속 표현과 의미를 바꿀 수 있다.
- 세 관점을 모두 경험한 뒤 Common Evening을 한 번 실행한다.

# **플레이 순서와 세계 시간은 별도 모델이다.**

---

# 3. 전체 경험 뼈대

```text
Role Orientation
↓
Perspective Morning Echo
↓
Role Experience
↓
Role Completion
↓
Perspective Bridge
↓
Next Role Orientation
↓
...
↓
Common Evening
↓
Historical / Curriculum Connection
↓
Later-Day Change
```

Common Morning을 세 번 반복하지 않는다.

각 역할 시작에는 같은 아침을 다른 위치에서 짧게 다시 느끼는 **Perspective Morning Echo**를 사용할 수 있다.

---

# 4. Curriculum Anchor는 전체 경험에 분산한다

교과서 핵심을 마지막 설명 페이지에 몰아넣지 않는다.

전체 흐름:

```text
Hunt
→ 뗀석기/주먹도끼를 몸으로 만남
→ 이동·동굴/바위 그늘 가능성을 경험

Gather
→ 도구를 채집/가공에 다시 사용
→ 먹을거리와 가까운 자원의 한계를 경험

Camp
→ 불·막집·음식 익히기·생활 손질을 경험
→ 새 거처 후보가 공동체 문제로 바뀜

Common Evening / Conceptualization
→ '뗀석기', '주먹도끼', '막집', '동굴/바위 그늘', '이동 생활'을 정확히 연결
→ 실제 유물/유적과 접속
```

# **한 역할이 모든 교과 내용을 설명하지 않는다. 같은 개념이 여러 역할에서 다른 의미로 다시 등장한다.**

---

# 5. Experience → Name → Reuse → Connect의 위치

## Experience

역할 안에서 먼저 몸으로 겪는다.

예:

- R에게 돌도구를 받음
- 불에 손을 가까이 함
- 막집 덮개가 흔들리는 것을 봄
- 넓은 동굴/바위 그늘을 발견함

## Name

스토리를 과하게 끊지 않는 짧은 terminology reveal.

예:

> **뗀석기 · 주먹도끼**
> 돌을 깨뜨리거나 떼어 만든 대표적인 도구

## Reuse

다른 행동/역할에서 다시 의미 있게 사용.

예:

- 땅파기
- 두들기기
- 자르기/손질

## Connect

Common Evening 또는 후속 Conceptualization에서 교과서 개념·실제 유물·유적과 연결.

# 6. Role Orientation

역할 전환 자체는 어렵게 숨기지 않는다.

학생에게 현재 관점을 짧게 알려준다.

예:

> **사냥을 나선 사람의 관점**

> **거처에 남아 생활을 이어가는 사람의 관점**

그 뒤 역할 내부에서는 고정 HUD처럼 반복하지 않는다.

역할 안에서는 그 사람이 아는 범위만 보여준다.

---

# 7. Hunt Perspective

핵심 문법:

# **멀어짐 → 흔적 → 도구 → 발견 → 가능성 → 위험 → 새 장소 → 귀환**

핵심 Curriculum Anchor:

- 뗀석기
- 주먹도끼
- 사냥 전 관찰
- 이동 거리와 먹을거리 불확실성
- 동굴·바위 그늘 발견 가능성
- 불/거처로 돌아가는 의미

Hunt는 `주먹도끼 설명 역할`이 아니다.

도구는 관계·몸·행동 속에서 먼저 존재해야 한다.

---

# 8. Gather Perspective

핵심 문법:

# **가까이 살핌 → 분별 → 손으로 채집 → 가공 → 반복 → 장소 기억 → 범위 확대**

핵심 Curriculum Anchor:

- 풀뿌리·열매 등 먹을거리
- 도구의 땅파기/두들기기 등 생활 사용
- 식량을 얻는 일이 사냥만이 아님
- 가까운 자원이 언제나 충분하지 않음
- 이동 범위가 넓어지는 이유

Hunt의 추적·공포 climax를 복제하지 않는다.

---

# 9. Camp Perspective

핵심 문법:

# **불 → 생활 유지 → 거처 손질 → 시간 흐름 → 빈자리 → 기다림 → 재회 → 다음 장소 고민**

핵심 Curriculum Anchor:

- 불의 생활 기능
- 음식 익히기
- 임시 거처 / 막집
- 가죽·도구·먹을거리 손질
- 자연환경으로부터 몸을 보호하는 생활
- 동굴 또는 바위 그늘 같은 다른 거처 가능성

Camp에서는 Hunt 위험의 실제 내용을 전지적으로 알 수 없다.

모르기 때문에 기다린다.

---

# 10. 동굴 발견은 Same-Day World Fact 후보가 될 수 있다

Hunt 중 학생이 실제로 넓은 동굴/바위 그늘을 발견하면 그 사건은 후속 역할에서 회수 가능하다.

예:

```text
Hunt
→ cave-shelter-noticed

Camp 후속 표현
→ 돌아온 사람이 '큰 바위 아래 넓은 곳이 있었다'고 이야기함
→ 현재 막집을 손질하던 사람에게 다른 의미가 생김
```

그러나 다음은 금지한다.

- Hunt가 동굴을 발견했다고 Camp의 이미 끝난 과거 장면이 소급 변경됨
- 동굴 발견 즉시 공동체 전체가 이사 완료 상태가 됨
- `동굴 = 더 좋은 집`으로 자동 판정

동굴은 **거처 후보**다.

---

# 11. Stable World Facts

같은 날 역할 순서와 무관하게 유지되어야 하는 것:

- day identity
- community identity
- 아침의 기본 공간
- 불이 있는 생활 거점
- 반복 등장 인물
- 현재 공동체가 사용하는 임시 거처의 기본 형태
- 그날의 기본 자연 조건

역할 선택이 이를 임의로 바꾸지 않는다.

---

# 12. Cross-Role Signals

한 역할의 결과를 후속 표현에서 회수하는 질적 신호.

예:

- `hunt-returned-late`
- `hunt-returned-with-food`
- `hunt-returned-empty-handed`
- `hunt-cave-shelter-noticed`
- `hunt-cave-shelter-inspected`
- `hunt-shared-carry`

좋은 signal:

- 다른 역할/저녁에서 의미가 실제로 달라질 수 있음
- 학생의 행동과 연결됨
- 점수가 아님

나쁜 signal:

- 모든 클릭 기록
- 순간 animation state
- 내부 reducer stage를 그대로 공유

---

# 13. Perspective Bridge

Perspective Bridge는 역할 결과 점수표가 아니다.

역할을 마친 학생이

- 내가 겪은 것은 공동체의 하루 일부였음을 느끼고
- 다른 사람에게 같은 사건이 다르게 보일 수 있음을 준비하고
- 방금 경험한 교과 개념을 억지로 시험받지 않은 채 다음 관점으로 넘어가게 한다.

가능한 짧은 회수:

> 손에 들고 있던 주먹도끼를 잠시 내려다본다.

> 아까 본 넓은 바위 공간이 떠오른다.

단, 매 Bridge마다 용어 설명을 반복하지 않는다.

---

# 14. Common Evening

Common Evening은 세 역할의 결과를 한곳에 모은다.

보여줄 수 있는 것:

- 가져온 먹을거리 / 빈손
- 몸의 피로
- 서로의 귀환
- 불
- 도구
- 막집/현재 거처의 상태
- 새로 발견한 동굴 또는 바위 그늘에 대한 이야기
- 내일 무엇을 해야 할지에 대한 공동체의 불확실성

하지 않을 것:

- 총점
- 역할별 우승
- 사냥 성공 = 최고 결과
- `교과서 정답 정리표`로 즉시 전환

---

# 15. Historical / Curriculum Connection

교과 용어를 정확히 짚는 층은 존재해야 한다.

다만 역할 몰입이 끝나자마자 긴 강의가 되는 것은 피한다.

좋은 방식:

```text
내가 손에 들었던 것
→ 뗀석기 / 주먹도끼

내가 출발했던 임시 거처
→ 막집

이동 중 발견했던 자연 공간
→ 동굴 / 바위 그늘도 생활 공간으로 이용

불 앞에서 겪은 것
→ 추위·짐승·조리와 연결된 불의 이용
```

가능하면 실제 유물/유적 연결도 여기서 한다.

---

# 16. Multi-Day Change

Day 1 이후에만 세계의 장기 변화가 진행된다.

가능한 누적:

- 가까운 먹을거리 감소
- 더 멀어지는 탐색 거리
- 막집 손질 부담
- 계절/날씨 변화
- 새 거처 후보 발견
- 동굴/바위 그늘의 장단점 확인
- 새로운 물/식량 접근성

이런 조건이 쌓여

> **왜 옮겨 다니며 살았을까?**

를 서사적으로 만든다.

# 17. Curriculum Anchor Coverage Matrix

| 핵심 | Hunt | Gather | Camp | 통합 |
|---|---|---|---|---|
| 뗀석기 | 받음/들고 이동 | 생활 사용 | 손질/보관 가능 | 정확한 용어 회수 |
| 주먹도끼 | 명명/사용 시작 | 땅파기·두들기기 등 재사용 | 불 옆에 내려놓음/손질 | 실제 유물 연결 |
| 불 | 출발/귀환 모티프 | 간접 | 유지·조리·보호 | 기능 정리 |
| 막집 | 출발점 | 귀환 기준 | 직접 생활/손질 | 주거 다양성 정리 |
| 동굴/바위 그늘 | 발견/살핌 | 주변 자원과 연결 가능 | 새 거처 후보 논의 | 생활 공간 다양성 |
| 이동 생활 | 거리 체감 | 자원 범위 확대 | 떠남의 부담 | 이유 개념화 |

모든 칸을 억지로 채우는 것이 목표가 아니다. **한 개념이 최소 두 맥락에서 의미 있게 다시 등장하는 것**을 우선한다.

# 18. Stage 02 Acceptance Gate

- Student Play Order와 In-World Time이 분리되는가?
- 세 역할이 같은 dayId를 공유하는가?
- 각 역할 내부에서 Role-True limited POV를 지키는가?
- `뗀석기/주먹도끼`가 경험→명명→재사용 흐름을 갖는가?
- 막집과 동굴/바위 그늘을 동시에 생활 공간 가능성으로 다루는가?
- 동굴 발견이 cross-role에서 후속 의미를 가질 수 있는가?
- 다른 역할의 과거를 소급 변경하지 않는가?
- Curriculum Anchor가 특정 역할의 설명 부담으로 몰리지 않는가?
- Perspective Bridge가 점수표/퀴즈가 아닌가?
- Common Evening이 세 관점을 통합하는가?
- Multi-Day Change가 이동 생활 이해로 이어질 수 있는가?

이 Gate를 통과한 구조만 Stage 03~07의 입력으로 사용한다.
