## 2단계 결과물 — 전체 경험 구조 v3

> 목적: 세 역할을 하나의 공동체가 보내는 하루로 묶고, 몰입·서사·학습이 같은 인과 구조를 갖도록 전체 경험을 정의한다.
>
> 상위 기준: `docs/01_PROJECT_CORE.md`, `docs/07_IMMERSION_NARRATIVE_BIBLE.md`.

# 1. 전체 체험의 핵심

이 프로젝트는

**사냥 게임 + 채집 게임 + 기다림 게임**

의 모음이 아니다.

# **같은 공동체의 같은 하루를 세 위치에서 살아보는 경험**

이다.

세 역할은 서로 다른 장소와 문제를 경험하지만 같은 아침에서 갈라지고 같은 저녁에서 다시 만난다.

이후 며칠의 변화가 누적되어

# **“이곳에서 우리는 계속 살아갈 수 있을까?”**

라는 공동체 질문으로 확장된다.

---

# 2. 전체 한 줄 구조

## **Cold Open 공통 아침 → 역할이 자연스럽게 갈라짐 → Hunt / Gather / Camp의 같은 하루 → Perspective Bridge → 공통 저녁 재회 → 며칠의 변화 → 머물기 어려워짐 → 이동 결정 → 이동 경험 → 새 거처 → 새로운 밤 → 역사 개념화 → 신석기 연결**

중요한 변화는 `공통 아침 = 설명 화면`이 아니라 **학생이 세계에 들어오는 첫 몰입 장면**이라는 점이다.

---

# 3. 공통 아침 — 설명하지 말고 살게 한다

## 목표

시작 20~30초 안에 학생이 다음을 느낀다.

- 나는 사람들이 함께 머무는 장소에 있다.
- 밤부터 이어진 불과 생활의 흔적이 있다.
- 오늘도 먹을 것을 구하고 생활을 이어가야 한다.
- 사람들은 각자 움직이기 시작한다.
- 나도 그중 한 사람으로 행동한다.

## 권장 시작 리듬

**어둠/소리 → 불 → 내 손/가까운 물체 → 주변 사람 → 생활 문제 → 작은 행동 → 역할 무리에 자연스럽게 합류**

## 하지 않을 것

- 시대 설명부터 시작
- 학습목표 제시
- 세 역할 메뉴를 먼저 보여줌
- `오늘은 사냥 역할입니다` 같은 메타 설명
- 개발 Stage/버전 노출

역할은 메뉴로 `선택했다`기보다 **같은 장면 안에서 관점이 이동하는 것**처럼 느껴지는 편을 우선 검토한다.

---

# 4. 공통 경험 층과 역할 고유 경험 층

## A. Common Experience

공유하는 세계와 서사의 뼈대:

- 같은 공동체
- 같은 거처
- 같은 아침 불
- 같은 생활 문제
- 서로의 존재
- 같은 하루의 시간대
- 같은 저녁 재회
- 며칠 변화
- 이동 결정과 새 거처

Common은 역할을 연결하지만 역할별 플레이 방법을 결정하지 않는다.

## B. Role Experience

### Hunt

**보이지 않는 사냥감을 찾음 → 기회를 만남 → 결과가 불확실함 → 더 갈지 돌아갈지 고민 → 자연 위험 → 결과와 관계없이 귀환**

### Gather

**가까운 주변을 익숙하게 살핌 → 발견 → 반복 → 이전처럼 쉽게 찾기 어려운 곳이 늘어남 → 탐색 범위를 넓힘 → 공동체로 가져감**

### Camp

**불·먹을거리·도구·주변 생활을 이어감 → 시간이 흐름 → 밖에 나간 사람의 결과를 모름 → 늦어지는 귀환 → 불과 거처를 지킴 → 재회**

세 역할은 고유한 리듬을 갖는다.

---

# 5. 역할 진입은 정체성 전환이다

`role-entry`는 단순한 안내 화면이 아니다.

각 역할로 들어갈 때 학생은 다음을 짧게 확인해야 한다.

- 내가 지금 누구와 있는가
- 어디에 있는가
- 지금 무엇이 필요한가
- 내가 무엇을 하려는가

예:

Hunt:

> “같이 가자.”

Gather:

> 누군가 빈 바구니/담을 것을 챙기고 주변을 살핀다.

Camp:

> 밖으로 나가는 사람들의 뒷모습과 남은 불을 동시에 본다.

정확한 표현은 각 역할 STORY에서 결정한다.

---

# 6. 세 역할의 동시성

학생의 실제 플레이 순서와 세계 안 시간은 분리한다.

학생이 Hunt → Gather → Camp 순으로 플레이해도 세계 안에서는 **같은 하루의 서로 다른 관점**이다.

따라서 역할 전환 때 `다음 날`처럼 느껴지지 않아야 한다.

Perspective Bridge는 이를 설명문으로 길게 말하기보다 **같은 아침의 다른 방향/같은 불/같은 인물의 흔적** 같은 연속성 장치로 전달하는 것을 우선한다.

---

# 7. 역할별 Dramatic Question

## Hunt

# **“오늘 먹을 것을 구하고 무사히 돌아갈 수 있을까?”**

## Gather

# **“오늘 필요한 먹을 것을 어디까지 가야 찾을 수 있을까?”**

## Camp

# **“밖에 나간 사람들이 돌아올 때까지 이곳의 하루를 어떻게 이어갈까?”**

## 전체 공동체

# **“이곳에서 우리는 계속 살아갈 수 있을까?”**

이 질문들은 UI 퀘스트 문구가 아니라 서사를 설계하는 내부 축이다.

---

# 8. Perspective Bridge

역할 완료 뒤 바로 결과표/다음 역할 메뉴로 가지 않는다.

Perspective Bridge는 다음 역할이 **같은 날 동시에 존재했다**는 감각을 회수한다.

가능한 장치:

- Hunt가 떠날 때 보았던 사람이 Gather/Camp 관점의 시작 인물로 이어짐
- 같은 불이 다른 의미로 보임
- 같은 해의 위치를 다른 공간에서 봄
- Hunt에서 `기다리는 사람`이 Camp에서는 `기다리는 나`가 됨

Bridge는 짧아야 한다. 설명보다 시점 전환을 사용한다.

---

# 9. 공통 저녁 — 세 결과가 하나의 생활이 된다

공통 저녁은 score board가 아니다.

학생은 자신이 보지 못한 하루의 흔적을 본다.

- 밖에서 가져온 먹을 것
- 빈손으로 돌아온 사람
- 채집한 것
- 이어진 불
- 손질된 도구나 생활 흔적
- 기다리던 사람의 반응

핵심 이해:

## **“내 역할의 결과만으로 오늘이 결정된 것이 아니었다.”**

공통 저녁은 세 RoleCompletion의 질적 신호를 **서사적으로 통합**한다.

---

# 10. 며칠의 변화

하루 하나만으로 이동 생활의 원인을 결론내리지 않는다.

며칠의 montage/짧은 반복에서 각 역할의 부담이 변한다.

### Hunt

- 찾는 시간이 길어지는 날
- 더 먼 거리
- 늦어지는 귀환

### Gather

- 가까운 익숙한 장소에서 이전처럼 쉽게 찾기 어려운 날
- 더 넓은 탐색 범위

### Camp

- 밖에 나간 사람들이 더 늦게 돌아옴
- 남은 먹을거리·불·생활 준비의 부담
- 기다림의 시간 증가

이 변화가 같은 공동체에서 동시에 쌓인다.

---

# 11. 이동 결정

이동은 `정답 버튼`이 아니다.

앞선 경험 때문에 학생이

> “여기서 계속 지내기 쉽지 않겠는데.”

라고 느낀 뒤 공동체가 움직인다.

이때 비로소 교과서의 이동 생활 개념에 가까워진다.

---

# 12. 이동 자체도 체험이다

이동은 컷신 한 장으로 끝내지 않는다.

학생은 최소한 다음을 경험한다.

- 가져갈 것과 두고 갈 것
- 불/도구/먹을거리 같은 생활 요소
- 함께 움직여야 함
- 익숙한 장소를 떠나는 감정
- 새로운 거처가 자동으로 주어지지 않음

정확한 PLAYFLOW는 후속 단계에서 설계한다.

---

# 13. 새 거처와 역사 개념화

새로운 장소에서 다시 불을 중심으로 사람들이 모인다.

처음의 아침과 시각·감정적 대구를 만든다.

그 뒤 경험을 개념으로 정리한다.

학생이 앞서 겪은 일을 근거로

- 먹을 것을 찾아 이동
- 뗀석기 사용
- 불 사용
- 동굴/바위 그늘/막집 등 생활
- 협력과 역할

을 이해하도록 한다.

개념화는 별도 암기시험이 아니라 **내 경험에 이름을 붙이는 단계**다.

---

# 14. 전체 감정선

## **낯섦 → 일상 속 참여 → 역할의 기대/집중 → 불확실성 → 각 역할의 부담 → 저녁 재회의 안도 → 다른 관점에 대한 이해 → 반복되는 부담 → 떠나야 할지도 모른다는 인식 → 이동의 긴장 → 새 장소의 안도 → 역사적 이해**

---

# 15. 전체 몰입 연속성 장치

프로젝트 전체에서 반복해 의미가 변하는 요소를 둔다.

## 불

- 시작: 일상의 따뜻함
- Camp: 지켜야 하는 생활 중심
- Hunt/Gather 귀환: 돌아갈 장소
- 저녁: 재회
- 이동: 가지고 갈 수 없는 장소성과 이어가야 할 생활 기술의 대비
- 새 거처: 다시 시작

## 해/빛

- 아침: 하루 시작
- 역할 중: 시간 부담
- 저녁: 귀환/재회

## 사람의 말

대표적으로

> **“해가 지기 전에 돌아와.”**

같은 문장을 서로 다른 관점에서 재해석한다.

---

# 16. 전체 Acceptance Criteria

전체 구조는 다음을 만족해야 한다.

- 첫 30초가 학습 안내가 아니라 세계 진입으로 느껴짐
- 세 역할 모두 `내가 그 사람이다`라는 자기 위치를 갖음
- 역할마다 기억되는 관계 인물이 최소 하나 있음
- 역할 선택/전환이 독립 미니게임 메뉴처럼 느껴지지 않음
- 같은 아침/저녁/불/시간이 관점을 연결함
- 공통 저녁이 결과표가 아님
- 이동 생활이 앞선 경험의 결과로 이해됨
- 최종 개념화에서 학생이 자신의 플레이를 근거로 설명할 수 있음
