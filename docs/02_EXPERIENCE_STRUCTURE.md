# 1. 전체 체험의 핵심

# **같은 공동체의 같은 하루를 서로 다른 사람의 몸과 눈으로 살아보고, 경험이 겹치면서 당시 삶의 조건·관계·감정을 역사적으로 상상하고 이해하는 것**

학생은 Hunt / Gather / Camp를 순서대로 플레이하지만 세계 안에서는 세 사람이 같은 하루를 각자의 위치에서 살아간다.

공통:

- 같은 불
- 같은 거처
- 같은 날씨와 해
- 같은 공동체 사람들
- 같은 아침/저녁의 사건

달라지는 것:

- 몸
- 위치
- 가까운 사람
- 알고 있는 정보
- 할 수 있는 행동
- 위험과 부담
- 감정

---

# 2. Student Play Order ≠ In-World Time

이 프로젝트의 핵심 시간 원칙이다.

예를 들어 학생이

```text
Hunt → Gather → Camp
```

순서로 플레이해도 세계 안에서

```text
Hunt 하루가 끝난 뒤 Gather 하루가 시작되고,
그 뒤 Camp 하루가 시작되는 것
```

이 아니다.

세 역할은 **같은 날의 서로 다른 관점**이다.

따라서:

- 역할 순서는 수업/플레이 순서다.
- 역할 내부 `morning / afternoon / dusk / evening`은 그 역할 관점의 같은 날 시간이다.
- 먼저 플레이한 역할의 완료가 나중에 플레이하는 역할의 이미 지나간 오전 사건을 변경하지 않는다.
- cross-role memory는 `세계가 뒤늦게 바뀌는 것`이 아니라 **같은 사건의 반대편을 어떻게 보여줄지 정하는 정보**다.

# **플레이 순서는 시간을 전진시키지 않는다.**

---

# 3. Same-Day Snapshot Rule

역할에 진입할 때 그 역할은 같은 하루의 자기 관점을 연다.

각 역할이 참조할 수 있는 shared 정보는 두 종류로 구분한다.

## Stable World Facts

역할 순서와 무관하게 같은 것.

- 공동체/거처
- 날씨/계절 배경
- Shared Morning Event
- 반복 인물 identity
- 공통 motif

## Cross-Role Presentation Signals

먼저 플레이한 역할의 경험을 이후 관점에서 **재해석**하기 위한 정보.

예:

- Hunt가 늦게 귀환했다면 Camp에서 기다림의 정서/길이가 더 강하게 보일 수 있음
- Hunt가 무거운 것을 가져왔다면 Camp 저녁 재회에서 그 물건이 보일 수 있음

단, 이런 signal은 **Camp가 오전부터 미래를 알고 있었다는 식의 전지적 정보로 사용하지 않는다.**

---

# 4. 역할 전환은 명료하게

관점이 바뀔 때 현재 시점을 짧게 알려줄 수 있다.

예:

> **사냥을 나선 사람의 관점**

> **가까운 곳에서 먹을거리를 찾는 사람의 관점**

> **거처에 남아 생활을 이어가는 사람의 관점**

이 정보는 진입용 orientation이다.

# **관점을 알려준 뒤에는 그 관점으로 살아가게 한다.**

---

# 5. Role-True Perspective

역할 안에서는 그 사람이 실제로 알 수 있는 범위만 player-facing 정보로 사용한다.

## Hunt

알 수 있음:

- 눈앞 풍경
- 내 몸/도구
- 동행자 반응
- 흔적
- 거처와의 거리
- 해/피로
- 자연 위험
- 아침에 들은 말

알 수 없음:

- 같은 시간 Camp 내부에서 벌어진 일
- 남아 있는 사람의 속마음
- 아직 일어나지 않은 귀환 반응

## Gather

알 수 있음:

- 가까운 환경
- 손으로 살피는 대상
- 함께 찾는 사람
- 이전에 본 장소
- 탐색 범위/귀환 시간

Hunt의 내부 위험과 결과를 미리 알지 않는다.

## Camp

알 수 있음:

- 떠난 사람의 부재
- 불과 생활 작업
- 낮아지는 해
- 먼 소리/기척
- 돌아오지 않는 시간

밖에서 실제로 무슨 일이 있었는지는 귀환/후속 관점에서 알게 된다.

# **관점의 제한은 정보 부족이 아니라 역사적 상상력을 만드는 장치다.**

---

# 6. 전체 큰 구조

```text
Embodied Cold Open
→ 현재 역할 관점 고지
→ 첫 역할의 같은 하루
→ Perspective Bridge
→ 두 번째 역할의 같은 하루
→ Perspective Bridge
→ 세 번째 역할의 같은 하루
→ Common Evening
→ 필요 시 경험 비교/대화
→ 며칠의 변화
→ 공동체 고민
→ 이동
→ 새 거처
→ Historical Conceptualization
```

Micro Reflection은 필수 화면이 아니다.

몰입을 끊으면 생략하거나 Common Evening/수업 토론/마지막 개념화로 미룬다.

---

# 7. Opening / Shared Morning Event

세계 안의 아침은 하나다.

첫 20~30초의 목표:

- 나는 여기에 있다.
- 내 몸이 있다.
- 가까운 사람이 있다.
- 오늘의 생활이 이미 시작되고 있다.
- 내가 할 첫 행동이 있다.

긴 시대 설명이나 역할 메뉴가 먼저 나오지 않는다.

---

# 8. Perspective Morning Echo

각 역할에서 같은 아침 일부를 다른 위치에서 다시 볼 수 있다.

Hunt:

- 도구를 받음
- 밖으로 나갈 사람들과 합류
- 남는 사람의 말을 들음

Camp:

- 같은 불 가까이에 있음
- 밖으로 나가는 사람을 봄
- 같은 말/도구 전달을 반대편에서 경험할 수 있음

같은 사건의 반복 자체가 목적이 아니라 **위치가 바뀌면 의미가 달라지는 것**이 목적이다.

---

# 9. Perspective Bridge

Bridge는 다음 역할 선택 메뉴가 아니라 **관점이 닫히고 다른 관점이 열린다는 짧은 연결**이다.

가능:

```text
이전 역할의 마지막 시야
→ fade / blink / 정적
→ 새 역할 관점 한 줄
→ 새 몸과 환경
```

같은 불·사람·물건·소리는 유용하면 continuity anchor로 사용한다.

복잡한 퍼즐처럼 만들지 않는다.

---

# 10. Cast Network

많은 NPC보다 반복되는 소수의 사람을 우선한다.

같은 인물은 역할이 달라져도 같은 사람이어야 한다.

연속성:

- 외형
- 목소리
- 말투
- 손짓
- 물건
- 이전 사건
- 나와의 관계

한 관점의 `기다리는 사람`이 다른 관점의 player body가 될 수 있다.

---

# 11. 역할별 Dramatic Question

## Hunt

# **먹을 것을 더 좇을 것인가, 시간·거리·위험·사람을 생각해 돌아갈 것인가?**

## Gather

# **가까운 곳에서 충분히 찾지 못할 때 어디까지 더 살펴볼 것인가?**

## Camp

# **해야 할 생활을 이어가면서 아직 돌아오지 않는 사람들을 어떻게 기다릴 것인가?**

전체:

# **이곳에서 우리는 계속 살아갈 수 있을까?**

질문은 텍스트로 제시하기보다 상황이 질문 자체가 되게 한다.

# 14. Choice Fairness

모든 선택이 같은 결과를 가져야 하는 것은 아니다.

판정 기준:

- 당시 판단할 정보가 있었는가?
- 결과가 앞선 조건과 연결되는가?
- 우연/불확실성이 있어도 자의적인 벌처럼 느껴지지 않는가?
- 결과가 학생 인격의 좋고 나쁨으로 채점되지 않는가?

현실적인 실패·후회·죄책감을 허용한다.

---

# 15. Threat / Horror

특히 Hunt는 공포게임 같은 강한 순간을 가질 수 있다.

```text
정적
→ 이상 징후
→ 사람 반응
→ 내 몸 정지
→ 직접 확인
→ 위험 접근
→ 필요 시 strong-accent
→ 회피/판단
→ 남는 긴장 또는 안도
```

공포가 자연 속 인간의 취약성, 거리, 어둠, 협력과 연결되어야 한다.

의미 없는 jump scare 반복이나 적 처치 루프로 바꾸지 않는다.

---

# 16. Learning Invariants

모든 학생이 같은 장면을 볼 필요는 없다.

전체 경험에서 다음 조건은 충분히 드러난다.

- 도구가 생활 행동과 연결됨
- 불이 생활과 공동체에 중요함
- 먹을거리 확보가 불확실함
- 여러 사람이 다른 일을 하며 의존함
- 자연·시간·거리 조건을 완전히 통제할 수 없음
- 한 장소 생활의 부담이 누적됨
- 이동 생활이 앞선 경험과 연결됨

# **공통 역사 조건 + 서로 다른 개인 경험**

을 목표로 한다.

---

# 17. Common Evening

Common Evening은 **세 역할 관점이 모두 끝난 뒤 한 번** 열린다.

개별 역할 완료 뒤 저녁을 반복하지 않는다.

공통 저녁은 결과표가 아니라 재회다.

달라질 수 있는 것:

- 누가 먼저 누구를 보는가
- 무엇을 들고 돌아왔는가
- 얼마나 늦었는가
- 몸/동행자 상태
- 침묵/걱정/안도
- 함께 내려놓거나 나누는 행동

Common Evening은 역할별 점수 합산이 아니라 **서로 다른 하루의 결과가 한 장소에서 만나는 장면**이다.

---

# 18. Cross-Role Causality Guardrail

앞 역할의 선택은 이후 역할에서 의미 있게 회수될 수 있다.

그러나 다음을 금지한다.

- 나중에 플레이한 역할이 앞 역할의 이미 플레이된 과거 사건을 소급 변경
- Hunt 선택 때문에 Gather의 독립적 핵심 사건이 사라짐
- 먼저 플레이한 역할이 다른 역할의 정답을 미리 알려줌
- 모든 역할을 하나의 거대한 공유 상태 기계로 결합

Cross-role 신호는 **재회·기다림·대사·사물·후속 관점의 의미 변주**에 우선 사용한다.

---

# 19. 며칠의 변화와 이동

세 역할의 같은 하루가 통합된 뒤에야 시간 축을 다음 날/며칠로 전진시킨다.

```text
Day 1 multi-perspective
→ Common Evening
→ later days
→ 자원/거리/부담 변화
→ 공동체 고민
→ 이동
```

이동은 정답 버튼이 아니라 앞선 누적 경험의 결론이어야 한다.

---

# 20. Historical Imagination → Conceptualization

좋은 플레이 뒤 학생이 먼저 이런 문장을 만들 수 있어야 한다.

> 먹을 것을 찾으려면 멀리 갈 수도 있고, 해가 지면 돌아오는 것도 위험했을 것 같다.

> 밖에 나간 사람이 무슨 일을 겪는지 남아 있는 사람은 몰라서 기다리는 시간이 불안했을 것 같다.

교과 개념은 이런 이해에 이름을 붙인다.

Reflection/질문은 필요할 때만 사용하며 경험 자체를 대체하지 않는다.

---

# 21. Acceptance Gate

- Student Play Order와 in-world same-day time이 구분되는가?
- 역할 진입 시 현재 시점이 명확한가?
- 역할 내부가 해당 인물의 제한 시점인가?
- 다른 역할 정보를 전지적으로 미리 알려주지 않는가?
- 각 역할이 다른 몸·공간·감정·딜레마를 갖는가?
- Cross-role signal이 과거를 소급 변경하지 않는가?
- 죄책감·후회·공포·안도가 자연스럽게 생길 수 있는가?
- Common Evening이 세 역할 뒤 한 번만 열리는가?
- 같은 하루가 끝난 뒤에만 multi-day 단계로 넘어가는가?
- 학생이 플레이를 통해 역사적 이유를 상상하기 시작하는가?

## 판정

이 구조를 Stage 03~06의 시간·관계·상태 계약이 침해하면 하위 문서를 수정한다.
