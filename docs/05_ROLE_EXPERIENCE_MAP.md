# 구석기 역사 체험 웹게임
## Stage 05 — 세 역할 핵심 경험 맵 v7 / Same-Day Distinct Role Grammar + Curriculum Anchors

> 목적: Hunt / Gather / Camp가 같은 공동체와 같은 하루를 공유하되 **몸의 사용, 시선, 관계, 감정, 고민, 시간 감각, 결과 구조가 분명히 다른 역할 경험**이 되게 한다. 교과서 핵심 개념은 한 역할의 설명 부담으로 몰지 않고 서로 다른 생활 맥락에서 다시 만나게 한다.

# 1. 세 역할은 같은 하루의 서로 다른 몸

```text
Same Day 1
├─ Hunt: 멀어지는 몸
├─ Gather: 가까이 살피는 몸
└─ Camp: 같은 공간을 지키는 몸
```

학생 플레이 순서는 세계 시간과 다르다.

세 역할은 서로 다른 사람의 몸과 제한된 시야를 사용한다.

---

# 2. 역할별 핵심 문법

## Hunt

# **거리 / 흔적 / 도구 / 추적 / 위험 / 새 장소 / 귀환**

몸:

- 걷기
- 주먹도끼를 든 손
- 몸 낮추기
- 달리기/물러서기 가능
- 피로한 귀환

주요 감정:

- 기대
- 집중
- 발견의 흥분
- 두려움
- 후회/죄책감
- 안도
- 새로운 장소에 대한 호기심/경계

## Gather

# **가까운 환경 / 분별 / 손 / 채집 / 가공 / 반복 / 공간 기억 / 범위 확대**

몸:

- 풀/흙/뿌리를 만짐
- 땅을 파거나 꺼냄
- 두드리기
- 담기/옮기기
- 반복적으로 몸을 숙임

주요 감정:

- 집중
- 작은 발견의 만족
- 답답함
- 헛수고
- 익숙한 장소에 대한 기억
- 더 멀리 가야 할지도 모른다는 불안

## Camp

# **불 / 거처 / 손질 / 반복 노동 / 시간 / 빈자리 / 기다림 / 재회**

몸:

- 불 가까이 손
- 덮개/막집 손질
- 음식 익히기
- 가죽/도구/먹을거리 손질
- 밖을 바라봄

주요 감정:

- 안정감
- 반복 노동의 피로
- 걱정
- 기다림
- 불안
- 귀환의 안도
- 새 거처 이야기에 대한 기대/의심

# 3. Curriculum Anchor 분배 원칙

교과서 핵심을 다음처럼 역할에 분산한다.

| Anchor | Hunt | Gather | Camp |
|---|---|---|---|
| 뗀석기 | R에게 받음 / 명명 | 생활 행동에 재사용 | 손질/보관/불 옆에 놓임 |
| 주먹도끼 | 대표 도구로 몸에 유지 | 땅파기·두들기기 등 다용도성 강화 | 귀환한 도구를 다시 봄 |
| 불 | 출발/귀환 모티프 | 간접 연결 | 난방·조리·보호·생활 중심 |
| 막집 | 출발 거점 | 귀환 기준 | 직접 손질/생활 |
| 동굴/바위 그늘 | 발견/탐색 가능 | 주변 자원/쉼터 관점 | 새로운 거처 후보 논의 |
| 이동 생활 | 거리가 멀어짐 | 가까운 자원이 줄어 범위 확대 | 현재 장소를 유지할지 고민 |
| 먹을거리 | 사냥의 불확실성 | 채집의 중요성 | 가공/조리/분배 |

# **한 개념은 가능하면 두 역할 이상에서 다른 의미로 다시 만난다.**

---

# 4. Hunt — 교과 개념을 ‘몸에 들고 나가는’ 역할

Hunt에서 `뗀석기/주먹도끼`를 처음 명확히 짚는다.

권장 흐름:

```text
R의 손
→ 주먹도끼 받음
→ 짧게 용어 명명
→ 손에 계속 보임
→ 흔적/환경을 살피는 데 사용 가능
→ 귀환까지 continuity
```

주먹도끼를 박물관식 item card로 만들지 않는다.

---

# 5. Gather — 주먹도끼의 ‘만능 도구’ 의미를 확장

Gather는 주먹도끼 또는 다른 뗀석기를 생활 가공에 사용하며 Hunt와 다른 의미를 보여준다.

예:

- 땅을 파 풀뿌리를 찾음
- 단단한 부분을 두드림
- 먹을거리 손질

교과서에 나오는 `풀뿌리를 두들겨 먹기 편하게 함` 같은 생활 맥락을 참고할 수 있다.

핵심:

# **같은 도구가 사냥 무기만이 아니라 생활 도구라는 감각**

을 준다.

다만 모든 Gather 행동을 주먹도끼 하나로 해결하지 않는다.

---

# 6. Camp — 불과 거처를 ‘생활 유지’로 경험

Camp에서 불은 가장 직접적인 Curriculum Anchor다.

학생은 설명보다 행동으로 다음을 경험한다.

- 차가운 몸/손을 불 가까이에 둠
- 고기나 먹을거리를 익힘
- 불이 약해지면 유지해야 함
- 어두워질수록 불 주변의 안정감이 커짐

이후 짧게 불의 기능을 교과 개념으로 연결할 수 있다.

---

# 7. 막집은 Camp의 핵심 생활 공간

현재 공동체의 기본 거처가 막집 중심이라면 학생이 직접

- 흔들리는 덮개
- 바람이 들어오는 틈
- 비를 완전히 막지 못하는 부분
- 손질해야 하는 나뭇가지/가죽

을 경험한다.

먼저 경험한 뒤:

> **막집**
> 비바람을 겨우 피할 정도의 임시 거처

정도로 짧게 명명할 수 있다.

막집을 안정적인 영구 주택처럼 묘사하지 않는다.

---

# 8. 동굴 / 바위 그늘은 다른 생활 공간 가능성

Hunt에서 직접 발견할 수 있다.

Gather에서는:

- 바위 그늘 아래 식물/자원
- 비를 잠시 피하는 경험
- 주변 환경 기억

으로 나타날 수 있다.

Camp에서는 Hunt가 발견한 장소를 다른 관점으로 재평가한다.

예:

```text
Hunt:
“안이 넓고 바람을 피하기 괜찮아 보였어.”

Camp:
현재 막집 덮개를 손질함
→ 그 이야기를 들음
→ '하지만 물은 가까운가?'라는 다른 고민
```

# **동굴 = 막집의 업그레이드가 아니다. 조건이 다른 생활 공간이다.**

---

# 9. 동굴 발견의 Cross-Role 의미

Hunt에서 저장할 수 있는 질적 signal:

- `hunt-cave-shelter-noticed`
- `hunt-cave-shelter-inspected`
- `hunt-cave-animal-sign-seen`

Camp에서 이를 점수처럼 읽지 않는다.

후속 장면 variation에 사용한다.

예:

- 동굴 얘기를 듣고 관심을 보임
- 동물 흔적 때문에 신중하게 반응
- 현재 막집 수리 부담과 비교

---

# 10. 역할별 ‘정답 문제’ 방지

## Hunt에서 피할 것

> 주먹도끼의 용도는 무엇인가?

## Gather에서 피할 것

> 구석기인은 무엇을 채집했는가?

## Camp에서 피할 것

> 구석기 사람의 집은 막집인가 동굴인가?

대신 실제 행동·상황이 먼저다.

교과 용어는 짧고 명확하게 짚되, 선택을 시험으로 바꾸지 않는다.

# 11. Historical Fact와 역할별 재구성

Fact:

- 뗀석기 사용
- 주먹도끼 다용도성
- 이동 생활
- 불 사용
- 막집
- 동굴/바위 그늘 생활

Reconstruction:

- R이 도구를 건넴
- Gather 인물이 특정 뿌리를 발견함
- Camp 인물이 그날 막집을 손질함
- Hunt가 그날 특정 동굴을 발견함

세 역할 모두 이 구분을 침해하지 않는다.

# 12. 역할별 Primary Attention

## Hunt

우선 시선:

- 상대 손 / 도구
- 흔적
- 동행자 반응
- 위험
- 동굴 입구
- 귀환 불빛

## Gather

우선 시선:

- 지면/식물
- 손
- 도구
- 담는 물건
- 이전 장소의 흔적

## Camp

우선 시선:

- 불
- 손질할 거처
- 음식
- 빈자리
- 돌아오는 사람

교과 용어 cue가 Primary Attention을 빼앗지 않게 한다.

# 13. 역할별 Screen Treatment

## Hunt

- 이동 sway
- 추적 focus
- 위험 accent / strong-accent 가능
- 동굴 입구에서 exposure 변화
- 귀환 불빛 warm recovery

## Gather

- 작은 focus shift
- 손/대상 강조
- 시간 변화는 미묘하게
- Hunt식 horror accent 반복 금지

## Camp

- fire warmth
- 서서히 변하는 ambient light
- 기다림에서 소리/밝기 변화
- 귀환 순간 작은 회복 accent

---

# 14. 세 역할의 결과 구조

## Hunt

- food outcome
- return burden
- danger experience
- relationship memory
- shelter discovery

## Gather

- gathered resources의 질적 상태
- 가까운 장소에서의 부족 경험
- 이동 범위
- 가공/도구 사용 경험
- 공간 기억

## Camp

- fire/거처 유지 상태
- 기다림 경험
- 돌아온 사람과의 관계
- 현재 거처 부담
- 새 장소에 대한 공동체 관심/경계

점수표로 합치지 않는다.

---

# 15. Common Evening에서의 결합

세 역할 경험이 하나의 생활로 다시 묶인다.

가능한 장면:

- Hunt의 주먹도끼가 불 옆에 놓임
- Gather한 뿌리/열매를 두드리거나 손질
- Hunt가 가져온 고기를 불에 익힘
- Camp에서 유지한 불과 거처가 귀환의 장소가 됨
- 새 동굴 이야기를 사람들이 들음

이렇게 하면 교과서 의·식·주 요소가 별도 표가 아니라 **같은 저녁의 생활**로 만난다.

---

# 16. Multi-Day 이동 서사

동굴 발견은 단독으로 이동을 결정하지 않는다.

다음이 누적될 수 있다.

```text
가까운 자원 감소
+ 사냥/채집 거리 증가
+ 막집 유지 부담
+ 새로운 동굴/바위 그늘 후보
+ 물/먹을거리 접근성
+ 위험 정보
```

이것이 여러 날 뒤

> **여기를 떠나야 할까?**

라는 공동체 고민으로 발전한다.

교과서의 `먹을 것을 찾아 옮겨 다님`을 결과 문장으로 주기보다 원인을 살아보게 한다.

# 17. Stage 05 Acceptance Gate

- Hunt/Gather/Camp가 같은 플레이 문법을 공유하지 않는가?
- 세 역할이 같은 dayId의 다른 관점인가?
- 뗀석기/주먹도끼가 Hunt에서 명명되고 다른 역할에서 재사용될 수 있는가?
- 주먹도끼가 사냥 전용 무기로 오해되지 않는가?
- 불의 기능을 Camp에서 실제 행동으로 경험하는가?
- 막집을 직접 생활/손질하는가?
- 동굴/바위 그늘을 다른 생활 공간 가능성으로 다루는가?
- 동굴 발견이 Hunt에서 끝나지 않고 후속 관계/공동체 문제로 회수될 수 있는가?
- 이동 생활의 이유가 세 역할 결과를 통해 누적되는가?
- 교과서 핵심이 역할마다 퀴즈로 변질되지 않는가?
- Common Evening에서 의·식·주·도구·관계가 다시 결합되는가?

이 Gate를 통과한 역할 맵만 Stage 06 기술 설계와 Stage 07 Skeleton의 기준으로 사용한다.
