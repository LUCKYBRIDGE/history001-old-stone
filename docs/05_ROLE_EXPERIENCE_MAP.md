# 구석기 역사 체험 웹게임
## Stage 05 — 세 역할 핵심 경험 맵 v9 / Same-Day Social Recontextualization Grammar

>
> 기준선:
> - `docs/00_CANONICAL_BASELINE.md`
> - `docs/01B_RELATIONSHIP_AGENCY_PRINCIPLES.md`

# 1. 같은 하루의 서로 다른 몸

```text
Same Day 1
├─ Hunt: 멀어지는 몸
├─ Gather: 가까이 살피는 몸
└─ Camp: 같은 공간을 지키는 몸
```

Student Play Order와 In-World Time은 다르다.

# **같은 Day 1을 공유해도 같은 정보·감정·의미를 공유하는 것은 아니다.**

# 2. 역할별 핵심 문법

## Hunt

# **거리 / 흔적 / 주먹도끼 / 추적 / 위험 / 새 장소 / 귀환**

몸:

- 걷기
- 도구 든 손
- 몸 낮추기
- 물러서기/짧은 도주
- 피로한 귀환

감정:

- 기대
- 집중
- 발견의 흥분
- 두려움/공포
- 후회/죄책감
- 안도
- 새 장소에 대한 호기심/경계

관계:

- 함께 떠난 사람과 같은 사건을 몸으로 겪음
- 거처에 남은 사람의 말이 시간/거리 압박으로 callback
- 귀환 때 아침 관계가 다른 의미로 돌아옴

## Gather

# **가까운 환경 / 분별 / 손 / 채집 / 가공 / 반복 / 공간 기억 / 범위 확대**

몸:

- 풀/흙/뿌리를 만짐
- 땅파기
- 두들기기
- 담기/옮기기
- 반복적으로 몸을 숙임

감정:

- 집중
- 작은 발견의 만족
- 답답함/헛수고
- 익숙한 장소 기억
- 더 멀리 가야 할지도 모른다는 불안

관계:

- 가까운 공간에서 다른 사람과 노동/분별을 나눔
- Hunt와 다른 시각에서 같은 랜드마크·사람·도구를 만날 수 있음
- 다른 역할의 사건을 직접 보지 않았다면 자동으로 알지 않음

## Camp

# **불 / 현재 거처 / 생활 유지 / 손질 / 시간 / 빈자리 / 기다림 / 재회 / 새 장소 재평가**

몸:

- 불 가까이 손
- 임시 거처 덮개/재료 손질
- 음식 익히기
- 가죽/도구/먹을거리 손질
- 밖을 바라봄

감정:

- 안정감
- 반복 노동의 피로
- 걱정/기다림
- 불안
- 귀환의 안도
- 새 거처 이야기에 대한 기대/의심

관계:

- Hunt에서 `떠나는 나`였던 사람이 Camp에서는 `떠나는 다른 사람`이 될 수 있음
- 비어 있는 자리와 낮아지는 해가 관계의 시간성을 만듦
- 귀환은 결과 보고 화면이 아니라 기다림의 종료/변화

# 3. Curriculum Anchor 분배

| Anchor | Hunt | Gather | Camp |
|---|---|---|---|
| 뗀석기 | 도구를 받은 뒤 상위 개념 명명 | 다른 뗀석기/도구 사용과 연결 가능 | 도구 손질/보관 |
| 주먹도끼 | 대표적인 구체 예로 첫 만남/continuity | 땅파기·두들기기·손질 등 다용도성 강화 | 돌아온 도구를 다시 봄 |
| 불 | 출발/귀환 anchor | 간접 연결 | 난방·조리·보호·생활 중심 |
| 현재 임시 거처 | 출발 거점 | 귀환 기준 | 실제 생활/손질 대상 |
| 막집 | 아직 조기 명명하지 않아도 됨 | 간접 | 생활/손질 뒤 정식 명명 |
| 동굴/바위 그늘 | 발견/탐색 가능 | 쉼터/환경 기억 가능 | 전달받은 정보/직접 경험에 따라 새 거처 후보 재평가 |
| 이동 생활 | 거리가 멀어짐 | 가까운 자원이 줄어 범위 확대 | 현재 장소 유지 여부 고민 |
| 먹을거리 | 사냥의 불확실성 | 채집 중요성 | 가공/조리/분배 |

# **한 개념은 가능하면 두 역할 이상에서 다른 의미로 다시 만난다.**

---

# 4. Hunt — 도구와 함께 멀어지는 역할

권장 흐름:

```text
익숙한 사람의 손
→ 돌도구를 받음
→ 뗀석기 상위 개념 명명
→ 지금 손의 대표적인 예 = 주먹도끼
→ 손에 계속 보임
→ Stage 08 이후 실제 생활 행동에 재사용
→ 귀환까지 continuity
```

Player-facing에서는 `R의 손` 같은 authoring ID를 노출하지 않는다.

주먹도끼를 item card나 사냥 무기로만 만들지 않는다.

---

# 5. Gather — 도구의 생활 의미를 확장

Gather는 Hunt와 다른 방식으로 도구를 사용한다.

예:

- 땅을 파 풀뿌리를 찾음
- 단단한 부분을 두드림
- 먹을거리 손질

핵심:

# **같은 시대의 도구가 공격용 하나가 아니라 생활 문제를 해결하는 수단이라는 감각**

모든 Gather 행동을 주먹도끼 하나로 해결하지는 않는다.

---

# 6. Camp — 불과 거처를 생활 유지로 경험

Camp에서 불은 가장 직접적인 Anchor다.

행동으로 먼저 경험:

- 차가운 몸/손을 불 가까이에 둠
- 먹을거리 익히기
- 불 유지
- 어두워질수록 불 주변의 안정감

그 뒤 불의 기능을 교과 개념으로 연결한다.

Camp의 불은 Hunt에서 보았던 **같은 생활 중심**이면서, Hunt에서는 떠나고 돌아오는 spatial anchor, Camp에서는 계속 지켜야 하는 생활 조건이다.

---

# 7. 현재 임시 거처 → 막집

Stage 07의 현재 거처를 처음부터 최종 교과 `막집`으로 단정하지 않는다.

Camp 기본 경로:

```text
현재 임시 거처에서 생활
→ 흔들리는 덮개/바람/재료를 직접 손질
→ 왜 임시 거처인지 이해
→ 짧게 '막집' 명명
```

막집을 안정적인 영구 주택처럼 묘사하지 않는다.

---

# 8. 동굴 / 바위 그늘 — 조건이 다른 생활 공간

Hunt:

- 직접 발견/살핌 가능

Gather:

- 바위 그늘 아래 자원/잠시 비 피하기/공간 기억으로 나타날 수 있음

Camp:

- 직접 본 적이 없다면 Hunt가 가져온 정보를 **전달받은 뒤** 현재 거처의 생활 부담과 함께 재평가

예:

```text
Hunt:
직접 입구/바닥/어둠을 봄

귀환 뒤:
“오는 길에 큰 바위 아래 넓은 곳이 있었어.”

Camp:
현재 거처 손질
→ 그 말을 들음
→ “물은 가까운가?”라는 다른 고민
```

# **동굴 = 막집의 업그레이드가 아니다.**

# **다른 역할에서 본 사실 = 내 캐릭터가 자동으로 아는 사실이 아니다.**

---

# 9. Cross-Role Social Recontextualization

같은 사람과 같은 사건을 역할마다 다른 의미로 경험하게 한다.

| Shared event | Hunt에서 | Camp에서 | 교육/감정 의미 |
|---|---|---|---|
| 새벽 불 | 떠나기 전 온기/생활 중심 | 계속 유지해야 하는 생활 중심 | 불은 단일 기능이 아님 |
| 돌도구 전달 | 내 손에 주먹도끼가 들어옴 | 다른 사람에게 도구를 건네는 반대편 몸 | 같은 사건의 관계적 재해석 |
| 출발 | 내가 사람들과 멀어짐 | 사람들이 내 앞에서 멀어짐 | 이동과 부재의 양면 |
| `해가 지기 전에 와` | 후반 귀환 압박 | 기다림의 시작 | 시간 + 관계 callback |
| 오후 | 기회/위험/거리 | 빈자리/낮아지는 해/생활 유지 | 같은 시간의 다른 감정 |
| 불빛 | 돌아갈 곳을 찾는 신호 | 사람들이 돌아오길 기다리는 장소 | spatial anchor + 사회적 의미 |
| 귀환 | 안도/피로/아쉬움 | 기다림 종료/걱정 회수 | 성공/실패보다 공동체 재결합 |

Gather는 같은 Day 1의 제3의 정보축을 제공한다.

예:

- Hunt/Camp가 직접 못 본 흔적이나 자원 상태를 볼 수 있음
- Hunt가 멀리 간 사이 가까운 환경이 어떻게 변했는지 경험
- Camp가 나중에 들은 정보를 Gather는 직접 보았을 수도 있음

# **Perspective의 목적은 장면 반복이 아니라 의미와 정보의 차이를 만드는 것이다.**

# 10. Shared Memory와 Knowledge Transfer

가능한 event/memory signal:

- `hunt-cave-shelter-noticed`
- `hunt-cave-shelter-inspected`
- `hunt-cave-animal-sign-seen`
- `return-line-heard`
- `returned-late`
- `returned-empty-handed`
- `shared-track-observation`

다른 역할에서는 점수처럼 읽지 않는다.

대신:

- 관심
- 경계
- 침묵
- 현재 거처 부담과 비교
- 물/먹을거리 질문
- 귀환 반응

같은 variation에 사용한다.

필수 구분:

```text
World event happened
≠
Character witnessed it
≠
Character later heard about it
```

구체 기술 schema는 `docs/06_TECH_BLUEPRINT.md`만 소유한다.

---

# 11. Perspective Knowledge Boundary

역할 전환 시 이전 역할의 내부 정보를 자동으로 복사하지 않는다.

각 관점에서 구분한다.

- 직접 본 것
- 함께 겪은 것
- 들은 것
- 아직 모르는 것

예:

Hunt가 동굴 안쪽 흔적을 보았지만 Camp에게 말하지 않았다면:

- Camp는 `새 공간이 있었다`는 것조차 모를 수 있음

Hunt가 귀환 뒤 이야기했다면:

- Camp는 직접 본 것이 아니라 **전달받은 정보**로 안다

# **Limited Knowledge가 있어야 다른 관점이 의미를 가진다.**

# 12. 역할별 정답 문제 방지

피할 것:

- Hunt: `주먹도끼의 용도는?`
- Gather: `구석기인은 무엇을 채집했나?`
- Camp: `집은 막집인가 동굴인가?`

대신 실제 행동·상황·관계가 먼저다.

---

# 13. 역할별 위험 문법

## Hunt

자연 위험/미지/거리/귀환이 강한 긴장축.

## Gather

오판·헛수고·낯선 식물·범위 확대 같은 다른 불확실성.

## Camp

불 꺼짐, 날씨, 부재/기다림, 현재 거처 부담 같은 생활 위험.

Hunt의 jump-scare/추적 문법을 다른 역할에 복제하지 않는다.

같은 사건도 역할에 따라 위협의 종류가 다를 수 있다.

예:

- Hunt에게 늦은 시간 = 귀환 위험
- Camp에게 같은 늦은 시간 = 돌아오지 않는 사람에 대한 걱정

- risk exposure

- 도구/가공 경험

- what Camp actually knows

점수·랭킹으로 합치지 않는다.

# 15. Fact / Reconstruction

공통 Fact:

- 도구/불/거처/이동 생활 같은 역사적 조건

재구성:

- R/H1/H2 authoring identity에 대응하는 구체 가상 인물
- 그 인물의 이름/습관/shared past
- 어느 사람이 어느 날 무엇을 발견/말했는지
- 구체 감정/선택 결과
- 누가 어떤 정보를 언제 전달했는지

Teacher/Debug에서 경계를 관리한다.

Player-facing에서는 재구성 관리 라벨보다 장면 연속성을 우선한다.

# 16. Stage 05 Acceptance Gate

- 세 역할의 몸/시선/감정 문법이 다른가?
- 같은 사람/같은 사건이 역할마다 다른 의미로 재해석되는가?
- 같은 Day 1이라는 이유로 모든 역할이 같은 정보를 자동으로 알고 있지 않은가?
- 직접 경험 / 목격 / 전달받음 / 모름을 구분할 수 있는가?
- Hunt가 교과 설명을 독점하지 않는가?
- `뗀석기 → 주먹도끼` 관계가 모든 역할에서 일관적인가?
- 주먹도끼를 사냥 전용 무기로 축소하지 않는가?
- current temporary shelter와 막집 명명 시점이 구분되는가?
- 동굴/바위 그늘을 다른 조건의 생활 공간으로 다루는가?
- 불이 Hunt에서는 출발/귀환, Camp에서는 유지/기다림의 다른 의미를 갖는가?
- `해가 지기 전에 와` 같은 관계 motif가 다른 관점에서 의미가 달라지는가?
- cross-role signal이 점수가 아닌가?
- 각 역할의 위험/결과 문법이 복제되지 않는가?
- Perspective 전환이 단순 `다른 화면`보다 이전 사건의 사회적 재해석을 만드는가?
