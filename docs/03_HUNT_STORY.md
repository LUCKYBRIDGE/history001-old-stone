# 1. Hunt 한 문장

# **새벽의 현재 임시 거처에서 이미 함께 살아온 사람에게 돌도구를 받아, 익숙한 두 사람과 먹을 것을 찾으러 나간 한 사람이 흔적을 읽고 기회를 좇다가 거리·해·위험·새 자연 거처 후보·귀환 부담 사이에서 판단하고 자기 선택의 결과를 안고 같은 불과 사람들에게 돌아오는 하루.**

핵심 질문:

> **오늘 먹을 것을 구하고 사람들에게 돌아갈 수 있을까?**

보조 질문:

- 이 돌도구는 왜 여러 순간에 필요할까?
- 멀리서 발견한 저 공간은 머물 만한 곳일까?
- 조금 더 가는 선택은 무엇을 바꿀까?
- 내가 함께 살아온 사람들에게 오늘의 선택은 어떤 의미가 될까?

# 2. Hunt Learning Invariants

어떤 분기에서도 Hunt 전체에서 다음이 드러나야 한다.

1. 사냥은 공격보다 흔적·환경 관찰에서 시작한다.
2. 발견은 먹을거리 확보를 보장하지 않는다.
3. 뗀석기라는 상위 도구 개념을 경험과 연결한다.
4. 현재 손의 구체 예가 주먹도끼임을 짧게 명명한다.
5. 주먹도끼는 카드가 아니라 손에 들고 이어지는 생활 도구다.
6. 더 멀리 가는 것은 시간·거리·피로·귀환 부담을 키울 수 있다.
7. 자연 속 인간도 위험에 노출된다.
8. 먹을 것을 구했든 빈손이든 귀환까지가 Hunt다.
9. 동굴/바위 그늘 같은 자연 공간을 생활에 이용할 이유를 경험할 수 있다.
10. 새 공간을 발견했다고 즉시 새 집이 되지는 않는다.
11. Hunt만으로 공동체 하루가 완성되지 않는다.
12. 주요 인물은 기능 설명이 아니라 이름·습관·shared event·callback으로 기억되어야 한다.
13. Player는 이 공동체를 처음 방문한 사람이 아니라 Day 1 이전부터 함께 살아온 사람처럼 행동해야 한다.

# 3. 반복 인물 — Character Memory Sheet

R/H1/H2는 **authoring ID**다. Player-facing 이름은 별도의 fictional naming review 후 확정하며, 실제 구석기 이름이라고 주장하지 않는다.

각 인물은 기능으로 소개하지 않고 다음 다섯 항목으로 설계한다.

```text
Player-facing name
+ embodied habit
+ shared past hint
+ today's shared event
+ callback
```

# 3A. Day 1 공동체는 핵심 인물 3명만 존재하지 않는다

Player + R/H1/H2만 보이면 작은 RPG party처럼 읽힐 수 있다.

따라서 production/world design에서는 이름 없는 background community actor가 자기 생활을 이어갈 수 있다.

예:

- 불을 살피는 사람
- 재료/먹을거리를 정리하는 사람
- 현재 거처 덮개를 만지는 사람
- 쉬고 있는 사람
- 다른 사람과 짧게 대화하는 사람

정확한 공동체 인원수와 구체 사회 조직을 역사적 보편 사실로 단정하지 않는다.

# **핵심 인물은 세계의 유일한 NPC가 아니라, Player가 오늘 특히 많이 얽히는 사람들이다.**

# 4. 감정선

# **이미 이어져 온 일상의 온기 → 도구 전달 → 소속감 → 멀어짐 → 집중 → 발견의 기대 → 추적 욕구 → 새 장소 호기심 → 시간 압박 → 불안 → 위협/공포 → 판단 → 결과 → 피로/후회 또는 성취 → 귀환 긴장 → 같은 불빛 → 재회 → 안도·죄책감·아쉬움의 혼합**

감정은 점수나 도덕 판정이 아니다.

---

# 5. 1막 — 눈뜨기 전부터 이어지던 새벽

아직 완전히 밝지 않다.

Player가 눈을 뜨기 전에도 세계는 이미 진행 중이다.

가능한 sensory/social layer:

- 장작이 내려앉는 소리
- 낮은 발소리
- 누군가 재료를 옮기는 소리
- Player에게 정보를 주기 위한 것이 아닌 짧은 NPC-to-NPC 대화
- 불 냄새와 눈꺼풀 너머 붉은빛

눈을 뜬 뒤:

- 모두가 Player를 동시에 바라보지 않음
- background actor는 자기 행동을 계속함
- R과 짧게 눈이 마주칠 수 있음
- 다른 사람이 R의 이름을 자연스럽게 불러 학생이 이름과 위치를 연결할 수 있음
- 현재 임시 거처는 설명문보다 생활 행동과 공간으로 먼저 존재

학생이 먼저 경험:

- 불 가까운 손/무릎
- 이미 움직이고 있는 사람들
- 비바람을 피하려 세워 둔 현재 임시 거처
- 익숙한 사람의 반응

불은 배경이 아니라 따뜻함·생활 중심·귀환 anchor로 먼저 느껴진다.

Stage 07에서는 이 현재 거처를 바로 `막집`이라고 명명하지 않는다.

# **첫 장면의 목적은 사람을 소개하는 것이 아니라, Player가 이미 이 생활 안에 있었다고 느끼게 하는 것이다.**

---

# 6. 2막 — 손, 돌, 기억

R이 한쪽은 손에 잡히고 다른 쪽은 날카롭게 깨진 돌도구를 내민다.

```text
R의 손
→ 돌도구
→ 내 손
```

R은 먼저 도구를 설명하지 않는다.

가능한 짧은 말:

> `손.`

또는 shared past를 쓸 경우:

> `이번에는 놓치지 마.`

학생 행동:

> **돌도구를 받는다.**

받은 뒤 짧게:

> **뗀석기**  
> 돌을 깨뜨리거나 떼어 만든 도구를 뗀석기라고 한다. 지금 손에 든 것은 그 대표적인 예인 **주먹도끼**다.

이 장면에서 중요한 순서:

# **Person / Action → Embodied Contact → Experience → Name**

- modal 금지
- 즉시 퀴즈 금지
- R이 교과 문단을 말하는 연출 금지
- 다음 행동과 공존

특정 아침 R이 이 도구를 건네는 사건은 재구성이다.

---

# 7. 3막 — 사람들의 흐름에 합류해 나간다

H1/H2는 Player가 버튼을 누를 때까지 정지한 NPC가 아니다.

가능한 장면:

- H1은 이미 몇 걸음 움직였거나 준비를 마치고 기다림
- H2는 Player보다 바깥쪽/다른 사람/먼 곳을 보고 있을 수 있음
- H1과 H2 사이 짧은 말이 오갈 수 있음
- Player에게만 모든 대사가 향하지 않음

짧은 말:

> `가자.`

출발 직전 R:

> **`해가 지기 전에 와.`**

다른 핵심 인물이 대신 대답할 수도 있다.

Player는 주먹도끼를 계속 손에 가진다.

불·사람·현재 임시 거처가 뒤에서 점점 멀어진다.

# **귀환 motif는 퀘스트 지시가 아니라 이미 관계가 있는 사람이 한 일상적 말이어야 한다.**

---

# 8. 4막 — 흔적을 찾기 전의 빈 공간

사냥감은 처음부터 보이지 않는다.

학생은:

- 눌린 풀
- 흙 변화
- 가지
- 소리
- 지면

을 직접 살핀다.

거처에서 멀어지는 감각은 숫자 HUD보다 다음으로 전달한다.

- 불이 작아짐
- 사람 소리가 줄어듦
- 거처가 보이지 않게 됨
- 기억할 수 있는 랜드마크를 지남

Stage 08 이후에는 주먹도끼를 흙·풀 주변을 살피거나 장애물을 치우는 생활 행동에 사용할 수 있다.

Stage 07 Skeleton에서 단순히 손에 들고 관찰한 것을 `다용도성 경험 완료`로 처리하지 않는다.

---

# 9. 5막 — 사람의 행동으로 발견이 시작된다

발견은 `H1이 흔적을 발견했습니다` 같은 설명으로 시작하지 않는다.

가능한 문법:

```text
앞서 가던 사람이 멈춤
→ 발소리가 끊김
→ 몸을 낮춤
→ Player가 그 변화를 알아차림
→ 가까이 감
→ 상대가 몸을 비켜줌
→ Player가 직접 눌린 풀/흙을 봄
```

H2는 같은 순간 다른 방향을 볼 수도 있다.

발견은 시스템 배너보다 사람의 정적·시선·몸짓과 Player의 직접 관찰에서 시작한다.

# **Character habit이 gameplay tutorial을 대신해야 한다.**

---

# 10. 6막 — 접근과 첫 시도

가능한 의도:

- 기다린다.
- 조금 가까이 간다.
- 지금 기회를 잡는다.

결과:

- 기회가 생김
- 대상이 이동
- 흔적이 이어짐
- 놓침

즉시 승패를 확정하지 않는다.

---

# 11. 7막 — 조금만 더

중심 딜레마 전에 학생은 설명 카드가 아니라 world state로 다음을 알아야 한다.

- 이어지는 가능성
- 낮아지는 해
- 보이지 않는 거처
- 함께 온 사람들의 피로/몸 상태
- 손의 주먹도끼
- 아침에 들은 귀환 말

가능한 선택:

- 조금 더 따라감
- 돌아갈 때를 생각함
- 주변/해/사람 상태를 더 확인함

사람 사이에 판단 차이가 생길 수 있다.

예:

> `조금만 더.`

다른 사람은 해를 보고:

> `늦어.`

한쪽을 정답 NPC로 만들지 않는다.

더 밀어붙이면 더 큰 기회와 위험이 함께 생길 수 있다.

아침의 `해가 지기 전에 와`가 이때 처음으로 실질적 압박과 관계 callback이 되어야 한다.

---

# 12. 8막 — 한동안 이동한 뒤 새로운 지형

추적 또는 주변 확인 과정에서 큰 바위 아래 어두운 공간을 볼 수 있다.

갑자기 `동굴 발견!` 배너를 띄우지 않는다.

```text
한동안 더 이동
→ 익숙한 길의 기준이 줄어듦
→ 한 사람이 먼저 멈춤
→ Player가 정지/시선 변화를 알아차림
→ 큰 바위 아래 어두운 틈을 직접 봄
→ 가까이 감
```

이 장면에서도 `주변을 살피는 사람` 같은 기능 설명을 사용하지 않는다.

특정 날 이 사람들이 이 공간을 발견하는 사건은 재구성이다.

---

# 13. 9막 — 자연 거처 후보를 살핀다

직접 확인 가능한 것:

- 입구가 넓음
- 위가 두꺼운 바위로 가려짐
- 바닥 일부가 비교적 마름
- 비/바람을 피할 가능성
- 안쪽은 어둡고 끝이 잘 안 보임
- 다른 동물 이용 여부 불확실
- 물/먹을거리 거리 불확실

사람 반응 후보:

> `안이 꽤 넓어.`

> `안쪽은 먼저 봐야 해.`

이 대사들은 기능 설명이 아니라 각 인물의 위치·몸 방향·이전 행동과 연결된다.

탐색 뒤 짧게:

> **동굴 / 바위 그늘**  
> 구석기 사람들은 이런 자연 공간도 생활 공간으로 이용했다.

이 시점에 아직 직접 경험하지 않은 `막집`을 비교 설명으로 끌어오지 않는다.

새 공간을 기억하되 바로 이사하지 않는다.

가능한 world/shared memory:

- `cave-shelter-noticed`
- `cave-shelter-inspected`
- `cave-animal-sign-seen`
- `who-witnessed-cave`

누가 이 장소를 직접 보았는지 이후 관점의 knowledge와 연결한다.

---

# 14. 10막 — 이상한 것

동굴 장면과 위험 장면은 같은 사건일 수도, 별도일 수도 있다.

위험 징후:

- 평소와 다른 소리
- 큰 흔적
- 어두운 안쪽 움직임
- 수풀 움직임
- 갑작스러운 정적

순서:

```text
anomaly
→ person reaction
→ body reaction
→ player observation
→ treatment accent
→ judgment
```

동굴을 항상 공포 장소로 고정하지 않는다.

누가 먼저 위험을 알아차리는지는 고정된 `관찰 담당` 역할보다 현재 위치/시선/상황과 연결한다.

---

# 15. 11막 — 위험 대응

행동 후보:

- 사람들과 붙어 움직임
- 조용히 거리 만듦
- 안전한 방향 확인

위험 대응은 전투 승리 구조가 아니다.

가능한 결과:

- 거리 부담
- 시간 부담
- 피로
- shared relationship memory
- 불안/안도

위험 때 누가 누구에게 가까이 붙었는지, 누가 기다렸는지, 누가 먼저 움직였는지가 후속 관계 기억이 될 수 있다.

---

# 16. 12막 — 사냥 결과

결과는 단일 성공/실패가 아니다.

축:

- 먹을거리 확보 여부
- 얼마나 멀리 갔는지
- 위험을 얼마나 겪었는지
- 귀환 시간이 어떤지
- 누구와 무엇을 함께 겪었는지
- 새 자연 거처 후보를 누가 보았는지

성공/빈손 모두 정상적인 하루가 될 수 있다.

---

# 17. 13막 — 귀환

학생은:

- 랜드마크
- 이동 기억
- 낮아지는 해
- 몸의 피로
- 아침의 귀환 말
- 같이 돌아가는 사람의 상태

을 이용해 돌아간다.

거리 회수:

```text
아까 보이지 않던 익숙한 랜드마크
→ 더 가까운 생활 흔적
→ 멀리 보이는 같은 불빛
→ 사람 소리
→ 현재 거처
```

멀리 같은 불빛이 보이는 순간은 중요한 emotional callback이다.

아침의 불은 `출발 배경`, 저녁의 불은 `사람들에게 돌아가고 있다는 증거`가 된다.

---

# 18. 14막 — 불과 재회

먹을 것이 있든 없든:

# **`돌아왔다.`**

가 강한 감정적 순간이어야 한다.

가능한 변주:

- 이른/늦은 귀환
- 먹을거리 확보/빈손
- 위험 노출
- 새 장소 발견
- shared relationship memory

늦었다면 R은 `걱정 담당 NPC`처럼 긴 설명을 하지 않는다.

예:

- 불 옆에서 먼저 일어남
- Player의 손보다 얼굴을 먼저 봄
- 잠깐 침묵
- `왔네.`처럼 짧게 말함

이때 아침의 `해가 지기 전에 와`가 학생 안에서 다시 의미를 가질 수 있다.

게임이 학생을 나쁜 사람으로 판정하지는 않는다.

---

# 19. 자연 거처 정보의 후속 회수와 Limited Knowledge

발견한 경우 저녁에:

> `오는 길에 큰 바위 아래 넓은 곳이 있었어.`

같이 말할 수 있다.

후속 사람들이 묻는 것:

- 물은 가까운가?
- 바닥은 어떤가?
- 위험 흔적은 없었는가?
- 먹을거리와 거리는 어떤가?

즉시 이사 결론을 내리지 않는다.

# **Hunt에서 본 것을 Camp 인물이 자동으로 알고 있지 않는다.**

누가 직접 보았고, 누가 귀환 뒤 전달받았는지를 구분한다.

---

# 20. Curriculum Anchor 분기 독점 방지

Hunt에서 자연 거처 후보를 직접 보지 못해도 전체 경험에서 `동굴/바위 그늘 생활` 개념이 사라지면 안 된다.

대체 경로:

- Gather에서 바위 그늘 이용
- Camp에서 다른 사람의 발견 이야기
- Common Evening/Conceptualization에서 회수

이때 `다른 사람이 알고 있으니 내 캐릭터도 자동으로 안다`가 아니라, 관점별 정보 전달 사건을 통해 연결한다.

---

# 21. Stage 03 Acceptance Gate

- Hunt가 제한 1인칭인가?
- Player가 구석기 세계의 관광객이 아니라 이 공동체의 기존 구성원처럼 느껴지는가?
- 눈뜨기 전부터 공동체 생활이 진행 중인가?
- 핵심 인물이 기능 label보다 이름/습관/shared event/callback으로 설계되어 있는가?
- background community가 핵심 인물 3명만 있는 RPG party 느낌을 줄이는가?
- R의 도구 전달이 관계 장면인가?
- `뗀석기 → 주먹도끼` 관계가 정확한가?
- 단순 receive와 실제 다용도 사용을 구분하는가?
- H1/H2 authoring 기능이 Player-facing 설명으로 새어 나오지 않는가?
- NPC-to-NPC interaction이 최소한 일부 장면에서 존재할 수 있는가?
- 선택 전 시간/거리/사람 정보가 world state로 충분히 보이는가?
- 아침 귀환 말이 후반 시간/거리 압박과 재회에서 callback되는가?
- 자연 거처 후보가 자동 정답 집이 아닌가?
- 위험이 세계→사람→몸→효과 순서로 형성되는가?
- 공포·후회·죄책감이 역사 상황에서 자연스럽게 생길 수 있는가?
- 먹을거리 결과보다 귀환/재회까지가 Hunt인가?
- 누가 어떤 사건을 직접 알았는지 perspective별로 구분 가능한가?
- 특정 분기가 교과 개념을 독점하지 않는가?
