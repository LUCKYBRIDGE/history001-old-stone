# R2_EMBODIED_PLAYTEST_PROTOCOL.md

## 목적

R2 Stage 07 이후 prototype이 실제로 **신체화된 1인칭·관계·딜레마·명료성·안전·학습 전이**를 구현했는지 교사/학생이 검증한다.

자동 테스트와 별개다.

---

# 1. Session metadata

기록:

- 날짜
- 교사/학생
- 브라우저/화면 크기
- first play 여부
- reduced effects 여부
- 시작부터 첫 의미 있는 행동까지 걸린 시간
- 막힌 횟수
- 도움/hint 단계
- 중단/재시작 여부

---

# 2. 첫 30초 / Clarity

확인:

- 내 몸이 화면에 자연스럽게 보이는가?
- 몸이 풍경 위에 붙은 장식처럼 보이지 않는가?
- 내 앞에 실제 사람이 있다고 느껴지는가?
- 설명 없이 첫 행동을 이해하는가?
- 무엇을 눌러야 할지 찾느라 오래 헤매지 않는가?
- actor/environment cue만으로 가능한가?
- hint가 필요했다면 어느 단계에서 이해했는가?
- `게임 시작`보다 `이미 그곳에 있다`는 느낌이 강한가?

중요 기록:

> 사실: 첫 행동 전에 약 12초 동안 여러 곳을 클릭함.
>
> 해석: 도구 전달 장면의 Primary Attention이 약할 수 있음.

사실과 해석을 분리한다.

---

# 3. Primary Attention / Cognitive Load

장면마다 확인:

- 무엇을 가장 먼저 봤는가?
- 설계한 Primary Attention Target과 일치하는가?
- 몸/NPC/대사/효과가 서로 경쟁하지 않는가?
- 한 번에 정보가 너무 많지는 않은가?
- 중요한 단서를 놓친 이유가 있는가?

학생이 `어디를 봐야 할지 모르겠다`면 몰입 문제가 아니라 clarity 문제로도 기록한다.

---

# 4. 관계

- 기억나는 사람이 있는가?
- 그 사람이 왜 기억나는가?
- 물건/시선/행동을 실제로 주고받았다고 느끼는가?
- 내 선택을 그 사람이 기억하는 것처럼 느껴지는가?
- 관계 점수 없이도 관계 변화가 느껴지는가?
- NPC가 나를 평가/비난하는 느낌은 없었는가?
- 특정 선택을 하도록 죄책감을 주는 느낌은 없었는가?

---

# 5. 몸과 행동

- 걷기/앉기/몸 낮추기/운반에서 보이는 몸이 자연스러운가?
- 몸이 필요하지 않은 순간에는 과하게 보이지 않는가?
- 도구가 계속 같은 손/몸과 연결되어 보이는가?
- 사람과 내 손이 같은 공간에 있다고 느껴지는가?
- 몸이 현재 상태를 말해주는 순간이 있었는가?
- 손/팔/관절/광원에 이질감이 있는가?
- 과도한 흔들림/멀미가 있는가?

Body identity 관련 교사 QA:

- 역할의 몸 외형이 불필요하게 성별/연령 역할 고정관념을 암시하지 않는가?

학생에게 성별 고정관념을 직접 유도하는 질문은 하지 않고 자발적 해석을 관찰한다.

---

# 6. 위협 / 정서 안전

- `위험` 문구를 보기 전에 이상함을 느꼈는가?
- 무엇 때문에 위험하다고 느꼈는가?
- 주변 사람의 행동이 긴장에 영향을 줬는가?
- 내 몸의 멈춤/자세 변화가 자연스러운가?
- 전투보다 피하고 판단해야 하는 느낌이었는가?
- 너무 무섭거나 불쾌하지는 않았는가?
- jump scare처럼 느껴지지는 않았는가?
- 위험 뒤 recovery beat가 긴장을 적절히 낮추는가?

위협 목표:

# **긴장과 취약함은 느끼되 공포 체험이 되지 않는가?**

---

# 7. 고민 / Choice Fairness

- 실제로 망설인 선택이 있었는가?
- 왜 고민했는가?
- 선택 전에 판단에 필요한 정보를 봤는가?
- 정답을 찾는 느낌이었는가, 상황을 판단하는 느낌이었는가?
- 다른 선택도 나름 이유가 있다고 느꼈는가?
- 결과가 앞에서 본 조건과 연결된다고 느꼈는가?
- `몰랐던 정보 때문에 벌 받았다`는 느낌은 없었는가?
- 특정 선택만 명백히 좋은 사람/좋은 결과를 주는가?

---

# 8. 결과 / Reconvergence

- 내 선택 때문에 뒤 장면이 달라졌다고 느꼈는가?
- 성공/빈손 외에 시간·거리·관계·피로가 의미를 바꾸는가?
- 같은 거처로 돌아와도 내 하루에 맞는 반응처럼 느껴지는가?
- 다른 경로와 비교했을 때 재수렴 뒤에도 의미 차이가 남는가?
- 결과가 점수표처럼 정리되지는 않는가?

Round 2 이후 가능하면 서로 다른 2개 경로를 비교한다.

---

# 9. 관점 전환 / Orientation

- 다른 역할로 바뀔 때 `다음 미니게임`처럼 느껴지는가?
- 아니면 다른 사람의 몸과 눈으로 옮겨간 느낌이 드는가?
- 지금 누구의 위치인지 이해하는가?
- 손이 달라진 이유를 이해하는가?
- 같은 사람/불/물건/대사를 알아보는가?
- orientation 한 줄이 있다면 도움이 되는가, 몰입을 깨는가?
- 다른 관점에서 앞의 행동을 다시 생각한 순간이 있는가?

핵심:

> **`왜 손이 바뀌었지?`라는 혼란보다 `아, 이번엔 저 사람이구나`가 먼저 오는가?**

---

# 10. Screen Treatment

각 효과에 대해:

- 효과를 알아차렸는가?
- 효과가 상황을 이해하는 데 도움이 되었는가?
- 게임 HP/경고 효과처럼 느껴졌는가?
- 색/초점/깜빡임/흔들림이 과했는가?
- 효과 때문에 조작/읽기가 어려웠는가?
- 효과가 Primary Attention을 방해했는가?
- `멋진 효과`보다 `불이 따뜻함/긴장/피로/귀환`이 먼저 느껴졌는가?

특히:

- red flash 느낌 여부
- blink 빈도
- sway/멀미
- blur 불편

를 기록한다.

---

# 11. Reduced Effects parity

가능하면 같은 구간을 reduced effects로 확인한다.

- 진행 가능한가?
- 중요한 위험/시간/관계 정보를 여전히 이해하는가?
- 선택에 필요한 정보가 유지되는가?
- 관점 전환을 이해하는가?
- Learning Evidence가 동일하게 확보되는가?

Reduced effects가 `내용이 빠진 버전`이면 FAIL이다.

---

# 12. Learning Invariants

관찰/질문을 통해 확인한다.

학생이 경로와 관계없이 다음 근거를 경험했는가?

- 도구가 생활 행동에 쓰임
- 불이 생활과 연결됨
- 먹을거리 확보가 확실하지 않음
- 여러 역할이 서로 필요함
- 시간/거리/자연 조건의 제약
- 같은 곳에서 계속 생활하기 어려워지는 맥락
- 이동이 앞선 경험과 연결됨

모든 항목이 한 역할에서 보여야 하는 것은 아니다.

전체 체험에서 보존되어야 한다.

---

# 13. Micro Reflection / Learning Transfer

플레이 뒤 짧게 묻는다.

- 왜 더 따라갈지 돌아갈지 고민했어?
- 위험이라고 쓰여 있기 전에 무엇이 이상했어?
- 다른 사람의 입장에서 보니 무엇이 달랐어?
- 왜 여러 사람이 서로 다른 일을 해야 했을까?
- 왜 계속 같은 곳에 머물기 어려워졌을까?

평가 포인트:

- 화면의 설명을 반복하는가?
- 자기 플레이 사건을 근거로 말하는가?
- 다른 사람 관점을 연결하는가?

# **Experience → Reflection → Historical Concept**

전이가 실제로 일어나는지 본다.

---

# 14. Teacher / Classroom readiness

교사 확인:

- 현재 major phase를 확인할 수 있는가?
- student UI에 debug가 노출되지 않는가?
- checkpoint에서 재시작 가능한가?
- reduced effects를 쉽게 적용 가능한가?
- 학생이 막혔을 때 hint 상태를 확인 가능한가?
- 학생별 다른 결과가 있어도 공통 토론이 가능한가?

---

# 15. 역사적 오해 관찰

학생이 자발적으로 다음처럼 일반화하는지 관찰한다.

- `사냥은 남자가 하는 일이다.`
- `이 사람은 엄마/아빠/족장이다.`
- `구석기 사람들은 항상 이렇게 행동했다.`
- 재구성된 특정 대사를 역사적 사실로 받아들임

이런 해석이 반복되면 body/cast/story/context 설계를 수정한다.

---

# 16. 판정 체계

각 영역:

- PASS
- NEEDS REVISION
- FAIL

독립 판정:

- Functional Complete
- Embodied Complete
- Relationship/Agency Complete
- Clarity/Safety Complete
- Learning Complete
- Immersion Complete

자동 테스트 PASS는 위 사람 관찰 판정을 대신하지 않는다.

---

# 17. Stage 07 최소 완료 기준

모두 충족:

- [ ] 첫 행동을 큰 혼란 없이 수행
- [ ] 몸/사람/환경이 하나의 공간처럼 보임
- [ ] R 또는 핵심 인물이 기억됨
- [ ] walking/crouch POV가 과하지 않음
- [ ] screen treatment가 보조적으로 작동
- [ ] reduced effects에서도 동일 진행
- [ ] Perspective transition을 이해
- [ ] Player/Teacher/Debug 분리
- [ ] stable checkpoint 동작
- [ ] 최소 Learning Evidence가 실제 행동에서 생성됨

하나라도 핵심 FAIL이면 Hunt 전체 Stage 08로 가지 않고 Skeleton을 수정한다.
