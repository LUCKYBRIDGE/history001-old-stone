# R2_EMBODIED_PLAYTEST_PROTOCOL.md

## 목적

R2 Stage 07 Skeleton과 이후 Embodied role prototype이 **사람의 시야·몸·관계·감정·교과 개념·역사적 상상력**으로 작동하는지 확인한다.

현재 Stage 07은 최종 아트가 아니라 CSS/DOM layout proof다.

따라서 `예쁘다/안 예쁘다`보다 다음을 본다.

- 몸과 세계가 같은 공간처럼 느껴지는가
- 사람과 관계가 생기는가
- 교과 용어가 체험 뒤 정확하게 이름 붙여지는가
- 상위 개념/구체 유물 관계가 오해 없이 전달되는가
- cave가 설명 카드보다 실제 장소 발견처럼 느껴지는가
- 교과서 사실과 재구성 사건이 교사에게 구분되는가

첫 플레이에서는 Debug를 보지 않는다.

학생/교사가 스스로

- 무엇을 먼저 보았는지
- 무엇이 궁금했는지
- 어느 순간 `교과 공부` 느낌이 강해졌는지
- 어느 순간 실제 장소/사람처럼 느껴졌는지

를 관찰한다.

# 3. Stage 07 현재 흐름

```text
사냥을 나선 사람의 관점
→ 눈을 뜬다
→ 새벽 불 + 현재 임시 거처
→ R을 봄
→ 돌도구를 받음
→ '뗀석기' 상위 개념 명명
→ '지금 손에 든 대표적 예 = 주먹도끼' 연결
→ 주먹도끼를 손에 유지
→ H1/H2와 출발
→ 현재 임시 거처가 뒤로 멀어짐
→ 몸 낮춰 지면 관찰
→ 한동안 더 이동
→ 큰 바위 아래 어두운 공간 발견
→ 가까이 가 동굴/바위 그늘 후보를 살핌
→ '동굴 / 바위 그늘' 짧은 연결
→ 장소와 길을 기억
→ 같은 날 다른 관점
```

# 4. Gate A — First-Person / Body

각 항목 1~5점.

1. 첫 화면부터 웹 문서보다 역할 진입처럼 느껴지는가?
2. 손/무릎/도구 위치가 물리적으로 이해되는가?
3. 자세 변화가 `화면 전환`보다 내 몸의 변화처럼 느껴지는가?
4. 도구가 받은 뒤 같은 물건으로 계속 느껴지는가?
5. 관점 전환 뒤 다른 사람의 몸이라는 것이 자연스러운가?

---

# 5. Gate B — R / H1 / H2 Relationship

1. R이 설명 NPC가 아니라 익숙한 사람처럼 느껴지는가?
2. 도구 전달이 관계 장면처럼 느껴지는가?
3. H1/H2가 단순 실루엣 이상의 동행자로 읽히는가?
4. 사람들의 시선/움직임이 행동을 자연스럽게 유도하는가?
5. 대사가 과도한 튜토리얼처럼 느껴지지 않는가?

---

# 6. Gate C — 뗀석기 → 주먹도끼 Terminology Reveal

핵심 질문:

# **도구를 먼저 경험한 뒤, `뗀석기`라는 상위 개념과 `주먹도끼`라는 구체 예의 관계를 자연스럽게 이해하는가?**

확인:

- 받기 전에는 `뗀석기/주먹도끼`가 튀어나오지 않는가?
- 받은 직후 cue가 너무 크거나 긴가?
- cue 때문에 R과의 상호작용 감정이 끊기는가?
- 학생이 `뗀석기와 주먹도끼는 같은 말`이라고 오해하지 않는가?
- 학생이 `모든 뗀석기가 주먹도끼`라고 오해하지 않는가?
- `지금 손에 든 것은 대표적인 예인 주먹도끼`라는 관계가 이해되는가?
- cue 뒤에도 같은 도구가 손에서 계속 보이는가?
- `주먹도끼 = 사냥 전용 무기`로만 느껴지지 않는가?

학생에게 설명 없이 물어볼 질문:

> 뗀석기와 주먹도끼는 어떤 관계인 것 같아?

좋은 방향의 반응:

> 돌을 깨뜨리거나 떼어 만든 도구가 뗀석기이고, 주먹도끼는 그중 대표적인 도구 같다.

---

# 7. Gate D — Current Shelter → Cave Discovery

핵심 질문:

# **동굴이 유일한 `구석기 집`처럼 보이지 않고, 이미 다른 임시 거처에서 살던 사람들이 새 자연 공간 후보를 발견한 사건처럼 느껴지는가?**

확인:

1. 동굴 발견 전 현재 임시 거처가 실제 세계 안에 보이거나 느껴지는가?
2. 거처를 떠날 때 불/사람/임시 거처가 함께 멀어진다는 감각이 있는가?
3. 동굴 발견까지 어느 정도 이동했다는 시간·거리감이 있는가?
4. 바위 아래 공간이 먼저 `발견 대상`으로 보이는가?
5. cave 아이콘/카드보다 실제 공간처럼 읽히는가?
6. 넓이·마른 바닥·비바람을 피할 가능성이 느껴지는가?
7. 어둠·다른 동물·물/먹을거리 거리 같은 불확실성도 느껴지는가?
8. `여기 사람 살기 괜찮을 수도 있겠다`라는 생각이 자연스럽게 생기는가?
9. `동굴 / 바위 그늘` cue가 탐색 뒤 나오는가?
10. cave cue가 아직 직접 배우지 않은 `막집`을 갑자기 비교 설명하지 않는가?
11. cue가 `여기가 정답 집이다`라고 오해시키지 않는가?

---

# 8. Gate E — 교과서 느낌 vs 역사 체험

학생/교사에게 질문:

> 용어가 나오는 순간 갑자기 수업 문제를 푸는 느낌이 들었나?

> 아니면 방금 경험한 것의 이름을 알게 된 느낌이었나?

판정:

- 5: 이름 붙이기가 경험을 강화
- 4: 거의 자연스러움
- 3: 교과 cue가 조금 튐
- 2: 설명 화면 느낌이 큼
- 1: 몰입이 끊기고 교과서 페이지처럼 변함

3 이하면 Stage 08 전에 cue 크기/위치/문장/타이밍을 수정한다.

---

# 9. Gate F — Historical Imagination

플레이 직후 정답을 가르치기 전에 물어본다.

- 왜 이런 돌도구를 손에 들고 나갔을 것 같나?
- 왜 동굴이나 바위 그늘이 머물기에 쓸 만해 보였나?
- 그곳으로 바로 옮겨 살지 말고 더 확인해야 할 것은 무엇일까?
- 왜 현재 거처로 다시 돌아가야 했을까?

좋은 반응 예:

- 비/바람
- 어둠
- 동물 위험
- 물/먹을거리 거리
- 사람들
- 불
- 돌아가는 길

목표는 교과서 문장 그대로 복창하는 것이 아니다.

# 10. Gate G — Screen Treatment

확인:

- fire warmth가 과한가/약한가?
- tool focus가 용어 cue와 겹쳐 과도하게 시선을 끄는가?
- walking sway가 멀미/장난감 느낌을 만드는가?
- cave exposure가 공간 깊이를 돕는가?
- dark 영역이 정보를 숨기지는 않는가?
- reduced effects에서도 같은 의미가 유지되는가?

# 12. Gate I — Fact / Reconstruction Distinction

Teacher surface에서 확인:

- `동굴/바위 그늘 생활` 자체는 교과 연결로 표시되는가?
- `오늘 이 사람들이 이 장소를 발견했다`는 구체 사건은 **역사적 재구성**으로 구분되는가?
- R/H1/H2의 구체 대사와 사건을 실제 기록으로 오해시키지 않는가?

교사에게 확인 질문:

> 어디까지가 교과서가 직접 뒷받침하는 사실이고, 어디부터가 체험용 재구성인지 구분할 수 있는가?

이 질문에 답하기 어렵다면 Teacher surface 또는 handoff 설명을 보강한다.

# 13. Gate J — Misconception Check

학생에게 정답을 먼저 알려주지 않고 간단히 묻는다.

다음 반응은 FAIL 신호다.

- “뗀석기와 주먹도끼는 같은 말이야.”
- “모든 뗀석기가 주먹도끼야.”
- “주먹도끼는 사냥할 때만 써.”
- “구석기 사람들은 동굴에서만 살았어.”
- “저 동굴을 발견해서 바로 이사했어.”
- “R이 실제 역사책에 나오는 사람이야.”

좋은 방향:

- 뗀석기와 주먹도끼의 상·하위 관계를 설명함
- 주먹도끼가 여러 생활 행동에 쓰일 수 있다고 예상함
- 거처가 상황에 따라 달라질 수 있다고 이해함
- cave를 좋은 점과 위험/불확실성이 함께 있는 후보로 봄
- 게임 속 구체 인물·사건이 역사적 상상 재구성임을 이해함

# 15. Stage 07 Human Gate PASS 기준

다음이 모두 만족돼야 한다.

- 첫 화면 역할 진입이 이해됨
- 몸/도구 spatial relation이 크게 어색하지 않음
- R과 도구 전달이 실제 상호작용처럼 읽힘
- 현재 임시 거처가 동굴 발견 전에 존재감이 있음
- `뗀석기 → 주먹도끼` 관계가 오해 없이 전달됨
- 같은 도구 continuity가 느껴짐
- cave가 실제 자연 공간 후보처럼 읽힘
- cave의 장점과 불확실성이 함께 전달됨
- `동굴/바위 그늘` cue가 탐색 뒤 자연스럽게 붙음
- cave cue가 막집을 미리 설명하지 않음
- Teacher surface에서 사실/재구성 구분 가능
- reduced effects parity
- Perspective transition 명료
- 기본 Player에 개발 정보 없음
- 주요 오개념 신호가 없음

PASS 전 Stage 08 전체 Hunt 확장 금지.

# 16. Stage 08로 넘길 의도적 미완성

Stage 07에서 일부러 완료하지 않는 항목:

- 주먹도끼의 실제 땅파기/두들기기/자르기 상호작용
- 반복 사용 뒤 다용도 도구 의미 형성
- `막집`의 정식 명명과 거처 손질 체험
- 불의 세 기능을 실제 생활 행동으로 모두 체험
- cave 발견이 후속 선택/위험/귀환에 남기는 consequence
- Camp가 같은 cave 정보를 다른 입장에서 재평가하는 장면

이 항목들은 Stage 08 이후 책임이다. Stage 07에서 증명하지 않은 것을 완료했다고 기록하지 않는다.
