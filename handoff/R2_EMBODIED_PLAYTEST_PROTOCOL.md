# R2_EMBODIED_PLAYTEST_PROTOCOL.md

## 목적

R2 Stage 07 Skeleton과 이후 Embodied role prototype이 **실제로 사람의 시야·몸·관계·감정·교과 개념·역사적 상상력**으로 작동하는지 교사/학생이 확인한다.

현재 Stage 07은 최종 아트가 아니라 CSS/DOM layout proof다.

따라서 `예쁘다/안 예쁘다`보다 다음을 본다.

- 몸과 세계가 같은 공간처럼 느껴지는가
- 사람과 관계가 생기는가
- 교과 용어가 체험 뒤 자연스럽게 이름 붙여지는가
- cave가 설명 카드보다 실제 장소 발견처럼 느껴지는가

# 2. 자연 플레이 우선

첫 플레이에서는 Debug를 보지 않는다.

교과서 문서를 옆에 두고 정답 대조하며 플레이하지 않는다.

학생/교사가 스스로

- 무엇을 먼저 보았는지
- 무엇이 궁금했는지
- 어느 순간 `교과 공부` 느낌이 강해졌는지
- 어느 순간 실제 장소/사람처럼 느껴졌는지

를 관찰한다.

# 3. Stage 07 현재 흐름

```text
사냥을 나선 사람의 관점
→ 눈을 뜬다
→ 새벽 불
→ R을 봄
→ 돌도구를 받음
→ '뗀석기 · 주먹도끼' cue
→ 주먹도끼를 손에 유지
→ H1/H2와 출발
→ 몸 낮춰 지면 관찰
→ 큰 바위 아래 어두운 공간 발견
→ 가까이 가 동굴/바위 그늘 살핌
→ '동굴 · 바위 그늘' cue
→ 장소와 길을 기억
→ 같은 날 다른 관점
```

---

# 4. Gate A — First-Person / Body

각 항목 1~5점.

1. 첫 화면부터 웹 문서보다 역할 진입처럼 느껴지는가?
2. 손/무릎/도구 위치가 물리적으로 이해되는가?
3. 자세 변화가 `화면 전환`보다 내 몸의 변화처럼 느껴지는가?
4. 도구가 받은 뒤 같은 물건으로 계속 느껴지는가?
5. 관점 전환 뒤 다른 사람의 몸이라는 것이 자연스러운가?

---

# 5. Gate B — R / H1 / H2 Relationship

1. R이 `설명 NPC`가 아니라 익숙한 사람처럼 느껴지는가?
2. 도구 전달이 관계 장면처럼 느껴지는가?
3. H1/H2가 단순 실루엣 이상의 동행자로 읽히는가?
4. 사람들의 시선/움직임이 행동을 자연스럽게 유도하는가?
5. 대사가 과도한 튜토리얼처럼 느껴지지 않는가?

---

# 6. Gate C — 뗀석기 / 주먹도끼 Terminology Reveal

핵심 질문:

# **도구를 먼저 경험하고, 그다음 이름을 알게 되는가?**

확인:

- 받기 전에는 `뗀석기/주먹도끼`가 튀어나오지 않는가?
- 받은 직후 cue가 너무 크거나 긴가?
- cue 때문에 R과의 상호작용 감정이 끊기는가?
- cue를 보고 `아, 내가 방금 받은 그거구나`라고 연결되는가?
- cue 뒤에도 도구가 손에서 계속 보이는가?
- `주먹도끼 = 사냥 무기`로만 느껴지지 않는가?

관찰 메모:

```text
[ ] 자연스럽다
[ ] 조금 교과서 같다
[ ] 흐름을 크게 끊는다

구체 이유:
```

---

# 7. Gate D — Cave / Natural Shelter Discovery

핵심 질문:

# **`동굴에서 살았다`는 문장을 배우기 전에 왜 이런 곳을 이용했을지 느껴지는가?**

확인:

1. 바위 아래 공간이 먼저 `발견 대상`으로 보이는가?
2. cave 아이콘/카드보다 실제 공간처럼 읽히는가?
3. 입구가 넓다는 느낌이 드는가?
4. 바닥 일부가 상대적으로 마르거나 보호될 수 있다는 느낌이 드는가?
5. 안쪽이 어둡고 불확실하다는 것도 느껴지는가?
6. `여기 사람 살기 괜찮을 수도 있겠다`라는 생각이 자연스럽게 생기는가?
7. 동시에 `안쪽은 확인해야겠다`라는 경계도 생기는가?
8. `동굴 · 바위 그늘` cue가 **탐색 뒤** 나오는가?
9. cue가 `여기가 정답 집이다`라고 오해시키지 않는가?

---

# 8. Gate E — 교과서 느낌 vs 역사 체험

학생/교사에게 질문:

> 용어가 나오는 순간 갑자기 수업 문제를 푸는 느낌이 들었나?

> 아니면 방금 경험한 것의 이름을 알게 된 느낌이었나?

판정:

- 5: 이름 붙이기가 경험을 강화
- 4: 거의 자연스러움
- 3: 교과 cue가 조금 튐
- 2: 설명 화면 느낌이 큼
- 1: 몰입이 끊기고 교과서 페이지처럼 변함

3 이하면 Stage 08 전에 cue 크기/위치/문장/타이밍을 수정한다.

---

# 9. Gate F — Historical Imagination

플레이 직후 정답을 가르치기 전에 물어본다.

- 왜 이런 돌도구를 손에 들고 나갔을 것 같나?
- 왜 동굴이나 바위 그늘이 머물기에 쓸 만해 보였나?
- 그 동굴로 바로 옮겨 살지 말고 더 확인해야 할 것은 무엇일까?
- 왜 현재 거처로 다시 돌아가야 했을까?

좋은 반응 예:

- 비/바람
- 어둠
- 동물 위험
- 물/먹을거리 거리
- 사람들
- 불
- 돌아가는 길

목표는 교과서 문장 그대로 복창하는 것이 아니다.

---

# 10. Gate G — Screen Treatment

확인:

- fire warmth가 과한가/약한가?
- tool focus가 용어 cue와 겹쳐 과도하게 시선을 끄는가?
- walking sway가 멀미/장난감 느낌을 만드는가?
- cave exposure가 공간 깊이를 돕는가?
- dark 영역이 정보를 숨기지는 않는가?
- reduced effects에서도 같은 의미가 유지되는가?

# 13. Stage 07 Human Gate PASS 기준

다음이 모두 만족돼야 한다.

- 첫 화면 역할 진입이 이해됨
- 몸/도구 spatial relation이 크게 어색하지 않음
- R과 도구 전달이 실제 상호작용처럼 읽힘
- `뗀석기/주먹도끼` cue가 몰입을 크게 깨지 않음
- 같은 도구 continuity가 느껴짐
- cave가 실제 자연 공간 후보처럼 읽힘
- cave의 장점과 불확실성이 함께 전달됨
- `동굴/바위 그늘` cue가 탐색 뒤 자연스럽게 붙음
- reduced effects parity
- Perspective transition 명료
- 기본 Player에 개발 정보 없음

PASS 전 Stage 08 전체 Hunt 확장 금지.

# 14. Stage 08로 넘길 관찰

Stage 08에서 실제로 추가 검증할 것:

- 주먹도끼의 땅파기/두들기기/자르기 등 기능 사용
- 반복 사용 뒤 `만능 도구` 의미가 실제로 형성되는가
- cave 발견이 선택/위험/귀환에 어떤 결과를 남기는가
- 동굴 정보를 Camp가 다른 관점에서 어떻게 재해석하는가
- 막집과 동굴의 차이를 정답 문제가 아니라 생활 조건으로 이해하는가
