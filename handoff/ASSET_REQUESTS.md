# ASSET_REQUESTS.md

## Status

**요구사항 정의 단계 / 최종 이미지·사운드 제작은 아직 시작하지 않음**

Design Reboot R2에서 최종 자산 공정에 새 필수 조건이 생겼다.

---

# 1. 최우선 자산 원칙

최종 이미지의 단위는 `배경`이 아니다.

# **POV composition = 환경 + 플레이어 몸 + 물건 + 주변 인물 + 현재 행동 + 광원**

이다.

---

# 2. 제작 전에 필요한 문서/시트

최종 이미지 생성 전에 반드시 준비한다.

- Player Body Continuity Sheet — 역할별
- Cast Continuity Sheet — 반복 인물별
- POV / Camera Bible
- Visual Context Bible
- Visual Continuity Map
- Art Direction Bible
- Asset Spec
- Audio Context Map

---

# 3. Player Body Continuity 요구

역할마다 일관되게 관리:

- POV 높이
- 손/팔 비율
- 피부 표현
- 의복/장식
- 주 사용 손
- 도구 잡는 방식
- body pose
- 오염/젖음/피로 등 지속 상태

장면마다 다른 손/팔처럼 보이면 사용 불가.

---

# 4. Hunt 초기 prototype용 핵심 POV 상태

최종 아트 전에도 향후 필요 자산을 다음처럼 정의한다.

1. fire-rest — 불 앞 손/무릎
2. tool-handoff — R의 손 + 도구 + 내 손
3. walking-tool — 걷는 팔 + 도구 + 앞의 동행자
4. crouch-observe — 땅 가까운 손/무릎 + 흔적
5. discovery-focus — 낮춘 몸/도구 + 멀리 대상
6. alert-group — 긴장한 손/팔 + 가까워진 동행자
7. carrying-return — 운반 상태의 손/팔
8. tired-return — 피로한 귀환 body state
9. reunion — R과 가까이 마주하는 시야

---

# 5. Cast 요구

반복 인물 R/H1/H2는 장면마다 동일 인물로 인식되어야 한다.

관리:

- 얼굴
- 체형
- 머리
- 의복
- 반복 소지품
- 자세 습관
- 상대적 키/카메라 거리

관계 몰입에서 identity continuity가 핵심이다.

---

# 6. 광원/물리 연속성

플레이어 손만 별도 overlay처럼 떠 보이면 안 된다.

최종 이미지에서는:

- 손과 환경에 같은 광원
- 물체 가림 관계
- 정확한 원근
- 그림자/반사
- 접촉 위치

가 자연스러워야 한다.

---

# 7. 사운드 요구

향후 필요:

- 불 ambience
- 걷는 발/풀/흙
- 도구 전달/접촉
- 몸을 낮추는 움직임
- 위치감 있는 짧은 인물 대사
- 멀어지는 거처 소리
- 위협 징후
- 귀환 때 다시 들리는 익숙한 불/사람 소리

음악은 후순위.
