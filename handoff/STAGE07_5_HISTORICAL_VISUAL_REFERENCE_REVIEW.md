# 1. 이번 Review의 가장 중요한 발견 — Chronology Coherence Risk

현재 Day 1은 한국 초등 역사에서 배우는 `구석기 생활`을 체험하는 fictional reconstruction이며, 특정 유적의 특정 날짜를 1:1 복원하는 프로젝트가 아니다.

그러나 production visual이 구체화될수록 다음 위험이 커진다.

```text
전기/중기 대표성이 강한 주먹도끼
+
후기 구석기 특정 유적의 구체 막집 복원
+
후기 플라이스토세 특정 시기의 식생
+
유럽 후기 구석기 의복 복원
=
겉보기에는 사실적이지만 시간적으로 근거가 섞인 장면
```

따라서 기존 `REFERENCE-LOCK REQUIRED`보다 한 단계 위의 Gate를 둔다.

# **Chronology Coherence Gate**

어떤 visual detail을 확정하기 전에 반드시 확인한다.

1. 그 자료는 어느 구석기 단계/연대의 것인가?
2. 특정 지역/유적의 자료인가, 넓은 범위에서 확인되는가?
3. Day 1의 다른 핵심 visual anchor와 함께 존재했다고 말할 근거가 있는가?
4. 없다면 `구체 복원`이 아니라 `비진단적(generic/non-diagnostic) reconstruction`으로 낮출 수 있는가?
5. Player/Teacher에게 역사적 사실과 가상 재구성을 구분할 수 있는가?

# **‘구석기 자료’라는 이유만으로 서로 다른 세부를 한 장면에 합치지 않는다.**

# 6. Current Temporary Shelter — v1 Reference Decision

## LOCK할 수 있는 것

현재 Day 1 temporary shelter는 **low-specificity fictional temporary shelter / windbreak**로 유지한다.

시각적으로 잠글 것:

- 낮음
- 비대칭
- 자연 지형/재료와 이어짐
- 완전한 건축물보다 임시 보호 구조에 가까움
- Player가 영구 정착 주택으로 읽지 않음
- 현대 캠핑 장비 요소 없음

금지:

- A-frame camping tent
- 완벽한 삼각 텐트
- 네모난 집 + 삼각 지붕
- 정면 중앙 출입문
- 동일 재질이 팽팽하게 펼쳐진 현대 tent skin
- 동일 규격의 가공 목재
- 로프/매듭/봉제 디테일을 근거 없이 과도하게 정교하게 표현

## DEFER

- 정확한 기둥 개수
- 정확한 입면
- 정확한 덮개 재료
- 정확한 결속/매듭
- 문 위치
- exact Seokjangri reconstruction geometry

Teacher/Debug reconstruction note 권장:

> `현재 거처의 구체 형태는 특정 한 유적을 그대로 복원한 것이 아니라, 이동 생활 속 임시 보호 공간을 체험하기 위한 가상 재구성이다.`

# 9. Clothing Visual Decision

현재 production에서는 **exact garment reconstruction을 잠그지 않는다.**

대신 `anti-anachronism constraints`만 잠근다.

## LOCK — 하지 말아야 할 것

- 현대 티셔츠/바지 패턴처럼 명확한 tailoring
- 지퍼
- 금속 단추
- 현대 신발 sole
- 반복적인 machine-like stitch
- fantasy barbarian fur armor
- 동일한 동물가죽 cape를 모든 사람에게 uniform처럼 배치
- 과도한 장신구/tribal stereotype

## LOCK — 허용되는 production abstraction

- 몸을 덮는 단순한 overlapping covering surfaces
- hide/fiber 가능성을 열어 둔 비진단적 재질
- edge가 완벽히 공업적으로 재단되지 않음
- 캐릭터 사이 silhouette 차이는 가능하지만 현대 fashion role coding 금지
- 정확한 stitch/closure는 화면 핵심 정보로 강조하지 않음

## Teacher/Debug

> `복식의 구체 형태와 재료는 직접 자료가 제한적이므로, 화면의 옷은 당시의 특정 복식을 사실로 재현한 것이 아니라 생활 가능성과 아동 적절성을 고려한 재구성이다.`

# 11. Human Appearance Visual Decision

## LOCK — 피해야 할 표현

- `원시인` caricature
- 과장된 눈썹뼈/턱/털로 야만성을 표현
- Neanderthal stereotype을 근거 없이 사용
- 현대 특정 민족 얼굴을 `당시 한반도인의 표준 얼굴`로 제시
- 남자는 모두 거대/근육질, 여자는 모두 작고 수동적인 modern gender stereotype
- 깔끔한 현대 미용/헤어 styling

## LOCK — Stage 07.5 visual strategy

- fictional cast
- Grounded Illustrative Realism
- 얼굴은 사람으로 자연스럽게 읽히되 특정 고인류 species marker를 교육 내용처럼 강조하지 않음
- 캐릭터 식별은 얼굴 형태 하나보다 자세, hair silhouette의 작은 차이, body proportion, habitual gesture, 위치/행동 continuity로 분산
- Player body는 성별을 강하게 읽히게 하지 않음

## DEFER

- exact species identification
- final facial morphology
- exact skin tone range
- exact hair texture/style
- exact age
- sex/gender visual coding

이 항목은 chronology strategy와 reference pack이 먼저 필요하다.

# 13. Environment Visual Decision

## 지금 LOCK 가능한 것

Production v1에서는 `chronologically non-diagnostic environment`를 목표로 한다.

즉:

- 특정 계절을 강하게 주장하지 않음
- 특정 현대 조림지 같은 숲 금지
- 울창한 tropical jungle 금지
- 사바나 caricature 금지
- 단풍 절정/폭설/꽃 만발처럼 계절을 확정하는 motif 금지
- 현대 농경지처럼 평탄한 grass lawn 금지

화면 구성:

- route를 읽을 수 있는 open visual corridor
- 낮은 ground vegetation + 일부 shrub/tree mass
- 강/언덕/암반 등 Korean Paleolithic broad landscape references와 양립 가능한 terrain vocabulary
- 식물은 production foreground/depth 요소로 쓰되 species lesson처럼 세밀한 동정 가능성을 강요하지 않음

## 아직 잠그지 않음

- 특정 나무 species
- 특정 grass species
- exact canopy density
- foliage seasonal color
- snow/frost state
- exact humidity

# **Bible v2에서는 `환경 디자인의 구도와 깊이`는 잠그되 `식물 종과 계절`은 chronology가 확정되지 않는 한 비진단적으로 유지한다.**

# 14. Day 1 Chronology Strategy — Recommended Default

현재 프로젝트의 교육 목적과 이미 구축된 구조를 고려하면 v1 production에 가장 안전한 전략은 다음이다.

# **Korean Paleolithic Educational Composite / Element-level Provenance**

의미:

- Day 1 자체는 실존 사건/유적 복원이 아님
- 한국 구석기 생활의 broad curriculum anchor를 fictional same-day experience로 구성
- 각 구체 visual element는 자신의 provenance를 가짐
- 특정 유적의 복원 세부를 다른 시기의 대표 유물과 무조건 결합하지 않음
- chronology가 충돌할 수 있는 세부는 generic하게 낮춤

## 이 전략이 허용하는 것

- Korean handaxe morphology에 기반한 fictional tool
- 이동 생활
- 불
- 사람들과 공동 행동
- 자연 거처 발견
- exact site clone이 아닌 low-specificity temporary shelter

## 이 전략이 허용하지 않는 것

- `전곡리 어느 날`이라고 말하면서 석장리 후기 구석기 막집을 그대로 넣음
- `석장리 어느 날`이라고 말하면서 전기 구석기 handaxe 중심성을 사실처럼 결합
- 후기 플라이스토세 특정 vegetation 연구를 모든 구석기의 고정 landscape로 제시
- 유럽 후기 구석기 복식 복원을 한국 전기/중기 인물의 정답 옷으로 제시

## Teacher-facing provenance

Teacher/Debug에서는 중요한 visual anchor마다 다음 정도를 확인 가능하게 한다.

```text
Historical Anchor
Comparative Reference
Reconstruction Choice
Uncertainty / Deferred Detail
```

# 15. Alternative Strategy — Specific Archaeological Window

향후 프로젝트가 더 높은 역사 재현 정밀도를 원하면:

```text
specific region
+ specific chronological band
+ material culture set
+ environment set
+ hominin/cast strategy
```

를 먼저 잠그고 전체 scene을 다시 맞춘다.

이 경우 장점:

- 시각적 재현 근거가 강함
- 환경/거처/도구 consistency 향상

단점:

- 현재 초등 교과의 broad 구석기 요소를 한 Day 1 안에서 모두 경험시키기 어려워질 수 있음
- 기존 Hunt/Gather/Camp story 및 curriculum anchors 일부 재설계 필요 가능

따라서 Stage 07.5에서는 **Educational Composite**를 기본으로 유지하되, production 세부는 chronology-safe하게 제한하는 것을 권장한다.

# 16. Scene-by-Scene Reference Impact

## SC00 — eyes closed / camp audio

Reference impact 낮음.

Lock:

- fire sound
- materials handling
- short translated dialogue

Avoid:

- 특정 복식/도구를 소리로 과도하게 확정

## SC01 — living community

높은 reference sensitivity.

필요:

- shelter low-specificity
- clothing non-diagnostic
- human cast non-caricature
- fire/material activity

Background actor는 특정 후기 구석기 sewing workshop처럼 보이면 안 됨.

## SC02 — handoff

Reference certainty 높음.

- handaxe primary/secondary anchors 사용
- hands/body exact appearance는 fictional reconstruction

## SC03 — handaxe inspect

Reference certainty 높음.

- actual dimensions/proportions 활용
- terminology strong anchor

## SC04~SC08 — departure / track observation

환경 exactness 낮춤.

- route depth
- split rock landmark
- generic groundcover
- actor body/relationship continuity가 우선

## SC09~SC10 — rock shelter

Broad historical anchor 가능.

- natural space
- protection + uncertainty

특정 유명 동굴을 1:1 복제하지 않음.

## SC11 — Aru POV

가장 중요한 것은 historical object exactness보다 social/spatial continuity.

- same camp family
- same people
- same handaxe
- same departure direction

# 19. New Historical Integrity QA

Bible v2 / production review에 다음 질문을 추가한다.

## Chronology QA

- 이 visual detail은 어느 시기의 근거인가?
- handaxe와 함께 두어도 되는 세부인가?
- 특정 후기 구석기 자료를 broad 구석기 사실처럼 만들지 않았는가?

## Site-specificity QA

- 석장리 복원 요소를 `모든 구석기 거처`처럼 복제하지 않았는가?
- 특정 동굴/유적을 fictional Day 1 장소인 것처럼 표시하지 않았는가?

## Clothing QA

- 현대식 tailoring이 보이지 않는가?
- 유럽 후기 구석기 복식 그림을 한국 Day 1의 정답으로 복제하지 않았는가?

## Hominin QA

- `원시인` caricature가 없는가?
- 특정 species/ethnicity를 근거 없이 확정하지 않았는가?

## Environment QA

- 특정 시기 화분 자료를 Day 1 exact forest로 과잉 적용하지 않았는가?
- 극적인 계절 motif가 근거 없는 chronology claim이 되지 않는가?
