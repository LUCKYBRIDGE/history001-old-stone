# HUNT_PLAYTEST_NOTES.md

## Hunt 교사 플레이테스트 기록지 v2

상태: **v0.1 첫 플레이에서 HUX-001 확인 / v0.2 재테스트용으로 개편**

이 문서는 Hunt를 실제 플레이하며 **기능이 아니라 역할 빙의·리듬·역사적 의미가 살아 있는지** 기록하기 위한 기준이다.

---

# 1. 가장 먼저 볼 것 — 첫 30초

플레이 시작 후 20~30초 동안 다음을 기록한다.

- 내가 어디에 있는지 알 수 있었는가?
- 주변에 사람이 있다는 느낌이 있는가?
- 지금 왜 움직여야 하는지 알 수 있는가?
- `나는 사냥 역할입니다` 같은 설명 없이도 무엇을 하게 될지 짐작했는가?
- 첫 의미 있는 행동을 얼마나 빨리 했는가?
- Stage / Vertical Slice / RoleEntry 같은 개발 문구가 몰입을 깨는가?

# 4. Role Embodiment

각 항목에 `예 / 애매 / 아니오 + 근거`를 적는다.

1. `사냥 캐릭터를 조종한다`보다 `내가 같이 나간다`는 느낌이 있는가?
2. 내 손/몸/공간의 감각이 최소 몇 번 기억나는가?
3. 함께 나간 사람 중 기억나는 사람이 있는가?
4. 나를 기다리는 사람이 있다고 느껴지는가?
5. 내 행동이 공동체와 연결되어 있다고 느껴지는가?

---

# 5. 관계와 대사

1. `같이 가자`가 역할 배정 설명보다 자연스러운가?
2. `해가 지기 전에 돌아와`가 아침에는 과하게 강조되지 않는가?
3. 같은 말이 귀환 때 실제로 다르게 느껴지는가?
4. NPC가 정답을 알려주는 선생님처럼 보이지 않는가?
5. 짧은 대사가 사람의 존재를 만드는가, 아니면 텍스트만 늘리는가?

---

# 6. 공간·시간 연속성

1. 거처에서 멀어졌다고 느끼는 순간이 있는가?
2. 해가 낮아지는 것이 실제 판단에 영향을 주는가?
3. 앞에서 본 자연 랜드마크를 귀환에서 기억할 수 있는가?
4. 장면이 독립 카드가 아니라 한 길을 계속 걷는 것처럼 이어지는가?
5. 아침의 불과 저녁의 불빛이 같은 장소로 느껴지는가?

---

# 7. 탐색과 선택의 결과감

1. 흔적 탐색이 버튼 목록보다 주변을 살피는 행동처럼 느껴지는가?
2. 아무것도 없는 곳을 봐도 `틀렸다`는 느낌이 없는가?
3. 단서 판단은 정답 퀴즈처럼 보이지 않는가?
4. 접근/추적 선택 후 세계·사람·시간이 실제로 반응하는가?
5. `조금만 더`와 `돌아갈 때` 사이의 갈등이 생기는가?

---

# 8. 자연 위험

1. 위험이 적/전투 시작처럼 보이지 않는가?
2. 위험 신호가 먼저 나타나 긴장을 만드는가?
3. 사람도 자연 속에서 위험할 수 있다는 관점 변화가 생기는가?
4. 함께 움직이는 의미가 있는가?
5. 공격 버튼이 없어도 장면이 충분히 긴장되는가?

---

# 9. 성공과 빈손 비교

두 결과를 모두 확인한다.

## 먹을 것 확보

- 게임 승리처럼 과장되는가?
- 기쁨 뒤 `가지고 돌아가야 한다`는 현실이 이어지는가?

## 빈손

- 플레이 실력 실패처럼 느껴지는가?
- 아쉬움은 있으나 하루가 계속된다고 느껴지는가?

## 공통

- 두 결과 모두 귀환의 의미가 살아 있는가?
- 불빛 장면에서 성공/빈손 모두 안도가 있는가?

---

# 10. 텍스트와 메타 UI

1. 읽느라 행동이 멈추는 구간은 어디인가?
2. 같은 의미를 반복 설명하는 문장은 어디인가?
3. `사냥 · 추적 판단` 같은 제목이 체험을 화면 밖에서 보게 만드는가?
4. 개발/테스트용 문구가 보이는가?
5. 설명을 삭제해도 행동과 장면만으로 이해될 수 있는 곳은 어디인가?

# 11. 전체 판정 12개

`1 = 거의 느껴지지 않음 / 5 = 매우 분명함`

| 항목 | 1~5 | 근거 |
|---|---:|---|
| 시작부터 그 장소에 들어온 느낌 |  |  |
| 내가 공동체의 한 사람이라는 느낌 |  |  |
| 함께 나가는 사람이 실제 사람처럼 느껴짐 |  |  |
| 사냥감은 먼저 찾아야 한다 |  |  |
| 발견과 성공은 다르다 |  |  |
| 더 가면 시간/거리 부담이 생긴다 |  |  |
| 사람도 자연 속에서 위험할 수 있다 |  |  |
| 위험은 싸워 이기는 문제가 아니다 |  |  |
| 빈손도 정상적인 하루다 |  |  |
| 잡는 것만큼 돌아오는 것이 중요하다 |  |  |
| `해가 지기 전에 돌아와`의 의미가 변한다 |  |  |
| 불빛에서 `돌아왔다`는 안도가 느껴진다 |  |  |

# 14. Hunt Immersion Complete 조건

- [ ] 첫 30초 Opening Gate 통과
- [ ] 역할 설명 없이 기본 상황 이해
- [ ] 기억되는 동행자/기다리는 사람 존재
- [ ] 공간·시간 연속성 확인
- [ ] 선택 결과감 확인
- [ ] 성공/빈손 비교 완료
- [ ] 모티프 의미 변화 확인
- [ ] 개발 메타 UI가 기본 학생 화면을 방해하지 않음
- [ ] 주요 HUX 문제 분류/수정
- [ ] 교사 재플레이 통과
- [ ] 소규모 학생 테스트 통과

자동 테스트 통과만으로 이 체크리스트를 완료 처리하지 않는다.
