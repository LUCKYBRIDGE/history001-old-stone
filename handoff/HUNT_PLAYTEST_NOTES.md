# HUNT_PLAYTEST_NOTES.md

## Stage 09-A — 교사 직접 플레이 기록지

상태: **플레이테스트 준비 완료 / 실제 관찰 미실시**

이 문서는 Hunt Vertical Slice v0.1을 교사가 직접 플레이하면서 **관찰 사실을 먼저 기록**하기 위한 Stage 09-A 작업지다.

Stage 09-A에서는 새 기능을 추가하거나 즉시 코드를 고치지 않는다. 먼저 실제 플레이에서 무엇이 문제인지 확인하고, 그 기록을 다음 Stage 09-B에서 `유지 / 축소 / 수정 / 삭제`로 분석한다.

---

## 1. 플레이테스트 목적

이번 테스트는 다음 질문에 답하기 위한 것이다.

1. 사냥의 흐름이 초등학생에게 이해 가능한가?
2. 설명을 읽는 시간이 실제 행동보다 길게 느껴지지 않는가?
3. 흔적 탐색과 사냥 시도가 `직접 해 보는 경험`으로 느껴지는가?
4. 선택들이 정답 퀴즈가 아니라 서로 다른 판단으로 느껴지는가?
5. 사냥 성공이 게임의 유일한 좋은 결과처럼 느껴지지 않는가?
6. 빈손도 `실패 화면`이 아니라 정상적인 하루로 받아들여지는가?
7. 자연 위험이 전투보다 인간의 취약함·판단·협력으로 느껴지는가?
8. 사냥의 끝이 `잡았다`가 아니라 `돌아왔다`로 느껴지는가?
9. `“해가 지기 전에 돌아와.”`의 의미가 아침과 귀환에서 달라지는가?
10. 사냥 외에도 같은 공동체의 다른 사람들이 존재한다고 느껴지는가?

## 2. 실행 준비

권장 개발 환경:

- Node.js 24
- npm 11 이상
- 저장소 최신 `main`

로컬 실행:

```bash
git switch main
git pull
nvm use
npm install
npm run dev
```

Vite가 표시한 로컬 주소를 브라우저에서 연다.

### 플레이 전 확인

- 브라우저 콘솔이나 개발자 도구를 먼저 보지 않는다.
- 기획 문서를 다시 읽은 직후보다는, 가능한 한 `처음 보는 학생`에 가까운 상태로 1차 플레이한다.
- 첫 플레이에서는 어떤 결과가 나오도록 의도적으로 선택하지 않는다.
- 불편함을 발견해도 플레이 도중 코드를 수정하지 않는다.
- placeholder 이미지/텍스트 자체의 미완성도보다 **진행 의미·조작·이해·리듬**을 우선 평가한다.

## 3. 테스트 방식

### Round 1 — 자연스러운 첫 플레이

목적: 설명을 모르는 사용자가 자신의 판단대로 플레이했을 때의 실제 흐름을 본다.

규칙:

- 선택지를 `정답 찾기`처럼 분석하지 않고 자연스럽게 선택한다.
- 진행이 막히면 막힌 지점과 원인을 기록한다.
- 이해가 안 되는 문장은 다시 읽은 횟수까지 적는다.
- 지루해서 빨리 넘기고 싶었던 장면은 그대로 적는다.
- 감정 변화가 생긴 순간은 짧게 기록한다.

### Round 2 — 반대 결과 비교

목적: `먹을 것 확보`와 `빈손`이 모두 정상적인 하루로 느껴지는지 비교한다.

1차 플레이와 다른 결과가 나왔을 때만 두 번째 경로를 의도적으로 확인한다.

현재 prototype에서 결과 비교가 꼭 필요할 경우 사용할 수 있는 확인용 경로:

- **먹을 것 확보 예시**: 접근에서 `조금 더 기다리며 움직임을 살핀다` → 추적 판단에서 `조금 더 흔적을 따라간다` 또는 `주변과 해의 위치를 한 번 더 확인한다`
- **빈손 예시**: 추적 판단에서 `여기서 돌아가는 쪽을 생각한다`

이 경로 정보는 **Round 1 전에 보지 않는 것을 권장**한다.

## 4. 기록 원칙

좋은 기록:

> 사실: 흔적 탐색 화면에서 무엇을 해야 하는지 이해하기까지 약 10초 멈췄다.

피할 기록:

> 이 장면은 별로다.

### 수정안은 바로 확정하지 않는다

Stage 09-A의 역할은 `문제 발견`이다.

- 사실
- 사용자 반응
- 막힘 정도
- 감정 변화
- 반복 여부

를 기록한다.

`어떻게 고칠지`의 우선순위와 방법은 Stage 09-B에서 결정한다.

## 8. 가장 중요한 전체 판정 10개

플레이 직후, 너무 오래 생각하지 말고 1~5점으로 기록한다.

`1 = 거의 느껴지지 않음 / 5 = 매우 분명함`

| 항목 | 1~5 | 한 줄 근거 |
|---|---:|---|
| 사냥감은 바로 보이지 않고 먼저 찾아야 한다 |  |  |
| 발견과 사냥 성공은 다르다 |  |  |
| 사냥 결과를 확신할 수 없다 |  |  |
| 더 추적하면 시간과 거리 부담이 생긴다 |  |  |
| 사람도 자연 속에서 위험할 수 있다 |  |  |
| 위험은 싸워 이기는 문제가 아니다 |  |  |
| 빈손도 정상적인 하루다 |  |  |
| 잡는 것만큼 돌아오는 것도 중요하다 |  |  |
| 불빛은 공동체로 돌아왔다는 안도를 준다 |  |  |
