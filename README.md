# history001-old-stone

초등학생용 **구석기 역사 체험 웹게임** 프로젝트 저장소입니다.

이 저장소는 기획 문서, 실제 앱 코드, 테스트 기록, 이미지 제작 맥락, 세션 간 인수인계를 함께 관리하는 **Single Source of Truth**로 사용합니다.

## 새 ChatGPT 작업 세션에서 가장 먼저 읽을 것

1. [`AGENTS.md`](AGENTS.md)
2. [`PROJECT_STATUS.md`](PROJECT_STATUS.md)
3. [`docs/00_DEVELOPMENT_WORKFLOW.md`](docs/00_DEVELOPMENT_WORKFLOW.md)
4. [`handoff/CURRENT_HANDOFF.md`](handoff/CURRENT_HANDOFF.md)

그 다음 현재 작업과 관련된 `docs/` 기획 문서와 실제 코드를 확인합니다.

## 핵심 운영 원칙

- 개발의 주 작업 환경은 **ChatGPT 채팅**입니다.
- 채팅 세션은 길이보다 **작업 책임 단위**로 분리합니다.
- 프로젝트의 기억은 채팅이 아니라 GitHub에 남깁니다.
- 일반 개발 세션에서는 이미지를 생성하지 않습니다.
- 이미지는 기능과 장면이 검증된 뒤 별도 이미지 제작 공정에서 만듭니다.
- 이미지 제작에 필요한 역사·서사·연속성 맥락은 개발 초기부터 문서로 축적합니다.

자세한 전체 단계는 [`docs/00_DEVELOPMENT_WORKFLOW.md`](docs/00_DEVELOPMENT_WORKFLOW.md)를 참고하세요.
